  0 to 3, and a slot that releases the lowest bit at time 2. The
  clock runs to time 3, and each worker submits up to 2 values
  from 0 to 3

states: reachable states of two rooms whose records differ and
  have the same declared bits. The recipient should see the same
  thing in both
leaks: states in which the recipients have seen different things
by value: leaks with different values released at the same times
by timing: leaks with a release at different times
outputs: how many different things a worker can make the recipient
  see, for one record
in every state the core had released what the reference model
  says: the declared bits of the committed record, once, at the
  slot's deadline
