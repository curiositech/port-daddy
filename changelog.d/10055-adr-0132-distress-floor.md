- **The Distress Register floor (ADR-0132 phase 0): a halt that works with nothing else running.** `lib/distress.ts` implements the registry (four classes, the ADR code table), the exact one-line wire format with a round-tripping parser and serializer, `O_APPEND` appends to `~/.port-daddy/DISTRESS` and `<repo>/.portdaddy/DISTRESS` (bounded at 4096 bytes so concurrent writers never tear a line), and the halt sentinel `~/.port-daddy/HALT` (`haltActive`/`readHalt`/`writeHalt`, machine-wide authoritative). `bin/pd-distress` is the POSIX-sh twin (`raise`, `read`, `halt-active`, `show-halt`) with zero Node dependency, tested with node stripped from PATH. The Coordination Guard now takes a legible OFF state while the sentinel is hoisted — one calm stderr line, exit 0, no "COORDINATION LAYER DOWN" escalation for a daemon the operator turned off on purpose (the ADR-0131 conflation) — while the genuine no-sentinel case still escalates. The reaper, resurrection `check`/`claim`, the heartbeat-death handler and the custodian's resurrect duty all stand down while halted: silence during a HALT is compliance, not death.
