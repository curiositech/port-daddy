- **The roadmap projection's "canonical" order was host-dependent.** Both the item sort and the receipt sort broke ties with `localeCompare`, which consults the runtime's default locale — so the same projection could serialize in two different orders on two machines, which is the one thing a canonical serialization may not do. It also disagreed with the projection's own consumers: iOS sorts with Swift's `<`, and the two invert on case (`'alpha'.localeCompare('Beta')` is `-1`; `'alpha' < 'Beta'` is `false`), so a mixed-case pair of slugs came out one way on the web and the other way on the phone from the single projection that claims to define the order. Both sorts now compare code units, which is what the Swift and Rust consumers already do. A regression test pins the premise first — that the two comparators really do disagree — and then the order, so it cannot pass for the wrong reason if the runtime's collation changes.
