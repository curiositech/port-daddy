- **The page-overflow tests now close every PDF they open.** Four helpers in `test_page_overflow.py` opened a saved PDF and returned a page from it without ever closing the document, so both the document that built the page and the one that read it back were still open when the enclosing `tempfile.TemporaryDirectory()` removed the file underneath them — and the reader outlived the temporary directory entirely. POSIX tolerates unlinking an open file, which is why this never showed on Linux or macOS; on Windows `shutil.rmtree` raises `PermissionError: [WinError 32]` on exactly this pattern. Each helper now closes the builder document explicitly and reads the saved file back under `with pymupdf.open(path) as doc:`, so no document outlives the paper it was read from. No assertion changed and no case was added: the suite proves the same nineteen facts about margin collisions, ink off the foot, images off the paper, and running-foot intrusions.
