- **Export a roadmap item to GitHub Issues, Linear, or Jira.** `lib/roadmap-export.ts` is a one-way, repeatable push (not two-way sync — that's a materially harder problem and wasn't the ask) to each tracker's real API: GitHub REST Issues, Linear's `issueCreate` GraphQL mutation, Jira Cloud REST v3 issue create (Atlassian Document Format body included). New `POST /roadmap/items/:slug/export` route and `pd roadmap export <slug> --to github|linear|jira [target flags]` CLI command; on success the created issue's URL is recorded as a typed `issue` link on the roadmap card (`lib/planner-edges.ts` gains an `issue` artifact/link kind) so the two records stay associated. Credentials (`PD_GITHUB_TOKEN`/`GITHUB_TOKEN`, `PD_LINEAR_TOKEN`, `PD_JIRA_EMAIL`+`PD_JIRA_API_TOKEN`) are server-side env vars only — never accepted in the request body.
