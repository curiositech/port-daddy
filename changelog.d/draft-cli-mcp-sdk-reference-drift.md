- The docs site's reference catalogue is back in step with the product. Fifty-two CLI verbs that shipped without a reference page now have one — among them `pd periscope`, `pd coast-guard`, `pd dispatch`, `pd roster`, `pd parley`, `pd safe`, `pd secret` and `pd work` — along with three SDK methods (`takeoverSession`, `registerActor`, `ensureActorCredential`). The MCP page's tool counts are read off the catalogue generated from `mcp/server.ts` instead of being typed by hand, so the published figures are the server's own: it had been claiming 136 tools while the server served 190, and 17 default tools while the default set had grown to 19. A new CI job re-derives that catalogue and fails when it falls behind the server. Two social cards that were never generated (`/research` and `/whitepaper/sealed-harbor`) now exist, and the card renderer looks for Liberation Sans where Debian and Ubuntu actually install it rather than silently falling through to a font whose wider metrics push the footer off the edge of the card.
