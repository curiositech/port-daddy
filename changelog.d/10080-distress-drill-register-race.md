- **The distress drill's step 3 no longer flakes under CI load.** `scripts/pd-distress-drill.sh` wrote each register line to the machine-wide and repo-scoped `DISTRESS` files with two separate appends, then compared them byte-for-byte. Entities append concurrently, so two of them can interleave as A>machine, B>machine, B>repo, A>repo and leave the two files holding the same lines in a different order — a permanent divergence no wait can fix. The check now compares the registers as multisets (each file stays internally ordered by its own append sequence, which is what the SEEN-before-COMPLIED check already verifies), waits a listening interval for an in-flight line's second write, and prints the actual difference when it does fail. The comparison now lives in a `__registers-match` subcommand so the drill's own test suite can prove it still rejects a missing, extra, or duplicated line rather than passing vacuously.
