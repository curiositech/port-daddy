- **Roadmap snapshot export could silently truncate the committed roadmap.** `buildRoadmapSnapshot()` regenerated `docs/roadmap/roadmap.snapshot.json` wholesale from whatever the live daemon's `roadmap_items` table currently held, with no reconciliation against the file it was overwriting — any daemon that wasn't a strict superset of committed history (an ephemeral or parallel instance, a restored backup, a partial-loss DB) could export a much smaller snapshot and silently discard everything git already had, past the only existing guard (refuse zero items). Added a shrink guard: `buildRoadmapSnapshot()` now accepts the previously-committed snapshot and refuses to write one that drops more than 20% (configurable) of previously-known slugs, naming the missing slugs in the error. Both producers (`scripts/export-roadmap-snapshot.ts`, `pd roadmap chomp --emit-pr-plan`) now read the committed file and pass it through automatically; `--allow-shrink` / `PD_ROADMAP_ALLOW_SHRINK=1` opts out for a genuine intentional bulk deletion. Also adds `roadmap_search` to the MCP tool surface (matching the CLI/route addition already shipped in #9883), closing the "MCP/SDK — not added in this slice" gap that PR flagged.
