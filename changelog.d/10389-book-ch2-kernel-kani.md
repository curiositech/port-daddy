- **Chapter 2 now prints what Kani says of the Book's own kernel.** The chapter's section on verification described harnesses on Port Daddy's card crate, which is not the code the Book's kernel checks cards with. It now also prints a run of Kani on the kernel's order on patterns, over every pattern of up to four bytes. If one pattern reaches a second and the second a third, the first reaches the third, which is why a chain can be checked one card against the next. A control harness puts the same question to a wrong order and fails, as it must.
