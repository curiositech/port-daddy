- **Committed assets that nothing references are now found by a command instead of by a person remembering to grep.** Every reference guard in the repo runs reference → file — `scripts/check-doc-citations.mjs` for paths cited in prose, `website-v2/src/site-integrity.test.ts` for the site's asset literals, `scripts/harbor-research/check_plate_provenance.py` for plate records — and none of them runs file → reference, which is how 147 dead asset files accumulated until a human proved each one dead by hand. `scripts/check-orphan-assets.mjs` is the missing direction: it reports every image, plate, PDF, video and figure fragment under `docs/`, `whitepaper/` and the site trees that no source file reaches, resolving the ways this repo actually builds paths — JS template literals, LaTeX macro parameters such as `plates/swiss/chapter-#1.jpg`, extension-less `\input`, and the dark siblings `website-v2/src/components/site/ThemedImageSrc.ts` derives at runtime — so a plate the Book prints is never reported as dead. `--check` fails only inside `website-v2/public/whitepaper/plates/`, `website-v2/public/whitepaper/figures/` and `whitepaper/figures/`, and runs in `.github/workflows/library-checks.yml` beside the provenance check it pairs with; `scripts/orphan-assets-allow.json` carries one reason per exempt file, and an entry without a real reason fails the check itself.
