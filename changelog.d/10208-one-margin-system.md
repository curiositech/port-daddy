- **The Book's margin apparatus is one system, not two.** `whitepaper/figures/pd-pedagogy.tex` and its byte-identical twin under `website-v2/public/whitepaper/figures/` carried a second, in-column rendering of every margin device behind `\ifpdmargincolumn` — a switch that existed only so the retired standalone A4 chapter PDFs could compile the same chapter source. The switch, its `false` default, all eighteen branch sites and the `\pdmargincolumntrue` the Book's preamble set to turn the apparatus on are removed: `\pdmargincaption`, `\pdsidenote`, `\pdgloss`, `\pdmarginfigure`, `\pdprov`, `\pdprovedon`, `\pd@marginhead`, `\pd@marginglyph`, `pdrecitation`, `pdexercise`, `pdSolution`, `pdsession` and both exercise pointers now place into the margin unconditionally, and the degradation to `\caption`, `\footnote`, a parenthetical or nothing at all is deleted rather than left behind a conditional that is always true.
- **What is kept is the per-page fit test, which was never an artifact switch.** `\pdmargincaption` and `\pdsidenote` still measure one block against the room left in that page's column and set it in the text column when it does not fit — the guard that keeps a 400-character note on the paper instead of 36.7 pt past the trim. One margin system can still decide, page by page, that a particular block does not fit in it.
- **The rendered Book is unchanged to the byte.** The Book set `\pdmargincolumntrue`, so every branch deleted here was the one it never took; `scripts/build-whitepapers.sh coordination-papers-mega-volume` produces the same 9,738,993-byte, 543-page PDF (sha256 `452e7296c7d593ef413bc790124f415b2c7a139590c4ca67cb5a33730ef3b55b`) before and after, with 0 TeX errors and 0 `Marginpar on page` overflows.
