- **A CI guard now stops the relay's malformed-URL 500 defect class from returning.** `apps/relay/src/index.ts` decodes URL path segments with the fail-closed `safeDecodeSegment` helper everywhere except its own body — a raw `decodeURIComponent` call or bare reference (e.g. `.map(decodeURIComponent)`) anywhere else throws `URIError` on a malformed escape (`%ZZ`) and hits the worker's global boundary, answering a bare 500 `INTERNAL_ERROR` for what is only a bad URL, exactly the defect class `safeDecodeSegment` exists to prevent. `scripts/check-relay-decode-guard.mjs` (new `relay-decode-guard` CI job) parses the file with the TypeScript compiler API and fails on any `decodeURIComponent` reference outside `safeDecodeSegment`'s body, naming the file, line, and offending text. `tests/unit/relay-decode-guard.test.js` pins the mechanical behavior against fixtures and, separately, the real file's current state.
