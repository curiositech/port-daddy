- **A CI guard now stops the relay's malformed-URL 500 defect class from returning.** `apps/relay/src/index.ts` decodes URL path segments with the fail-closed `safeDecodeSegment` helper everywhere except its own body — a raw `decodeURIComponent` call, bare callback, receiver-qualified access, or computed property access anywhere else can reach the throwing builtin on a malformed escape (`%ZZ`) and hit the worker's global boundary, answering a bare 500 `INTERNAL_ERROR` for what is only a bad URL. `scripts/check-relay-decode-guard.mjs` parses the router with the TypeScript compiler API, rejects every executable reference outside `safeDecodeSegment`, and names the file, line, and offending text. `tests/unit/relay-decode-guard.test.js` pins direct, bare, destructured, qualified, computed, missing-anchor, and live-router behavior.
- **Porthole now owns terminal-recording CI exclusively.** The obsolete VHS workflow, which ignored failed tapes and self-committed generated files, is removed. The Porthole pipeline records replayable casts and GIF fallbacks, validates the resulting corpus, and retains the verified bundle as a workflow artifact.
