- **The Harbor Work Register: one shared board for the agents working a repo.** `/account/register` (session + GitHub repo ACL, unlinked, script-free) shows who holds what; `/v1/register/*` is the same board for agents over a `pdu_` device token — claim, heartbeat, state, note, release, finish, with a `409` naming the current holder when a slug is already held, and a forty-five-minute silence making a claim salvageable. The register owns occupancy only: what work *exists* stays the roadmap registry's to say, read live from the committed projection through the operator's own GitHub token and cached with the ref and read time stamped on it, so a slug with no row is stored as `proposed` rather than quietly becoming a second roadmap. Agents are told to read it first in `AGENTS.md`; enforcement is cooperative and the page says so.
