The section is now `\section*{Reader's Map}` with an `\addcontentsline`, matching the four sibling chapters that already carry that shape; the standalone kernel paper, which has no front matter of its own, keeps the map exactly as it was. The abstract's reading-time note now points at "the Reader's Map below" instead of `\S\ref`, since an unnumbered section has no number to cite.
