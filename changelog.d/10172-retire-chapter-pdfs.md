- **The eight standalone chapter PDFs are retired; the Book is the one document.** Each chapter used to publish its own PDF (single-writer-kernel, anchor-protocol, sealed-harbor, legible-swarm, spawn-to-person, harbor-economy, bonded-commons, federated-harbor) at A4 with no margin column — a second, worse-typeset copy of the same words next to the Book's 7x10in trim, and a reader could land on the wrong one. `scripts/build-whitepapers.sh` no longer builds them (only the Book and the seven research papers do); the eight `.pdf` files are removed from `website-v2/public/whitepaper/`; `whitepaper/textbook.json` drops the per-chapter `pdf` field entirely rather than pointing it at a dead path; and `website-v2/src/data/whitePapers.ts` drops `filename`/`pdfPath`/`pages`/`sizeKb` from the `WhitePaper` interface and from all eight chapters, along with the now-unreachable `paperPdfUrl` helper — every "read"/"download" affordance on the site (`PaperDetailPage`, the homepage CTA, the manifesto) points at `COLLECTED_VOLUME`, the Book's own PDF. The eight 301s in `website-v2/public/_redirects` are written out literally, so a reader following an old citation still lands on the Book without the data file having to carry a path to a file that is gone. `publication-digests.json` and `website-v2/scripts/check-whitepaper-metadata.ts` no longer track a per-chapter PDF. The Book's own front matter stops advertising the retired editions. The chapters' `.tex` sources are untouched and still independently compilable by hand; only the automated build-and-publish path for a standalone chapter PDF is gone.
- **The Book's own PDF is served from the site again, and the eight retired URLs redirect to it.** `website-v2/scripts/prune-pages-assets.mjs` deleted the Book from the deploy bundle on every build — correct when the illuminated edition was 30.9 MiB against Cloudflare Pages' 25 MiB per-asset limit, wrong now that the 7x10in trim has it at 9.3 MiB. It is a size check rather than a name list, so the file ships and `/whitepaper/coordination-papers-mega-volume.pdf` resolves to a real PDF instead of the SPA's HTML shell; the raw GitHub URL stays as the deliberate full-fidelity download, which is all it can be (it answers `X-Frame-Options: deny` and `Content-Type: application/octet-stream`, so it neither embeds nor opens). `website-v2/public/_redirects` gains a 301 from each of the eight retired `.pdf` paths to the Book, above the `/*` catch-all — without them a dead PDF URL answers 200 with HTML, so a citation manager saves `index.html` under a `.pdf` name and no 404 monitor ever sees it — and the postbuild step now composes those hand-written rules with the generated route rewrites instead of overwriting them.
- **The CI gate that protected the standalone papers is retired with them.** `scripts/harbor-research/check_standalone_figures.py` and `whitepaper/standalone-figures.json` are removed and the "No Book-side edit has shrunk a standalone paper" step is gone from `library-checks.yml`. Its premise was that a chapter source was, in the same bytes, a submission paper; with no second artifact it had reversed, failing exactly the Book-side figure consolidation that `check_duplicate_figures.py` requires. The `\ifpdbook` branch scanner it shared stays, with its coverage, in `tests/harbor-research/test_pdbook_branch.py`. <!-- cite-exempt: naming the removed script and its retired gate is the entry — the path is deliberately gone as of this change -->
