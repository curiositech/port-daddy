- **Binary media now routes to Git LFS repo-wide instead of from three directory-scoped globs that missed every large file in the tree.** `.gitattributes` previously sent only `whitepaper-foundlings/**` and `skill_candidates/**` to LFS — 409 files and 139.8 MiB — while 2,378 other media files carried 767.8 MiB as ordinary git blobs, and not one of the 25 largest files in `HEAD` matched any of those globs. Ten bare `*.ext` rules now make the default correct wherever a file lands, with the two trees a build actually reads (`website-v2/public/`, `core/pd-console/`) explicitly exempted so a Pages deploy can never ship a pointer file in place of a PDF. The rules govern future writes only; no existing blob is rewritten. `.gitignore` also closes the trailing-slash gap that let a `node_modules` **symlink** be committed as an absolute path, and covers LaTeX intermediates repo-wide.
