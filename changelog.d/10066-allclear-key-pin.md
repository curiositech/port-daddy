- **The ALL-CLEAR trust root is a committed pin, not a file under `~/.port-daddy` (ADR-0132 §4, follow-up to #10052).** `~/.port-daddy/operator-allclear.pub` is writable by the same user every agent runs as, so on its own it proved nothing: a process could mint a keypair, plant its public half, and sign a lift with no TTY. `lib/distress-allclear.ts` now trusts only keys whose fingerprint is listed in the git-tracked `lib/distress-allclear-pins.ts`; an on-disk `.pub` that matches no pin is inert, the halt stays in force, and `KEY_ROTATED` is written to the ADR-0089 forensics journal as critical on every read path (`readHaltState`, `applyAllClear`, `liftHalt`). A pin that carries the SPKI PEM verifies with no `.pub` on disk at all. The pin set ships empty, so no halt can be lifted until the operator runs `keygen` and commits the entry it prints; `status` reports which key the build trusts. Tests and the phase-6 drill trust a throwaway key through an explicit `trustedKeys` option — no env var, no flag.
