- **pd-console's Cloud Fleet pane now shows each ship's raw model conversation — pd-transcript.v1 Phase 4** (`docs/FLEET-SESSION-TRANSCRIPTS.md`). A new "Raw Ship Sessions" section renders the selected run's transcript LEDGER (every captured ship/attempt with turns, token totals, cost, and the `INCOMPLETE` flag — token columns say `tokens not reported` rather than a lying `0/0`) and the shown session's turns as chat blocks: system/user prompts fold to a one-line summary exactly like the web viewer's `<details>`, the assistant's words render open, error turns paint Conflicted with an explicit `TRUNCATED` badge, and malformed lines are skipped WITH a counted notice — never silently. Data flows through the Phase 3 machine surfaces (`transcripts.json` + `.jsonl?attempt=N`) under the pane's existing operator bearer, the relay's uniform 404 renders as the honest "no captured sessions yet — a ship's transcript flushes when it completes" status, and a loaded session is memoized by (run, ship, attempt) since capture flushes once at completion — the poll loop never refetches immutable bytes. Render-agnostic by construction (the GPUI, ratatui, and offscreen-PNG faces paint the same `Block`s); Block-raster proofs committed under `core/pd-console/docs/artifacts/cloud-fleet-transcript/`.
