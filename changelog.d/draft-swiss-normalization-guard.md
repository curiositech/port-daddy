- **A Swiss normalization ratchet guards `website-v2/src/{components,pages}/**` against drift from the Book's Swiss visual system.** `scripts/check-swiss-normalization.mjs` scans every in-scope `.tsx`/`.ts`/`.css` file for a stray colour literal (hex or an `rgb`/`hsl`/`oklch`-family function, outside the token layers), a `rounded-*` class or `border-radius`, and elevation/blur/gradient (`shadow-*`, `box-shadow`, `backdrop-blur`, `bg-gradient-*`, `linear-/radial-/conic-gradient`) — with the false-positive suppressions the rules need (`#abc` in an `href`, `shadow-none`, `border-radius: 0`) and a `swiss-allow: <rule> — <reason>` escape hatch for genuine system primitives (a bare `swiss-allow` with no real reason is itself a failure). It's a ratchet, not a gate: `website-v2/scripts/swiss-normalization-ratchet.json` records today's known drift and the build fails only on a new violation, a listed file getting worse, or a listed file improving without its ratchet entry being updated to match — so the list can only shrink. New CI job `swiss-normalization-guard`.
