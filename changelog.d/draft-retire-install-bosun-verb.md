type: removed

- **`pd install-bosun` is retired as a public verb.** Bosun (`pd-bosun`, ADR-0036) is an optional legacy watchdog, and since v3.28 a supported install has exactly one lifecycle supervisor — Homebrew launchd on macOS, or the installed LaunchAgent/systemd service elsewhere — plus the daemon's own heartbeat writer. The release archives and the Homebrew `post_install` deliberately do not install Bosun, so the verb invited operators to wire a supervisor the supported install does not want. It is gone from the dispatcher, all three shell completions (bash/zsh/fish), `features.manifest.json`, and the compiled-CLI surface sweep; `pd install-bosun` now answers `Unknown command`. The installer-internal entry point (`install-daemon.ts install-bosun`) is unchanged and still available to the packaging flows that call it, and `pd doctor` still reports Bosun's presence or absence as context. `tests/unit/no-legacy-bosun-command.test.js` ratchets the public surfaces so the verb cannot quietly return.
