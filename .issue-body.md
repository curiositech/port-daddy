## Contradiction in one sentence

The README quick start (lines 30-40) shows `pd done "Auth complete"` succeeding with a bare note, but the actual CLI requires result notes to include a PR URL, "no-pr-yet: <reason>", or "not-applicable: <reason>" — plus the branch must be pushed to origin.

## Source of truth

- **Code (requirements):** `lib/git-origin-check.ts` lines 1-22, `cli/commands/sugar.ts` (handleDone)
- **Docs (wrong claim):** `README.md` lines 38-39 show bare note example

## Reproduction

```bash
pd begin "Test" --identity test:api --lifecycle durable
pd done "Auth complete"
# Fails with:
#   Result note must include one of:
#   - A PR URL
#   - no-pr-yet: <reason>
#   - not-applicable: <reason>
# Plus: Branch has no upstream — nothing has been pushed.
```

## Proposed fix

Update the README quick start example to show the actual working command:

```bash
pd done "Result: no-pr-yet: demo only"
```

OR add a disclaimer that the bare-note example requires special flags (`--skip-origin-check --reason`).
