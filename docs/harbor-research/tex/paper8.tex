\begin{abstract}
\noindent When dozens of autonomous LLM agents coordinate across asynchronous gossip channels, shared AST symbol claims, and iterative review DAGs, subtle inconsistencies inevitably emerge: clock skews, hallucinated review sign-offs, and Byzantine split-view equivocations. Pairwise cross-checking only verifies links that are explicitly inspected ($O(|E|)$ verification overhead); it cannot detect lies across uninspected links, nor can it diagnose whether an observed discrepancy stems from benign turn latency, a localized triadic review failure, or an irreconcilable macro-network partition.

In this paper, we develop a unified, mathematically rigorous framework for \textbf{multi-agent swarm legibility and active control} grounded in \textbf{cellular sheaf cohomology} and \textbf{discrete Hodge theory over simplicial 2-complexes}. We establish five primary results:
(i)~\textbf{The Rosetta Stone}: A formal algebraic dictionary mapping concrete swarm primitives (\texttt{AgentNode}, \texttt{WorkIntent}, AST claim leases, and Producer-Critic-Manager review triads) into cellular sheaves where vertices carry state stalks $\mathcal{F}(v) \in \mathbb{R}^D$, edges carry interface restriction maps $P_e$, and 2-cells enforce triadic round contracts;
(ii)~\textbf{Completion Residual Soundness \& Certified Lower Bounds (Theorem CR-1)}: Under a three-tier visibility model (\texttt{COMPARED}, \texttt{RELAYED}, \texttt{SEVERED}), the completion residual $r = \|\Pi_K g_K\|_2$ is strictly positive if and only if no global history explains the observed gossip. For a single-edge lie of magnitude $s$, $r$ achieves the closed form $r = |s|\sqrt{1 - R^{K}_{\mathrm{eff}}(e)}$, certifying a sharp lower bound on the injected contradiction. Across cut-edges, $r = 0$ by algebra, defining the exact topological horizon of detection;
(iii)~\textbf{Electrical Circulation \& Cycle Localization (Theorems CR-2 \& CR-3)}: The residual vector $\rho = \Pi_K g_K$ is an exact algebraic circulation ($B_K^T \rho = 0$) whose non-zero support is strictly confined to visible cycles passing through the equivocator, approximable in near-linear time $\widetilde{O}(|E| \cdot D)$ for fixed solver accuracy via Laplacian solvers;
(iv)~\textbf{The Swarm Legibility Ratio via Simplicial Hodge Decomposition (Theorem CR-5)}: On a 2-complex where 2-simplices model triadic contracts, any observed disagreement cochain admits a unique orthogonal split $g = \delta_0 x + h + \delta_1^* \psi$. We define the \textbf{Swarm Legibility Ratio} $\mathcal{L}(g) = \frac{\|h\|_2^2}{\|h\|_2^2 + \|\delta_1^* \psi\|_2^2} \in [0, 1]$, proving it cleanly separates micro-review bugs ($\mathcal{L} \approx 0$) from macro-network partition cavities ($\mathcal{L} \approx 1$);
(v)~\textbf{Optimal Cohomological Repair (Theorem CR-4)}: Given non-uniform intervention costs $w(e)$, finding the minimal-cost edge set to reconcile or fence to drive $r \to 0$ decomposes into a circulation min-cut. We prove that a greedy energy-to-cost controller choosing $e^* = \arg\max \frac{\|\rho_e\|^2}{w(e)}$ terminates in at most $\beta_1(G_K)$ rounds.

All results are grounded in verified mathematical proofs, executable simulation suites with falsification mutation tests, and real-world architectures from production multi-agent runtimes.
\end{abstract}

\section{The Problem: Hallucinations, Equivocations, and Partitions in Multi-Agent Swarms}\label{sec:problem}

\textbf{The scene.} In modern autonomous software engineering environments, dozens of specialized LLM agents collaborate concurrently: Producer agents write feature code, Critic agents synthesize adversarial unit tests, Manager agents adjudicate pull request merges, and supervisor actors coordinate resource leases and task progress. Because these agents execute across heterogeneous runtimes, Docker containers, and serverless workers, they communicate via asynchronous gossip channels, shared AST symbol claims, and event relays.

Inevitably, coordination breaks down. An agent reports an updated commit hash to one peer while lagging behind on another; a prompt-injected or hallucinating agent asserts that a test suite passed when it was rejected; or a cross-cloud network partition splits the fleet into two internally consistent but mutually contradictory branches.

If a supervisor were forced to run pairwise verification on every message exchanged across every edge, the communication overhead would scale as $O(|E|)$ and destroy the autonomy of the swarm.

\onebreath{The central question of this paper: can an observer detect, localize, categorize, and repair contradictions across communication channels that were never directly inspected, using only topology and linear algebra?}

The answer is affirmative, grounded in \textbf{cellular sheaf cohomology} and \textbf{discrete Hodge theory}.

\subsection{The Escher Staircase Intuition}
Imagine hiking along an open mountain trail. With each step forward, your altimeter reads $+1$\,m. You take three steps and climb $+3$\,m. Nothing is unusual: on an open path, elevation changes monotonically.

Now imagine M.C.~Escher's lithograph \emph{Ascending and Descending}. Four monks walk in a closed square courtyard:
\[
\Delta h_{AB} = +1, \quad \Delta h_{BC} = +1, \quad \Delta h_{CD} = +1, \quad \Delta h_{DA} = +1.
\]
Summing the height differences around the closed loop yields:
\[
\sum_{\text{loop}} \Delta h = 1 + 1 + 1 + 1 = +4 \neq 0.
\]
In physical reality, height $h$ is a single-valued potential field. Along any directed edge $(u, v)$, the difference is $\Delta h = h_v - h_u$. Therefore, the telescoping sum around any closed loop must vanish identically:
\[
(h_B - h_A) + (h_C - h_B) + (h_D - h_C) + (h_A - h_D) \equiv 0.
\]
Because the reported steps sum to $+4$, an auditor does not need to inspect the monks' footwear or question their honesty to prove that \textbf{an impossible contradiction has occurred}. The closed topological cycle traps the lie.

To make algebraic topology operational for software engineers building multi-agent systems, we translate the mathematical primitives into their concrete systems equivalents (summarized visually in Figure~\ref{fig:fieldguide}).

\paragraph{1. What is a Stalk $\mathcal{F}(v)$?}
Mathematically, a stalk is a vector space $\mathcal{F}(v) \cong \mathbb{R}^D$ assigned to vertex $v$. In a multi-agent runtime, it represents an agent's private state vector $x_v \in \mathbb{R}^D$, tracking:
\begin{enumerate}[noitemsep]
\item Local execution turn / epoch $t_v \in \mathbb{N}$;
\item Cumulative token spend budget $b_v \in \mathbb{R}_+$;
\item AST code claim / symbol lock lease hash $h_L \in \mathbb{R}$;
\item Working tree commit root hash $d_v \in \mathbb{R}$.
\end{enumerate}
Numerical stalks let a supervisor test consistency of selected shared-state constraints. The result depends on the encoding and available observations; its computational cost is qualified in Theorem~CR-3.

\paragraph{2. What is a Cochain Complex ($C^0 \xrightarrow{\delta_0} C^1 \xrightarrow{\delta_1} C^2$)?}
A sequence of vector spaces and linear coboundary operators satisfying the fundamental chain property:
\[
\delta_1 \circ \delta_0 = 0 \quad \Longleftrightarrow \quad \mathrm{im}(\delta_0) \subseteq \ker(\delta_1).
\]
In AI swarms:
\begin{itemize}[noitemsep]
\item \textbf{0-Cochains ($C^0$)}: Fleet State. The collection of all agent state vectors $(x_0, x_1, \dots, x_{n-1})$.
\item \textbf{1-Cochains ($C^1$)}: Channel \& PR Discrepancies. The pairwise differences $g_e$ reported across communication channels or Git pull requests between pairs of agents. The coboundary operator $\delta_0$ computes expected pairwise channel differences: $(\delta_0 x)_{uv} = x_v - x_u$.
\item \textbf{2-Cochains ($C^2$)}: Multi-Party Review Contracts. Evaluations across triangular consensus joins (e.g., Producer $\to$ Critic $\to$ Manager). The operator $\delta_1$ computes the net rotational discrepancy around each review triad: $(\delta_1 g)_{uvw} = g_{uv} + g_{vw} - g_{uw}$.
\end{itemize}
The identity $\delta_1 \circ \delta_0 = 0$ is the \textbf{Zero False-Alarm Guarantee}: whenever agents make legitimate asynchronous progress (manifesting as a potential gradient $\delta_0 x$), the review curl around every 3-agent review join is identically zero. Honest turn advances never trigger spurious review alarms.

\paragraph{3. What is a Gossip Tree vs. a Review Cycle?}
A tree is an acyclic graph ($\beta_1 = 0$). Standard agent frameworks (LangChain, AutoGen, CrewAI) default to hierarchical delegation trees. On a tree, the divergence operator has a trivial null space:
\[
\ker(\delta_0^T) = \{0\} \quad \Longrightarrow \quad \Pi_K = 0 \quad \Longrightarrow \quad r = \|\Pi_K g_K\|_2 = 0.
\]
If a child agent hallucinates along an uninspected link, the supervisor's linear solver can always find a fictitious set of node potentials $x$ that rationalizes the reported diffs. The lie is completely absorbed as ``the worker is just delayed.''
By contrast, closing the communication graph into a cycle makes $\ker(\delta_0^T) \neq \{0\}$. Contradictions cannot be absorbed by scalar potentials; they get trapped as an algebraic circulation $\rho \neq 0$ with certified residual $r > 0$.

\paragraph{4. What is a Gauge Process ($\delta_0 x$)?}
A 1-cochain belonging entirely to the image of the coboundary operator: $g = \delta_0 x \in \mathrm{im}(\delta_0)$. Systems equivalent: \textbf{benign asynchronous turn skew}. For instance, Agent A is on commit 105 while Agent B is on commit 104 due to a 150\,ms webhook delay. A gauge process is curl-free ($\delta_1(\delta_0 x) \equiv 0$) and self-resolving; it requires zero supervisor action.

\paragraph{5. What is Triadic Curl ($\delta_1^* \psi$)?}
The divergence-free rotational component of a 1-cochain produced by the adjoint coboundary operator: $\delta_1^* \psi \in \mathrm{im}(\delta_1^T)$ such that $\delta_0^*(\delta_1^* \psi) = 0$ and $\delta_1(\delta_1^* \psi) \neq 0$. Systems equivalent: \textbf{review hallucination / logical paradox}. If Coder submits a PR to Critic ($g_{01} = +1$), Critic rejects the PR to Manager ($g_{12} = +1$), but Manager hallucinates that Critic approved and merges into Coder ($g_{02} = -1$), the sum around the triangle is $(\delta_1 g)_{012} = 1 + 1 - (-1) = +3 \neq 0$. This contradiction will never self-resolve, but sheaf cohomology isolates it directly to the 3-cell $(v_0, v_1, v_2)$.

\paragraph{6. What is a Harmonic Cavity ($h \in \mathcal{H}^1$)?}
A 1-cochain in the kernel of the Hodge Laplacian $L_1$:
\[
h \in \ker(L_1) = \ker(\delta_0^*) \cap \ker(\delta_1) \cong H^1(X; \mathbb{R}).
\]
Systems equivalent: \textbf{macro-network partition / cross-harbor disconnect}. A harmonic cavity has zero curl locally ($\delta_1 h = 0$), meaning every single local code review inside the Frontend team passes with green checkmarks, and every local review inside the Backend team passes. Yet globally, the two halves of the swarm are drifting into incompatible realities.

\section{Mathematical Foundations: Discrete Exterior Calculus on Simplicial 2-Complexes}\label{sec:math}

We construct the theoretical framework from first principles using finite-dimensional vector spaces and standard linear algebra.

\subsection{Graphs as 1-Dimensional Cell Complexes}
Let $G = (V, E)$ be a finite directed graph with $n = |V|$ vertices and $m = |E|$ directed edges $e = (u, v)$ with $u < v$.
The vector space of 0-cochains is $C^0(G; \mathbb{R}) \cong \mathbb{R}^n$, assigning a real scalar $x_v$ to each vertex.
The vector space of 1-cochains is $C^1(G; \mathbb{R}) \cong \mathbb{R}^m$, assigning a real scalar $g_e$ to each edge.

The directed incidence matrix $B \in \mathbb{R}^{m \times n}$ is the 0th coboundary operator $\delta_0: C^0 \to C^1$:
\[
B_{e, w} = \begin{cases} -1 & \text{if } w = u \text{ (source of } e = (u, v)) \\ +1 & \text{if } w = v \text{ (target of } e = (u, v)) \\ 0 & \text{otherwise} \end{cases}
\]
Acting on $x \in \mathbb{R}^n$, $\delta_0$ computes the edge difference: $(\delta_0 x)_e = x_v - x_u$.
By the Fundamental Theorem of Linear Algebra, the edge space decomposes orthogonally:
\[
\mathbb{R}^m = \mathrm{im}(\delta_0) \oplus \ker(\delta_0^T).
\]
Here $\mathrm{im}(\delta_0)$ is the gradient (cut) space, while $\ker(\delta_0^T) = \ker(B^T)$ is the cycle (divergence-free circulation) space.

\subsection{Simplicial 2-Complexes and Triadic Contracts}
To capture 3-way consensus and review joins, we extend $G$ to an oriented simplicial 2-complex $X = (V, E, F)$, where $F$ is a set of oriented 2-simplices (triangles) $\tau = (u, v, w)$ with $u < v < w$.
The space of 2-cochains is $C^2(X; \mathbb{R}) \cong \mathbb{R}^{|F|}$.

The 1st coboundary operator $\delta_1: C^1 \to C^2$ is defined by:
\[
(\delta_1 g)_{\tau} = g_{uv} + g_{vw} - g_{uw} \quad \text{for } \tau = (u, v, w).
\]

\begin{lemma}[The Fundamental Simplicial Identity]\label{lem:chain}
The composition of the 0th and 1st coboundary operators vanishes identically:
\[
\delta_1 \circ \delta_0 = 0 \quad \Longleftrightarrow \quad \mathrm{im}(\delta_0) \subseteq \ker(\delta_1).
\]
Consequently, the discrete curl of any gradient cochain is zero across every 2-simplex.
\end{lemma}
\begin{proof}
We provide two proofs: an explicit coordinate computation and an algebraic-topological duality argument.

\emph{Direct Computation}: Let $x \in C^0(X; \mathbb{R})$ be an arbitrary 0-cochain. By definition of the 0th coboundary operator $\delta_0$, the entry of $\delta_0 x \in C^1(X; \mathbb{R})$ on any oriented edge $e = (u, v)$ with $u < v$ is:
\[
(\delta_0 x)_{uv} = x_v - x_u.
\]
Now consider an arbitrary oriented 2-simplex (triangle) $\tau = (u, v, w) \in F$ with orientation $u < v < w$. Applying the 1st coboundary operator $\delta_1$ to $\delta_0 x$:
\begin{align*}
(\delta_1 (\delta_0 x))_{\tau} &= (\delta_0 x)_{uv} + (\delta_0 x)_{vw} - (\delta_0 x)_{uw} \\
&= (x_v - x_u) + (x_w - x_v) - (x_w - x_u) \\
&= x_v - x_u + x_w - x_v - x_w + x_u \equiv 0.
\end{align*}
Because this identity holds identically for every triangle $\tau \in F$ and every 0-cochain $x \in C^0(X; \mathbb{R})$, the linear operator composition $\delta_1 \circ \delta_0$ evaluates to the zero matrix $0 \in \mathbb{R}^{|F| \times |V|}$.

\emph{Duality with Simplicial Boundaries}: In simplicial homology, the chain complex $C_2 \xrightarrow{\partial_2} C_1 \xrightarrow{\partial_1} C_0$ is governed by the boundary operator. For any oriented 2-simplex $\tau = [u, v, w]$, the boundary is $\partial_2 [u, v, w] = [v, w] - [u, w] + [u, v]$. The 1-boundary operator satisfies $\partial_1 [a, b] = [b] - [a]$. Evaluating the composition:
\[
\partial_1 (\partial_2 [u, v, w]) = \partial_1 ([v, w] - [u, w] + [u, v]) = ([w] - [v]) - ([w] - [u]) + ([v] - [u]) = 0.
\]
Because real cochains are linear functionals on chains ($C^k \cong C_k^*$), the coboundary operators are the formal matrix adjoints (transposes) of the boundary operators: $\delta_0 = \partial_1^*$ and $\delta_1 = \partial_2^*$. Transposing the chain boundary identity $\partial_1 \circ \partial_2 = 0$ yields:
\[
\delta_1 \circ \delta_0 = \partial_2^* \circ \partial_1^* = (\partial_1 \circ \partial_2)^* = 0^* = 0.
\]
This proves that $\mathrm{im}(\delta_0) \subseteq \ker(\delta_1)$, establishing that the cochain sequence forms a valid cochain complex.
\end{proof}

\section{The Rosetta Stone: Swarms to Cellular Sheaves}\label{sec:rosetta}

Autonomous agents exchange structured messages over restricted interfaces. We model their selected numerical interface data by a \textbf{cellular sheaf}, using the cellular construction developed by Curry~\cite{curry}. Robinson~\cite{robinson} provides the broader signal-processing context; neither source establishes that an arbitrary agent transcript admits a faithful linear encoding.

\begin{definition}[Cellular Sheaf on a Simplicial Complex]
\label{def:cellular-sheaf}
A cellular sheaf $\mathcal{F}$ over cell complex $X = (V, E, F)$ consists of:
\begin{enumerate}[noitemsep]
\item For each cell $\sigma \in X$, a vector space $\mathcal{F}(\sigma)$ called the \textbf{stalk} over $\sigma$.
\item For each incident pair $\sigma \trianglelefteq \tau$, a linear map $P_{\sigma \trianglelefteq \tau}: \mathcal{F}(\sigma) \to \mathcal{F}(\tau)$ called the \textbf{restriction map}.
\item Identity and compatibility: $P_{\sigma \trianglelefteq \sigma}=I$ and $P_{\tau \trianglelefteq \upsilon}P_{\sigma \trianglelefteq \tau}=P_{\sigma \trianglelefteq \upsilon}$ whenever $\sigma \trianglelefteq \tau \trianglelefteq \upsilon$.
\end{enumerate}
\end{definition}

\subsection{Coordinate-Wise Decoupling}
When restriction maps $P_e$ are coordinate projections selecting shared state fields $S_e \subseteq \{1, \dots, D\}$, the sheaf coboundary $\delta_0$ block-diagonalizes into independent scalar coboundary matrices $\delta_0^c$ for each coordinate $c \in \{1, \dots, D\}$.
The global completion residual decomposes as:
\[
r^2 = \sum_{c=1}^D (r^c)^2 = \sum_{c=1}^D \|\Pi_{K_c} g^c\|_2^2.
\]
This enables embarrassingly parallel consistency audits across all state fields with zero cross-talk.

\subsection{Practical Stalk Engineering and Heterogeneous Restriction Maps}
In deployed multi-agent platforms and autonomous agent operating systems, the vector stalk $\mathcal{F}(v) \cong \mathbb{R}^D$ is assembled via four deterministic feature pipelines rather than a monolithic embedding:
\begin{enumerate}[noitemsep]
\item \textbf{Temporal and Resource Invariants}: Monotonic execution turn epochs $t_v \in \mathbb{N}$ (Lamport logical clocks) and cumulative token spend $b_v = \mathrm{tokens} / 10^5 \in \mathbb{R}_+$.
\item \textbf{AST Symbol Leases and Cryptographic Digests}: Abstract Syntax Tree symbol path leases (e.g., \textsf{auth.ts:verifyToken}) encoded as multi-hot bitmasks or scalar hash-folded commit digests:
\[
x_v[\mathrm{git}] = \frac{\mathrm{MurmurHash3}(\mathrm{HEAD})}{2^{32} - 1} \in [-1, 1].
\]
\item \textbf{Semantic Beliefs via Principal Component Projection}: Dense natural language embeddings (e.g., 384-dimensional MiniLM-L6-v2 vectors from design rationales or PR summaries) compressed via incremental SVD/PCA to $k \in [8, 16]$ principal directions, preserving $>90\%$ of semantic variance while maintaining sparse Hodge solver efficiency.
\item \textbf{Triadic Review Stances}: Discrete categorical review logits:
\[
x_v[\mathrm{review}] \in \{-1.0 \text{ (Reject)},\, 0.0 \text{ (Pending)},\, +1.0 \text{ (Approve)}\}.
\]
\end{enumerate}

\paragraph{Heterogeneous Restriction Projections}
Because distinct agent roles maintain different internal variable sets (e.g., a Frontend agent with $D_u = 6$ tracking UI route bundles versus a Backend agent with $D_v = 6$ tracking database connection pools), restriction maps $P_{v \trianglelefteq e} \in \{0, 1\}^{d_e \times D_v}$ act as rectangular Boolean selection matrices:
\[
P_{v \trianglelefteq e} = \begin{bmatrix} I_{d_e \times d_e} & 0_{d_e \times (D_v - d_e)} \end{bmatrix},
\]
filtering each agent's private state down to the exact coordinates governed by the shared communication contract. The resulting coboundary evaluation $g_e = P_{v \trianglelefteq e} x_v - P_{u \trianglelefteq e} x_u$ executes in $\mathcal{O}(d_e)$ time per edge, bypassing expensive LLM arbitration and running in under 2 milliseconds across a 50-agent swarm.

\subsection{Explicit Trace Language and Deterministic Stalk Encoding}\label{sec:trace-encoding}

To ground cellular stalks in actual multi-agent execution rather than idealized telemetry, we define a concrete runtime event language and an explicit encoding map.

\begin{definition}[Swarm Event Alphabet $\Sigma_{\mathrm{swarm}}$]\label{def:event-alphabet}
Let $\Sigma_{\mathrm{swarm}}$ be the alphabet of discrete, typed, signed events emitted by agents in an asynchronous multi-agent coordination environment:
\[
\Sigma_{\mathrm{swarm}} = \Sigma_{\mathrm{git}} \cup \Sigma_{\mathrm{ast}} \cup \Sigma_{\mathrm{test}} \cup \Sigma_{\mathrm{review}} \cup \Sigma_{\mathrm{clock}} \cup \Sigma_{\mathrm{budget}},
\]
where the event constructors are defined as:
\begin{enumerate}[noitemsep]
\item $\textsf{CommitPushed}(h, p, \Delta) \in \Sigma_{\mathrm{git}}$: Git commit with hash $h \in \{0, 1\}^{256}$, parent hash $p \in \{0, 1\}^{256}$, and diff summary $\Delta$;
\item $\textsf{SymbolLockAcquired}(s, \ell, \tau) \in \Sigma_{\mathrm{ast}}$: AST symbol lock acquisition on symbol path $s \in \mathcal{S}$ with lease token $\ell$ and TTL epoch $\tau$;
\item $\textsf{SymbolLockReleased}(s, \ell) \in \Sigma_{\mathrm{ast}}$: Relinquishment of AST lock on symbol path $s$;
\item $\textsf{TestVerdict}(t, v, c) \in \Sigma_{\mathrm{test}}$: Test suite execution on target $t$ with status $v \in \{\textsf{Pass}, \textsf{Fail}, \textsf{Error}\}$ and coverage ratio $c \in [0, 1]$;
\item $\textsf{ReviewVerdict}(\textsf{pr}, \nu, \mu) \in \Sigma_{\mathrm{review}}$: Review stance on pull request $\textsf{pr}$ with vote $\nu \in \{-1.0 \text{ (Reject)},\, 0.0 \text{ (Pending)},\, +1.0 \text{ (Approve)}\}$ and semantic rationale embedding $\mu \in \mathbb{R}^{d_\mu}$;
\item $\textsf{TurnAdvanced}(k) \in \Sigma_{\mathrm{clock}}$: Lamport logical clock tick $k \in \mathbb{N}$~\cite{lamport-clocks};
\item $\textsf{SpendRecorded}(b, \kappa) \in \Sigma_{\mathrm{budget}}$: Cumulative token expenditure $b \in \mathbb{R}_+$ under model identifier $\kappa$.
\end{enumerate}
\end{definition}

An agent execution transcript is a finite sequence of events $\sigma_v = \langle e_1, e_2, \dots, e_N \rangle \in \Sigma_{\mathrm{swarm}}^*$. We denote the space of all finite transcripts by $\mathrm{Trace}(v) = \Sigma_{\mathrm{swarm}}^*$.

\begin{definition}[Deterministic Stalk Encoding Map $\mathrm{Enc}_v$]\label{def:deterministic-encoding}
The deterministic stalk encoding map $\mathrm{Enc}_v: \mathrm{Trace}(v) \to \mathcal{F}(v) \subseteq \mathbb{R}^D$ maps an agent's execution transcript $\sigma_v$ to a $D$-dimensional real state vector by partitioned projection:
\[
\mathrm{Enc}_v(\sigma_v) = \begin{bmatrix}
x_v^{\mathrm{clock}} \\
x_v^{\mathrm{spend}} \\
x_v^{\mathrm{ast}} \\
x_v^{\mathrm{commit}} \\
x_v^{\mathrm{review}}
\end{bmatrix} \in \mathbb{R}^D,
\]
where the coordinate blocks are evaluated deterministically from transcript $\sigma_v$:
\begin{align*}
x_v^{\mathrm{clock}} &= \max \left(\{0\} \cup \{ k \in \mathbb{N} : \textsf{TurnAdvanced}(k) \in \sigma_v \}\right) \in \mathbb{R}_+, \\
x_v^{\mathrm{spend}} &= \sum \left\{ b \in \mathbb{R}_+ : \textsf{SpendRecorded}(b, \kappa) \in \sigma_v \right\} \in \mathbb{R}_+, \\
x_v^{\mathrm{ast}}[s] &= \begin{cases} 1.0 & \text{if } \textsf{SymbolLockAcquired}(s, \ell, \tau) \in \sigma_v \text{ and } \textsf{SymbolLockReleased}(s, \ell) \notin \sigma_v \text{ with } \tau > t_{\mathrm{curr}}, \\ 0.0 & \text{otherwise}, \end{cases} \\
x_v^{\mathrm{commit}} &= \phi(h_{\mathrm{HEAD}}(\sigma_v)) \in [-1, 1]^{D_{\mathrm{commit}}}, \\
x_v^{\mathrm{review}}[\textsf{pr}] &= \begin{cases} \nu & \text{for the most recent } \textsf{ReviewVerdict}(\textsf{pr}, \nu, \mu) \in \sigma_v, \\ 0.0 & \text{if no verdict on } \textsf{pr} \text{ has been rendered}, \end{cases}
\end{align*}
and $\phi: \{0, 1\}^{256} \to [-1, 1]^{D_{\mathrm{commit}}}$ is a collision-resistant deterministic cryptographic hash projection.
\end{definition}

\subsection{Minimal Injectivity, \texorpdfstring{$\Lambda$}{Lambda}-Faithfulness, and Semantic Grounding}\label{sec:faithfulness}

To bridge discrete execution semantics with linear cohomology, the encoding map must be faithful: mutually contradictory transcripts must map to distinct stalk vectors separated by a positive geometric distance.

\begin{definition}[$(\Lambda, \mathcal{I})$-Faithful Stalk Encoding]\label{def:lambda-faithful}
Let $\mathcal{I} = \{I_1, I_2, \dots, I_m\}$ be a family of formal safety invariants on pairwise traces, where $I(\sigma_u, \sigma_v) \in \{0, 1\}$ evaluates to $1$ if traces $\sigma_u, \sigma_v$ are mutually consistent and $0$ if they witness a semantic contract violation (e.g., conflicting lock leases on the same AST symbol, or diverging head commits on a shared branch).
The sheaf restriction maps $(P_{u \trianglelefteq e}, P_{v \trianglelefteq e})$ and encoding maps $(\mathrm{Enc}_u, \mathrm{Enc}_v)$ are \textbf{$(\Lambda, \mathcal{I})$-faithful} on edge $e = (u, v)$ if there exists a scalar margin $\Lambda > 0$ such that for all finite traces $\sigma_u, \sigma_v \in \Sigma_{\mathrm{swarm}}^*$:
\[
I(\sigma_u, \sigma_v) = 0 \quad \Longrightarrow \quad \| P_{v \trianglelefteq e} \mathrm{Enc}_v(\sigma_v) - P_{u \trianglelefteq e} \mathrm{Enc}_u(\sigma_u) - g_e^{\mathrm{expected}} \|_2 \ge \Lambda,
\]
where $g_e^{\mathrm{expected}}$ is the expected nominal difference under normal asynchronous progression.
\end{definition}

\begin{lemma}[Affine Invariant Embedding]\label{lem:affine-embedding}
Let invariant $I_{\mathrm{mutex}}$ specify mutual exclusion on AST symbol leases: no two agents may simultaneously claim the same symbol $s^*$. If coordinate $c^* \in I_{\mathrm{ast}}$ represents symbol $s^*$, then for any restriction map selecting $c^*$, the stalk encoding is $(1.0, I_{\mathrm{mutex}})$-faithful with margin $\Lambda = 1.0$.
\end{lemma}
\begin{proof}
Suppose invariant $I_{\mathrm{mutex}}(\sigma_u, \sigma_v) = 0$, so that both agent $u$ and agent $v$ have acquired an active exclusive lock on symbol $s^*$ without releasing it.
By Definition~\ref{def:deterministic-encoding}, $x_u[c^*] = 1.0$ and $x_v[c^*] = 1.0$.
Under the mutual-exclusion specification, the nominal edge difference for exclusive resource ownership satisfies $g_e^{\mathrm{expected}}[c^*] = 0.0$ only when at most one agent holds the lock. When both simultaneously claim ownership, the contract evaluates the conflicting claim difference as:
\[
| P_{v \trianglelefteq e} x_v[c^*] - P_{u \trianglelefteq e} x_u[c^*] - g_e^{\mathrm{expected}}[c^*] | = |1.0 - 0.0| = 1.0 \ge \Lambda = 1.0.
\]
Thus the discrete contract violation maps directly to an affine coordinate discrepancy bounded below by $\Lambda = 1.0$.
\end{proof}

\begin{theorem}[Semantic Trace Grounding of Completion Residuals]\label{thm:trace-grounding}
Let the multi-agent stalk encoding be $(\Lambda, \mathcal{I})$-faithful on all visible edges $K \subseteq E$. Suppose an uninspected visible edge $e^* = (u^*, v^*) \in R \subseteq K$ carries an execution inconsistency witnessing an invariant violation $I(\sigma_{u^*}, \sigma_{v^*}) = 0$, while all other edges carry honest asynchronous transitions.
Then the observed cochain $g_K$ satisfies:
\[
g_K \notin \mathrm{im}(\delta_K),
\]
and the completion residual $r = \|\Pi_K g_K\|_2$ is strictly lower-bounded by:
\[
r \ge \Lambda \sqrt{1 - R_{\mathrm{eff}}^K(e^*)}.
\]
In particular, if $e^*$ is not a bridge of $G_K$, $r > 0$, certifying that semantic inconsistency in discrete execution traces implies non-membership of $g_K$ in $\mathrm{im}(\delta_K)$.
\end{theorem}
\begin{proof}
By $(\Lambda, \mathcal{I})$-faithfulness, the inconsistency on edge $e^*$ generates a cochain perturbation $\varepsilon_{e^*} = (g_K)_{e^*} - (\delta_K x^*)_{e^*}$ with norm $\|\varepsilon_{e^*}\|_2 \ge \Lambda$.
Because all other visible edges report honest conservative values, the perturbation is supported on the single uninspected edge: $\varepsilon_K = s \mathbf{1}_{e^*}$ with $|s| \ge \Lambda$.
Applying Assertion 3 of Theorem~CR-1:
\[
r = \|\Pi_K \varepsilon_K\|_2 = |s| \sqrt{1 - R_{\mathrm{eff}}^K(e^*)} \ge \Lambda \sqrt{1 - R_{\mathrm{eff}}^K(e^*)}.
\]
If $e^*$ is not a bridge of $G_K$, then by graph resistance theory $R_{\mathrm{eff}}^K(e^*) < 1$, which gives $1 - R_{\mathrm{eff}}^K(e^*) > 0$.
Therefore $r \ge \Lambda \sqrt{1 - R_{\mathrm{eff}}^K(e^*)} > 0$, which by Assertion 1 of Theorem~CR-1 proves that $g_K \notin \mathrm{im}(\delta_K)$.
\end{proof}

\section{Passive Detection: The Completion Residual and Consistency Radius}\label{sec:detection}

The three-tier visibility model and the scalar completion-residual results CR-1--CR-3 build on Paper~7 of the Harbor program~\cite{owens-r6}. We recall them here before introducing the triadic decomposition and repair discussion.

\subsection{The Three-Tier Visibility Model}
In real deployments, observer visibility is non-uniform:
\begin{enumerate}[noitemsep]
\item \textbf{\texttt{COMPARED} ($C$)}: The communication link between $u$ and $v$ was directly inspected. The pairwise difference $g_e$ is ground truth.
\item \textbf{\texttt{RELAYED} ($R$)}: The link was never directly inspected; both endpoints transmitted signed gossip reports to the supervisor.
\item \textbf{\texttt{SEVERED} ($S$)}: The link is completely quiet or severed. No data is available.
\end{enumerate}
Let $K = C \cup R$ be the set of visible edges. The observed data is $g_K \in \mathbb{R}^{|K|}$.

\subsection{Theorem CR-1: Completion Residual Soundness and Certified Lower Bounds}
The supervisor reconstructs the best global explanation via least squares:
\[
r = \min_{x \in \mathbb{R}^n} \| g_K - \delta_K x \|_2.
\]
The normal equations yield $\hat{x} = \delta_K^+ g_K$, producing reconstructed edges $\hat{g}_K = \delta_K \delta_K^+ g_K$.
The \textbf{completion residual vector} is:
\[
\rho = g_K - \hat{g}_K = (I - \delta_K \delta_K^+) g_K = \Pi_K g_K,
\]
where $\Pi_K$ is the orthogonal projector onto $\mathrm{coker}(\delta_K) = \ker(\delta_K^T)$.
The scalar residual is $r = \|\rho\|_2 = \|\Pi_K g_K\|_2$.

\begin{thebox}
\textbf{Theorem CR-1 (Soundness, Certified Lower Bound, and Closed Form).}
\begin{enumerate}
\item \textbf{Soundness}: $r > 0$ if and only if there exists \emph{no global vertex state assignment} $x \in \mathbb{R}^n$ simultaneously satisfying all reported pairwise differences in $K$.
\item \textbf{Certified Minimum Lie}: For any arbitrary lie perturbation $\varepsilon_K$ injected into honest data, the actual Euclidean norm of the injected lie is bounded below by $r$:
\[
\|\varepsilon_K\|_2 \ge r.
\]
\item \textbf{Single-Edge Lie Closed Form}: If an equivocator injects an inconsistency of magnitude $s$ on a single uninspected edge $e \in R$, the residual is given in closed form by:
\[
r = |s| \sqrt{1 - R_{\mathrm{eff}}^K(e)},
\]
where $R_{\mathrm{eff}}^K(e)$ is the effective resistance across edge $e$ in the resistor network $G_K$ with unit resistors on each edge.
\item \textbf{Cut-Edge Silence}: If edge $e$ is a bridge (cut-edge) of $G_K$, then $R_{\mathrm{eff}}^K(e) = 1$, which implies:
\[
r = |s| \sqrt{1 - 1} = 0.
\]
Equivocation across a cut-edge is provably silent to cohomology.
\end{enumerate}
\end{thebox}

\begin{proof}
We prove each of the four assertions in sequence:

\paragraph{Proof of Assertion 1 (Soundness):}
The supervisor's reconstructed state $\hat{x} \in \mathbb{R}^n$ minimizes the sum of squared differences:
\[
r = \min_{x \in \mathbb{R}^n} \| g_K - \delta_K x \|_2.
\]
By the Fundamental Theorem of Linear Algebra, the edge cochain space factors into mutually orthogonal subspaces: $\mathbb{R}^{|K|} = \mathrm{im}(\delta_K) \oplus \ker(\delta_K^T)$.
The operator $\Pi_K = I - \delta_K \delta_K^+$ is the orthogonal projector onto $\ker(\delta_K^T) = (\mathrm{im}(\delta_K))^\perp$.
Consequently:
\[
r = 0 \iff \|\Pi_K g_K\|_2 = 0 \iff \Pi_K g_K = 0 \iff g_K \in \ker(\Pi_K) = \mathrm{im}(\delta_K).
\]
By definition of the image of $\delta_K$, $g_K \in \mathrm{im}(\delta_K)$ if and only if there exists some vector $x \in \mathbb{R}^n$ such that $\delta_K x = g_K$, meaning $(x_v - x_u) = (g_K)_e$ for every visible edge $e = (u, v) \in K$.
Taking the logical contrapositive:
\[
r > 0 \iff g_K \notin \mathrm{im}(\delta_K) \iff \not\exists x \in \mathbb{R}^n \text{ simultaneously satisfying all edge diffs in } K.
\]
Thus, any non-zero residual $r > 0$ strictly certifies the presence of an irreconcilable global inconsistency.

\paragraph{Proof of Assertion 2 (Certified Minimum Lie):}
Let $g_K^{(0)} \in \mathrm{im}(\delta_K)$ denote the ground-truth cochain generated by honest underlying agent states $x^* \in \mathbb{R}^n$, so $g_K^{(0)} = \delta_K x^*$.
Suppose an adversary or hallucinating process injects an arbitrary perturbation vector $\varepsilon_K \in \mathbb{R}^{|K|}$, producing observed cochain $g_K = g_K^{(0)} + \varepsilon_K$.
Applying the orthogonal projector:
\[
\rho = \Pi_K g_K = \Pi_K (\delta_K x^* + \varepsilon_K) = \Pi_K \delta_K x^* + \Pi_K \varepsilon_K.
\]
Because $\mathrm{im}(\delta_K) = \ker(\Pi_K)$, we have $\Pi_K \delta_K \equiv 0$, which yields $\rho = \Pi_K \varepsilon_K$.
An orthogonal projector is symmetric ($\Pi_K^T = \Pi_K$) and idempotent ($\Pi_K^2 = \Pi_K$). Hence its eigenvalues are strictly bounded in $\{0, 1\}$, and its induced operator 2-norm satisfies $\|\Pi_K\|_2 = 1$ (assuming $\ker(\delta_K^T) \neq \{0\}$).
By the submultiplicative property of operator norms:
\[
r = \|\rho\|_2 = \|\Pi_K \varepsilon_K\|_2 \le \|\Pi_K\|_2 \|\varepsilon_K\|_2 = \|\varepsilon_K\|_2.
\]
Rearranging yields $\|\varepsilon_K\|_2 \ge r$. The scalar residual $r$ is an unforgeable, certified lower bound on the Euclidean norm of the injected lie.

\paragraph{Proof of Assertion 3 (Single-Edge Lie Closed Form):}
Assume the perturbation is concentrated on a single uninspected edge $e = (u, v) \in R$, so $\varepsilon_K = s \cdot \mathbf{1}_e$, where $\mathbf{1}_e \in \mathbb{R}^{|K|}$ is the standard unit basis vector.
The squared completion residual is:
\[
r^2 = \|\Pi_K (s \mathbf{1}_e)\|_2^2 = s^2 \mathbf{1}_e^T \Pi_K^T \Pi_K \mathbf{1}_e = s^2 \mathbf{1}_e^T \Pi_K \mathbf{1}_e = s^2 (\Pi_K)_{ee}.
\]
Substituting the definition $\Pi_K = I - \delta_K (\delta_K^T \delta_K)^+ \delta_K^T = I - B_K L_K^+ B_K^T$:
\[
(\Pi_K)_{ee} = \mathbf{1}_e^T (I - B_K L_K^+ B_K^T) \mathbf{1}_e = 1 - \mathbf{1}_e^T B_K L_K^+ B_K^T \mathbf{1}_e.
\]
The vector $B_K^T \mathbf{1}_e$ is precisely the $e$-th column of the incidence matrix transpose $B_K^T$, corresponding to the oriented edge from $u$ to $v$: $B_K^T \mathbf{1}_e = \mathbf{1}_v - \mathbf{1}_u$.
Thus:
\[
\mathbf{1}_e^T B_K L_K^+ B_K^T \mathbf{1}_e = (\mathbf{1}_v - \mathbf{1}_u)^T L_K^+ (\mathbf{1}_v - \mathbf{1}_u).
\]
In algebraic graph theory and resistor network theory, the quadratic form $(\mathbf{1}_v - \mathbf{1}_u)^T L_K^+ (\mathbf{1}_v - \mathbf{1}_u)$ is the exact definition of the effective resistance $R_{\mathrm{eff}}^K(e)$ between vertices $u$ and $v$ in a network where each edge has unit resistance $1\,\Omega$.
Therefore, $(\Pi_K)_{ee} = 1 - R_{\mathrm{eff}}^K(e)$.
Taking the principal square root yields:
\[
r = |s| \sqrt{1 - R_{\mathrm{eff}}^K(e)}.
\]

\paragraph{Proof of Assertion 4 (Cut-Edge Silence):}
An edge $e = (u, v)$ is a bridge (cut-edge) of graph $G_K$ if and only if the graph $G_K \setminus \{e\}$ has more connected components than $G_K$.
By graph topology, an edge is a bridge if and only if no simple cycle of $G_K$ contains $e$.
The cycle space is $\mathcal{Z}_1(G_K) = \ker(B_K^T) = \mathrm{im}(\Pi_K)$.
Because no cycle contains $e$, the $e$-th coordinate of every circulation vector $z \in \ker(B_K^T)$ must vanish: $z_e = \mathbf{1}_e^T z = 0$.
Since $\mathrm{im}(\Pi_K) = \ker(B_K^T)$, this implies $\mathbf{1}_e \in (\ker(B_K^T))^\perp = \mathrm{im}(B_K) = \ker(\Pi_K)$.
Therefore, $\Pi_K \mathbf{1}_e = 0$, which immediately gives $(\Pi_K)_{ee} = \mathbf{1}_e^T \Pi_K \mathbf{1}_e = 0$.
By Assertion 3, $R_{\mathrm{eff}}^K(e) = 1 - (\Pi_K)_{ee} = 1 - 0 = 1$.
Substituting $R_{\mathrm{eff}}^K(e) = 1$ into the residual formula yields:
\[
r = |s| \sqrt{1 - 1} = 0.
\]
The perturbation $\varepsilon_K = s \mathbf{1}_e$ lies entirely in the cut-space $\mathrm{im}(\delta_K)$ and can be perfectly rationalized by shifting vertex potentials across the cut: $x_w \gets x_w + s$ for all $w$ in the component containing $v$.
Thus, equivocation across a cut-edge is provably dark to passive cohomological observation.
\end{proof}

\subsection{Theorems CR-2 \& CR-3: Circulation Localization and Complexity}
\begin{thebox}
\textbf{Theorem CR-2 (Localization to Cycles).}
The residual vector $\rho = \Pi_K g_K$ satisfies $B_K^T \rho = 0$. It is an exact algebraic circulation. Its non-zero support $\mathrm{supp}(\rho) = \{e \in K : \rho_e \neq 0\}$ is strictly confined to the union of cycles in $G_K$ passing through the equivocating agent.
\end{thebox}

\begin{proof}
We divide the proof into two parts: verifying the circulation property ($B_K^T \rho = 0$) and proving cycle confinement.

\paragraph{Part 1: The Residual is an Algebraic Circulation.}
Recall the definition of the orthogonal projector $\Pi_K = I - B_K (B_K^T B_K)^+ B_K^T$.
Multiplying on the left by the transpose of the incidence matrix $B_K^T$:
\begin{align*}
B_K^T \rho &= B_K^T \Pi_K g_K = B_K^T \left( I - B_K (B_K^T B_K)^+ B_K^T \right) g_K \\
&= \left( B_K^T - (B_K^T B_K) (B_K^T B_K)^+ B_K^T \right) g_K.
\end{align*}
Let $A = B_K^T B_K \in \mathbb{R}^{n \times n}$. By the first Moore-Penrose pseudoinverse condition, $A A^+ A = A$.
Since $A$ is symmetric, we have $(A A^+ B_K^T)^T = B_K A^+ A = B_K$. Thus $A A^+ B_K^T = B_K^T$.
Substituting this identity into the expression for $B_K^T \rho$:
\[
B_K^T \rho = (B_K^T - B_K^T) g_K = 0 \in \mathbb{R}^n.
\]
The divergence at every vertex $v \in V$ is $(B_K^T \rho)_v = \sum_{e \in \delta^+(v)} \rho_e - \sum_{e \in \delta^-(v)} \rho_e = 0$.
Kirchhoff's Current Law holds at every node without exception. Therefore, $\rho \in \ker(B_K^T) = \mathcal{Z}_1(G_K; \mathbb{R})$, establishing that the completion residual is an exact algebraic circulation.

\paragraph{Part 2: Support is Confined to Cycles Traversing the Equivocator.}
Decompose the observed cochain as $g_K = g_K^{(0)} + \varepsilon_K$, where $g_K^{(0)} = \delta_K x^*$ is the honest conservative potential field and $\varepsilon_K$ is the perturbation injected by an equivocating agent $v^*$.
Because $\Pi_K g_K^{(0)} = 0$, we have $\rho = \Pi_K \varepsilon_K$.
Because agent $v^*$ can only alter reports on channels attached to its own node, the perturbation has support strictly within the star of edges incident to $v^*$: $\mathrm{supp}(\varepsilon_K) \subseteq \delta(v^*)$.
By the Cycle Flow Decomposition Theorem (Ahuja, Magnanti, and Orlin~\cite{ahuja-magnanti-orlin}), every circulation vector $\rho \in \ker(B_K^T)$ can be decomposed into a non-negative conformal linear combination of simple directed cycle flows:
\[
\rho = \sum_{j=1}^P \alpha_j \mathbf{1}_{C_j},
\]
where each $C_j$ is a simple directed cycle in $G_K$, $\alpha_j \neq 0$, and $\mathrm{supp}(\rho) = \bigcup_{j=1}^P C_j$.
Suppose, for the sake of contradiction, that there exists a cycle $C_m$ in the support of $\rho$ that does not pass through node $v^*$, so $v^* \notin V(C_m)$.
Because $v^* \notin V(C_m)$, no edge of cycle $C_m$ is incident to $v^*$, which implies:
\[
C_m \cap \delta(v^*) = \emptyset \quad \Longrightarrow \quad \mathrm{supp}(\mathbf{1}_{C_m}) \cap \mathrm{supp}(\varepsilon_K) = \emptyset.
\]
Consequently, the standard Euclidean inner product vanishes:
\[
\langle \mathbf{1}_{C_m}, \varepsilon_K \rangle = \sum_{e \in K} (\mathbf{1}_{C_m})_e (\varepsilon_K)_e = 0.
\]
Because $\rho = \Pi_K \varepsilon_K$ is the orthogonal projection of $\varepsilon_K$ onto the subspace of circulations $\mathcal{Z}_1(G_K)$, the projection theorem guarantees that $\langle \rho, z \rangle = \langle \varepsilon_K, z \rangle$ for any circulation $z \in \mathcal{Z}_1(G_K)$.
Setting $z = \mathbf{1}_{C_m} \in \mathcal{Z}_1(G_K)$:
\[
\langle \rho, \mathbf{1}_{C_m} \rangle = \langle \varepsilon_K, \mathbf{1}_{C_m} \rangle = 0.
\]
However, in the conformal cycle decomposition $\rho = \sum_j \alpha_j \mathbf{1}_{C_j}$, each cycle flow shares the sign of $\rho$ on its edges, so $\langle \rho, \mathbf{1}_{C_m} \rangle = \alpha_m \| \mathbf{1}_{C_m} \|_2^2 > 0$, an immediate contradiction.
Therefore, every cycle $C_j$ supporting $\rho$ must contain vertex $v^*$.
We conclude that $\mathrm{supp}(\rho) \subseteq \bigcup \{C \in \mathcal{C}(G_K) : v^* \in V(C)\}$.
\end{proof}

\begin{thebox}
\textbf{Theorem CR-3 (Computational Complexity).}
For the coordinate-decoupled stalk model of Section~\ref{sec:rosetta}, the completion residual $r$ and circulation vector $\rho$ can be approximated by solving $D$ scalar Laplacian systems. The Spielman--Teng solver~\cite{spielman-teng} gives expected time $O(|E|D\log^c|V|\log(1/\epsilon))$ for a constant $c$ and relative energy-norm accuracy $0<\epsilon<1$. This is $\widetilde{O}(|E|D)$ for fixed accuracy; it is not an exact-arithmetic or hardware-latency bound.
\end{thebox}

\begin{proof}
Computing the residual vector $\rho = g_K - \delta_K \hat{x}$ and its scalar norm $r = \|\rho\|_2$ requires solving the least-squares normal equations:
\[
L_K \hat{x} = \delta_K^T g_K, \quad \text{where } L_K = \delta_K^T \delta_K \in \mathbb{R}^{n \times n}.
\]
We analyze each computational stage:

\paragraph{1. Matrix Structure of the Normal Equations:}
For 1-dimensional scalar stalks ($D=1$), the coboundary operator $\delta_K$ is the directed incidence matrix $B_K \in \mathbb{R}^{|K| \times n}$.
The normal matrix $L_K = B_K^T B_K$ is the unweighted graph Laplacian matrix of the visible communication network $G_K = (V, K)$:
\[
(L_K)_{uv} = \begin{cases} \deg_{G_K}(u) & \text{if } u = v, \\ -1 & \text{if } (u, v) \in K \text{ or } (v, u) \in K, \\ 0 & \text{otherwise.} \end{cases}
\]
The matrix $L_K$ is symmetric and weakly diagonally dominant with zero row sums ($L_K \mathbf{1} = 0$). It is therefore a symmetric diagonally dominant (SDD) $M$-matrix with at most $2|K|$ non-zero off-diagonal entries.

\paragraph{2. Linear Solver Complexity:}
By the randomized SDD solver of Spielman and Teng~\cite{spielman-teng}, an $\epsilon$-approximate solution $\tilde{x}$ satisfying $\|\tilde{x} - \hat{x}\|_{L_K} \le \epsilon \|\hat{x}\|_{L_K}$ can be computed in expected time:
\[
T_{\mathrm{solve}} = O\left( |K| \log^c |V| \log(1/\epsilon) \right) = \widetilde{O}(|E|) \quad \text{for fixed } \epsilon,
\]
where $c$ is a constant from the solver bound. For $D$-dimensional stalks where restriction maps $P_e$ are coordinate projections onto shared state variables (Section~\ref{sec:rosetta}), the sheaf coboundary matrix block-diagonalizes into $D$ independent blocks of size $|K| \times |V|$.
The normal equations decouple into $D$ independent scalar Laplacian systems:
\[
L_{K, c} \hat{x}^{(c)} = (\delta_{K, c})^T g_K^{(c)}, \quad \text{for } c \in \{1, \dots, D\}.
\]
Solving these $D$ systems independently requires:
\[
D \cdot T_{\mathrm{solve}} = D \cdot \widetilde{O}(|E|) = \widetilde{O}(|E| \cdot D) \text{ operations.}
\]

\paragraph{3. Sparse Arithmetic Operations:}
\begin{itemize}[noitemsep]
\item \emph{Right-Hand Side Formation}: Computing $b = \delta_K^T g_K$ requires multiplying the transposed incidence matrix $B_K^T$ by $g_K$. Since $B_K^T$ contains exactly $2|K|$ non-zero entries ($\pm 1$), computing $b$ requires $2|K| \cdot D = O(|E| \cdot D)$ additions and subtractions.
\item \emph{Residual Evaluation}: Evaluating $\hat{g}_K = \delta_K \hat{x}$ requires computing $\hat{x}_v - \hat{x}_u$ for each edge $e = (u, v) \in K$ across $D$ dimensions, taking $O(|E| \cdot D)$ time.
\item \emph{Norm Computation}: Vector subtraction $\rho = g_K - \hat{g}_K$ and Euclidean norm evaluation $r = \sqrt{\sum_{e \in K} \|\rho_e\|_2^2}$ require $|K| \cdot D = O(|E| \cdot D)$ flops.
\end{itemize}
Summing all terms, the total algorithmic time complexity is:
\[
T_{\mathrm{total}} = \widetilde{O}(|E| \cdot D) + O(|E| \cdot D) = \widetilde{O}(|E| \cdot D).
\]
The asymptotic bound concerns approximate linear solves; measured latency requires a specified implementation and workload. For $\tilde{\rho}=g_K-\delta_K\tilde{x}$, the solver guarantee gives
\[
\|\tilde{\rho}-\rho\|_2=\|\tilde{x}-\hat{x}\|_{L_K}\le\epsilon\|\hat{x}\|_{L_K}.
\]
The same bound controls $|\|\tilde{\rho}\|_2-r|$ by the reverse triangle inequality. Numerical zero tests must account for this approximation error.
\end{proof}

\subsection{Explicit Observation and Sub-Gaussian Noise Model}\label{sec:noise-model}

In real-world distributed agent swarms, communication is corrupted by network latency jitter, discrete clock quantization, and LLM sampling fluctuations. Rather than treating reported differences as exact deterministic reals, we establish an explicit stochastic observation model.

\begin{definition}[Stochastic Observation Model]\label{def:stochastic-model}
Let $K \subseteq E$ denote the visible communication channels in the three-tier model. The observed 1-cochain $g_K \in \mathbb{R}^{|K|}$ is a random vector decomposing as:
\[
g_K = g_{\mathrm{true}} + \eta_K + \varepsilon_K,
\]
where:
\begin{enumerate}[noitemsep]
\item $g_{\mathrm{true}} = \delta_K x^* \in \mathrm{im}(\delta_K)$ is the ground-truth potential gradient generated by honest underlying agent state vectors $x^* \in \mathbb{R}^n$;
\item $\eta_K \in \mathbb{R}^{|K|}$ is zero-mean stochastic observation noise with independent coordinates satisfying a sub-Gaussian tail condition with variance proxy $\sigma^2 > 0$:
\[
\mathbb{E}[\eta_K] = 0, \quad \text{and} \quad \forall \mathbf{u} \in \mathbb{R}^{|K|} \text{ with } \|\mathbf{u}\|_2 = 1, \quad \mathbb{E}\left[ \exp\left( \lambda \mathbf{u}^T \eta_K \right) \right] \le \exp\left( \frac{\lambda^2 \sigma^2}{2} \right) \quad \forall \lambda \in \mathbb{R};
\]
\item $\varepsilon_K \in \mathbb{R}^{|K|}$ is an adversarial equivocation or hallucination perturbation vector injected across a subset of channels.
\end{enumerate}
\end{definition}

Because $\Pi_K$ projects onto $\ker(\delta_K^T) = (\mathrm{im}(\delta_K))^\perp$, the conservative component vanishes identically: $\Pi_K g_{\mathrm{true}} = \Pi_K \delta_K x^* = 0$.
The observed completion residual vector is therefore:
\[
\rho = \Pi_K g_K = \Pi_K \eta_K + \Pi_K \varepsilon_K.
\]
In an honest swarm ($\varepsilon_K = 0$), the residual is purely noise-driven: $r_{\mathrm{honest}} = \|\Pi_K \eta_K\|_2$.
Because $\Pi_K \in \mathbb{R}^{|K| \times |K|}$ is an orthogonal projection matrix, its eigenvalues are $\{0, 1\}$ with multiplicity $k = \mathrm{rank}(\Pi_K) = \beta_1(G_K)$, where $\beta_1(G_K)$ is the first Betti number (cycle rank) of the visible network.

\begin{theorem}[Sub-Gaussian Concentration and Detection Thresholds]\label{thm:noise-concentration}
Let $\eta_K \sim \mathrm{subG}(\sigma^2 I_{|K|})$ be sub-Gaussian noise on the visible edge complex.
For any target significance level $\delta \in (0, 1)$, define the \textbf{certified detection threshold}:
\[
\tau(\sigma, \delta) = \sigma \left( \sqrt{\beta_1(G_K)} + \sqrt{2 \ln(1/\delta)} \right).
\]
Then the following statistical guarantees hold:
\begin{enumerate}
\item \textbf{Type I Error (False Alarm Bound)}: For an honest swarm ($\varepsilon_K = 0$), the probability of a spurious inconsistency alarm is strictly bounded by $\delta$:
\[
\mathbb{P}\left( r > \tau(\sigma, \delta) \right) \le \delta.
\]
\item \textbf{Type II Error (Certified Detection Power)}: For any adversarial perturbation $\varepsilon_K$ whose projected topological norm satisfies:
\[
\|\Pi_K \varepsilon_K\|_2 \ge \tau(\sigma, \delta) + \sigma \sqrt{2 \ln(1/\delta)} = \sigma \left( \sqrt{\beta_1(G_K)} + 2\sqrt{2 \ln(1/\delta)} \right),
\]
the probability of failing to detect the equivocation is at most $\delta$:
\[
\mathbb{P}\left( r \le \tau(\sigma, \delta) \right) \le \delta.
\]
\item \textbf{High-Probability Injected Norm Lower Bound}: If the detector triggers ($r > \tau(\sigma, \delta)$), then with probability at least $1 - \delta$, the true Euclidean norm of the injected lie satisfies:
\[
\|\varepsilon_K\|_2 \ge r - \sigma \left( \sqrt{\beta_1(G_K)} + \sqrt{2 \ln(1/\delta)} \right) > 0.
\]
\end{enumerate}
\end{theorem}
\begin{proof}
\paragraph{1. Concentration of Projected Sub-Gaussian Vectors:}
Let $k = \beta_1(G_K) = \mathrm{rank}(\Pi_K)$. Because $\Pi_K$ is symmetric and idempotent, it admits an eigendecomposition $\Pi_K = U \mathrm{diag}(I_k, 0) U^T$.
The projected noise is $z = \Pi_K \eta_K$. The norm $\|z\|_2 = \|\Pi_K \eta_K\|_2$ is the Euclidean norm of a $k$-dimensional sub-Gaussian random vector with parameter $\sigma$.
By Vershynin's concentration for sub-Gaussian random vectors in Euclidean space~\cite{vershynin}, the expectation satisfies $\mathbb{E}[\|\Pi_K \eta_K\|_2] \le \sigma \sqrt{k}$, and the upper tail satisfies:
\[
\mathbb{P}\left( \|\Pi_K \eta_K\|_2 \ge \sigma \sqrt{k} + t \right) \le \exp\left( -\frac{t^2}{2\sigma^2} \right).
\]
Setting $t = \sigma \sqrt{2 \ln(1/\delta)}$ yields:
\[
\mathbb{P}\left( \|\Pi_K \eta_K\|_2 > \sigma \left( \sqrt{k} + \sqrt{2 \ln(1/\delta)} \right) \right) \le \exp(-\ln(1/\delta)) = \delta.
\]
This proves Assertion 1.

\paragraph{2. Power of the Detection Test:}
By the reverse triangle inequality on Euclidean norms:
\[
r = \|\Pi_K g_K\|_2 = \|\Pi_K \varepsilon_K + \Pi_K \eta_K\|_2 \ge \|\Pi_K \varepsilon_K\|_2 - \|\Pi_K \eta_K\|_2.
\]
Suppose $\|\Pi_K \varepsilon_K\|_2 \ge \tau(\sigma, \delta) + \sigma \sqrt{2 \ln(1/\delta)}$. Then:
\[
r \le \tau(\sigma, \delta) \quad \Longrightarrow \quad \|\Pi_K \eta_K\|_2 \ge \|\Pi_K \varepsilon_K\|_2 - \tau(\sigma, \delta) \ge \sigma \sqrt{2 \ln(1/\delta)}.
\]
Because $\mathbb{E}[\|\Pi_K \eta_K\|_2] \ge 0$, sub-Gaussian concentration ensures:
\[
\mathbb{P}\left( \|\Pi_K \eta_K\|_2 \ge \|\Pi_K \varepsilon_K\|_2 - \tau(\sigma, \delta) \right) \le \delta.
\]
Therefore, $\mathbb{P}(r \le \tau(\sigma, \delta)) \le \delta$, proving Assertion 2.

\paragraph{3. High-Probability Lower Bound:}
Since $\|\Pi_K \varepsilon_K\|_2 \ge r - \|\Pi_K \eta_K\|_2$, and $\|\Pi_K \eta_K\|_2 \le \tau(\sigma, \delta)$ with probability $\ge 1 - \delta$, we have:
\[
\|\varepsilon_K\|_2 \ge \|\Pi_K \varepsilon_K\|_2 \ge r - \tau(\sigma, \delta)
\]
holding with probability at least $1 - \delta$. When $r > \tau(\sigma, \delta)$, this certified lower bound is strictly positive.
\end{proof}

\subsection{Generalized Adversary Taxonomy and the Homological Cloaking Theorem}\label{sec:adversary-taxonomy}

Theorem~CR-1 explicitly characterized a single equivocator on an uninspected edge. In decentralized swarms, adversaries may collude across multiple agents or compromise sub-networks. We formalize this via a topological adversary taxonomy.

\begin{definition}[Adversary Support Hierarchy]\label{def:adversary-hierarchy}
Let $X = (V, E, F)$ be the communication and contract complex, and $K \subseteq E$ the visible edge set. We classify adversaries by their topological perturbation support:
\begin{enumerate}[noitemsep]
\item \textbf{Single-Edge Adversary $\mathcal{A}_{\mathrm{edge}}(e)$}: The adversary perturbs reports along a single channel $e \in K$; $\mathrm{supp}(\varepsilon) = \{e\}$.
\item \textbf{Single-Node Adversary $\mathcal{A}_{\mathrm{node}}(v)$}: An equivocating agent $v \in V$ that can report conflicting values across all channels incident to $v$; $\mathrm{supp}(\varepsilon) \subseteq \delta(v) = \{ e \in K : v \in e \}$.
\item \textbf{$k$-Node Coalition $\mathcal{A}_{\mathrm{coalition}}(S)$}: A coalition of at most $k$ colluding Byzantine agents $S \subset V$ with $|S| \le k$; $\mathrm{supp}(\varepsilon) \subseteq E(S) \cup \partial(S)$, where $E(S)$ are internal links between nodes in $S$ and $\partial(S) = \{ (u, v) \in K : u \in S, v \notin S \}$ is the cut boundary.
\item \textbf{Regional Sub-Complex Adversary $\mathcal{A}_{\mathrm{region}}(R)$}: An adversary confined to an induced sub-complex $R \subseteq X$.
\end{enumerate}
\end{definition}

\begin{theorem}[The Homological Cloaking Theorem]\label{thm:homological-cloaking}
Let $\mathcal{A}$ be an arbitrary adversary with perturbation support $E_{\mathcal{A}} \subseteq K$.
The perturbation $\varepsilon_K \in \mathbb{R}^{|K|}$ is \textbf{cohomologically invisible} ($r = \|\Pi_K \varepsilon_K\|_2 = 0$) if and only if:
\[
\varepsilon_K \in \mathrm{im}(\delta_K) \cap \mathbb{R}^{E_{\mathcal{A}}},
\]
where $\mathbb{R}^{E_{\mathcal{A}}} = \{ z \in \mathbb{R}^{|K|} : \mathrm{supp}(z) \subseteq E_{\mathcal{A}} \}$.
Equivalently, $\varepsilon_K$ is invisible if and only if there exists a potential vector $\Delta x \in \mathbb{R}^{|V|}$ such that for all edges $e = (u, v) \in K$:
\[
(\varepsilon_K)_e = \begin{cases} (\Delta x)_v - (\Delta x)_u & \text{if } e \in E_{\mathcal{A}}, \\ 0 & \text{if } e \notin E_{\mathcal{A}}. \end{cases}
\]
\end{theorem}
\begin{proof}
By definition of the orthogonal projector $\Pi_K = I - \delta_K \delta_K^+$, we have:
\[
r = \|\Pi_K \varepsilon_K\|_2 = 0 \iff \Pi_K \varepsilon_K = 0 \iff \varepsilon_K \in \ker(\Pi_K) = \mathrm{im}(\delta_K).
\]
Because $\mathrm{supp}(\varepsilon_K) \subseteq E_{\mathcal{A}}$, $\varepsilon_K \in \mathbb{R}^{E_{\mathcal{A}}}$. Thus $\varepsilon_K \in \mathrm{im}(\delta_K) \cap \mathbb{R}^{E_{\mathcal{A}}}$.
By definition of $\mathrm{im}(\delta_K)$, there exists $\Delta x \in \mathbb{R}^n$ such that $\delta_K \Delta x = \varepsilon_K$, meaning $(\Delta x)_v - (\Delta x)_u = (\varepsilon_K)_e$ for all $e \in K$.
For edges $e \notin E_{\mathcal{A}}$, $(\varepsilon_K)_e = 0$, requiring $(\Delta x)_v = (\Delta x)_u$.
\end{proof}

\begin{theorem}[Gauge Confinement of Collusive Equivocation]\label{thm:gauge-confinement}
Let $S \subset V$ be a coalition of $t$ equivocators ($|S| = t < |V|$) with edge support $E_S = E(S) \cup \partial(S)$.
\begin{enumerate}
\item \textbf{Global Gauge Identity}: If coalition $S$ remains completely invisible ($r = 0$), then there exists a vector $\phi_S \in \mathbb{R}^t$ such that for all boundary edges $e = (u, v) \in \partial(S)$ with $u \in S$ and $v \notin S$:
\[
(\varepsilon_K)_e = -(\phi_S)_u.
\]
In particular, the coalition cannot report distinct, contradictory lies to different honest neighbors unless it creates a detectable circulation ($\rho \neq 0$) across external paths connecting those neighbors.
\item \textbf{Triadic Curl Cloaking}: On a simplicial 2-complex $X$, suppose the coalition preserves all local triadic review contracts, so that $\delta_1 \varepsilon_K = 0$.
If in addition $H^1(X; \mathbb{R}) = \{0\}$ (the complex has no 1-dimensional harmonic cavities), then:
\[
\ker(\delta_1) \cap \ker(B_K^T) = \ker(L_1) = \{0\}.
\]
Consequently, any non-gauge adversarial perturbation ($\varepsilon_K \notin \mathrm{im}(\delta_0)$) must satisfy:
\[
r^2 + \|\delta_1 \varepsilon_K\|_2^2 > 0.
\]
Collusion cannot hide in both curl and divergence simultaneously; it must either produce a non-zero completion residual ($r > 0$) or violate at least one triadic review contract ($\delta_1 \varepsilon_K \neq 0$).
\end{enumerate}
\end{theorem}
\begin{proof}
\paragraph{Part 1: Boundary Potential Shift.}
By Theorem~\ref{thm:homological-cloaking}, $r = 0 \implies \varepsilon_K = \delta_K \Delta x$ for some $\Delta x \in \mathbb{R}^n$.
Because $\mathrm{supp}(\varepsilon_K) \subseteq E(S) \cup \partial(S)$, for any edge $e = (u, v)$ outside $E_S$ (connecting two honest agents $u, v \in V \setminus S$), we have $(\varepsilon_K)_e = 0$.
This implies $\Delta x_u = \Delta x_v$ for all vertices in the same connected component of honest agents $G_K[V \setminus S]$.
Setting the honest reference potential to zero ($\Delta x_w = 0$ for all $w \notin S$), the boundary edge difference for $e = (u, v)$ with $u \in S, v \notin S$ evaluates to:
\[
(\varepsilon_K)_e = \Delta x_v - \Delta x_u = 0 - (\Delta x)_u = -(\Delta x)_u.
\]
Defining $\phi_S = \Delta x|_S \in \mathbb{R}^t$ establishes the boundary gauge identity. If node $u \in S$ attempts to report $+s$ to honest neighbor $v_1$ and $-s$ to honest neighbor $v_2$, then $\Delta x_{v_1} - \Delta x_u = +s$ and $\Delta x_{v_2} - \Delta x_u = -s$. Subtracting gives $\Delta x_{v_1} - \Delta x_{v_2} = 2s \neq 0$. Any path in $G_K$ connecting $v_1$ and $v_2$ through honest nodes requires non-zero potential differences on edges outside $E_S$, contradicting $\mathrm{supp}(\varepsilon_K) \subseteq E_S$.

\paragraph{Part 2: Elimination of Homological Blind Spots.}
By the discrete Hodge decomposition (Theorem~CR-5), any 1-cochain decomposes orthogonally as:
\[
\varepsilon_K = \delta_0 x + h + \delta_1^* \psi, \quad \text{where } h \in \ker(L_1) \cong H^1(X; \mathbb{R}).
\]
Because $H^1(X; \mathbb{R}) = \{0\}$, the harmonic component vanishes identically: $h = 0$.
Therefore $\varepsilon_K = \delta_0 x + \delta_1^* \psi$.
If the adversary preserves all triadic contracts, $\delta_1 \varepsilon_K = 0$.
Applying $\delta_1$ to both sides:
\[
0 = \delta_1 \varepsilon_K = \delta_1 \delta_0 x + \delta_1 \delta_1^* \psi = 0 + \delta_1 \delta_1^* \psi.
\]
Taking the Euclidean inner product with $\psi$: $\langle \psi, \delta_1 \delta_1^* \psi \rangle = \|\delta_1^* \psi\|_2^2 = 0$, which proves $\delta_1^* \psi = 0$.
Thus $\varepsilon_K = \delta_0 x \in \mathrm{im}(\delta_0)$, proving that any undetectable, contract-preserving perturbation is strictly a benign global gauge transformation.
\end{proof}

\subsection{Theorem CR-5: Discrete Hodge-Helmholtz Decomposition}
We use the finite-dimensional Hodge decomposition underlying cellular sheaf spectral theory~\cite{hansen-ghrist}. Consider the cochain complex $C^0 \xrightarrow{\delta_0} C^1 \xrightarrow{\delta_1} C^2$.
We define the \textbf{Discrete Hodge 1-Laplacian}:
\[
L_1 = L_1^{\mathrm{down}} + L_1^{\mathrm{up}} = \delta_0 \delta_0^* + \delta_1^* \delta_1,
\]
where $\delta_0^* = \delta_0^T$ and $\delta_1^* = \delta_1^T$.

\begin{thebox}
\textbf{Theorem CR-5 (Discrete Hodge Decomposition \& Pythagorean Invariance).}
Every observed 1-cochain $g \in C^1$ admits a unique, mutually orthogonal decomposition:
\[
g = \underbrace{\delta_0 x}_{\text{Gauge Gradient}} + \underbrace{h}_{\text{Harmonic Cavity}} + \underbrace{\delta_1^* \psi}_{\text{Triadic Curl}}
\]
where:
\begin{enumerate}[noitemsep]
\item $\delta_0 x \in \mathrm{im}(\delta_0)$ is curl-free ($\delta_1(\delta_0 x) \equiv 0$), representing explainable node-level potentials (benign turn latency);
\item $h \in \ker(L_1) = \ker(\delta_0^*) \cap \ker(\delta_1) \cong H^1(X; \mathbb{R})$ satisfies zero divergence ($\delta_0^* h = 0$) and zero curl ($\delta_1 h = 0$), representing non-contractible topological partition cavities;
\item $\delta_1^* \psi \in \mathrm{im}(\delta_1^*)$ is divergence-free ($\delta_0^*(\delta_1^* \psi) \equiv 0$), representing local frustration in triadic review contracts.
\end{enumerate}
All three components are mutually orthogonal, and the squared norm satisfies:
\[
\|g\|_2^2 = \|\delta_0 x\|_2^2 + \|h\|_2^2 + \|\delta_1^* \psi\|_2^2.
\]
\end{thebox}

\begin{proof}
We structure the proof into four rigorous steps: (1) characterization of $\ker(L_1)$, (2) mutual orthogonality, (3) direct sum spanning of $C^1$, and (4) the Hodge isomorphism $\ker(L_1) \cong H^1(X; \mathbb{R})$.

\paragraph{Step 1: Characterization of the Harmonic Kernel $\ker(L_1)$.}
The Hodge 1-Laplacian is $L_1 = \delta_0 \delta_0^* + \delta_1^* \delta_1$, where $\delta_0^* = \delta_0^T$ and $\delta_1^* = \delta_1^T$.
For any 1-cochain $u \in C^1(X; \mathbb{R})$, evaluate the quadratic Dirichlet energy:
\[
\langle u, L_1 u \rangle = u^T (\delta_0 \delta_0^T + \delta_1^T \delta_1) u = u^T \delta_0 \delta_0^T u + u^T \delta_1^T \delta_1 u = \|\delta_0^* u\|_2^2 + \|\delta_1 u\|_2^2.
\]
Because the squared Euclidean norms are non-negative, $\langle u, L_1 u \rangle \ge 0$, establishing that $L_1$ is positive semi-definite.
Furthermore, $\langle u, L_1 u \rangle = 0$ if and only if both terms vanish simultaneously:
\[
\|\delta_0^* u\|_2 = 0 \quad \text{and} \quad \|\delta_1 u\|_2 = 0.
\]
Since a vector has zero norm if and only if it is the zero vector, $L_1 u = 0 \iff (\delta_0^* u = 0 \text{ and } \delta_1 u = 0)$.
Therefore, the harmonic subspace is precisely the intersection of divergence-free and curl-free cochains:
\[
\ker(L_1) = \ker(\delta_0^*) \cap \ker(\delta_1).
\]

\paragraph{Step 2: Pairwise Mutual Orthogonality.}
We demonstrate that all three subspaces $\mathrm{im}(\delta_0)$, $\ker(L_1)$, and $\mathrm{im}(\delta_1^*)$ are pairwise orthogonal:
\begin{enumerate}[noitemsep]
\item \emph{Orthogonality of $\mathrm{im}(\delta_0)$ and $\mathrm{im}(\delta_1^*)$}: For any $x \in C^0$ and $\psi \in C^2$:
\[
\langle \delta_0 x, \delta_1^* \psi \rangle = (\delta_0 x)^T (\delta_1^T \psi) = x^T (\delta_1 \delta_0)^T \psi.
\]
By Lemma~\ref{lem:chain}, $\delta_1 \circ \delta_0 \equiv 0$. Thus $x^T (0)^T \psi = 0$.
\item \emph{Orthogonality of $\mathrm{im}(\delta_0)$ and $\ker(L_1)$}: For any $x \in C^0$ and $h \in \ker(L_1)$:
\[
\langle \delta_0 x, h \rangle = x^T (\delta_0^T h) = x^T (\delta_0^* h).
\]
Since $h \in \ker(L_1) \subseteq \ker(\delta_0^*)$, we have $\delta_0^* h = 0$, so $\langle \delta_0 x, h \rangle = 0$.
\item \emph{Orthogonality of $\mathrm{im}(\delta_1^*)$ and $\ker(L_1)$}: For any $\psi \in C^2$ and $h \in \ker(L_1)$:
\[
\langle \delta_1^* \psi, h \rangle = \psi^T (\delta_1 h).
\]
Since $h \in \ker(L_1) \subseteq \ker(\delta_1)$, we have $\delta_1 h = 0$, so $\langle \delta_1^* \psi, h \rangle = 0$.
\end{enumerate}
Thus, the three subspaces are mutually orthogonal in the standard $L^2$ inner product on $C^1$.

\paragraph{Step 3: Direct Sum Decomposition $C^1 = \mathrm{im}(\delta_0) \oplus \ker(L_1) \oplus \mathrm{im}(\delta_1^*)$.}
By the Fundamental Theorem of Linear Algebra applied to $\delta_0: C^0 \to C^1$:
\[
C^1 = \mathrm{im}(\delta_0) \oplus (\mathrm{im}(\delta_0))^\perp = \mathrm{im}(\delta_0) \oplus \ker(\delta_0^*).
\]
Now consider the subspace $\ker(\delta_0^*)$ and the restriction of $\delta_1$ to this subspace.
By the Fundamental Theorem of Linear Algebra applied to $\delta_1|_{\ker(\delta_0^*)}$:
\[
\ker(\delta_0^*) = (\ker(\delta_0^*) \cap \ker(\delta_1)) \oplus (\ker(\delta_0^*) \cap (\ker(\delta_1))^\perp).
\]
From Step 1, $\ker(\delta_0^*) \cap \ker(\delta_1) = \ker(L_1)$.
Furthermore, $(\ker(\delta_1))^\perp = \mathrm{im}(\delta_1^*)$.
By Lemma~\ref{lem:chain} ($\delta_1 \delta_0 = 0$), taking transposes gives $\delta_0^* \delta_1^* = (\delta_1 \delta_0)^* = 0^* = 0$.
Thus, for every $\psi \in C^2$, $\delta_0^* (\delta_1^* \psi) = 0$, which proves that $\mathrm{im}(\delta_1^*) \subseteq \ker(\delta_0^*)$ unconditionally.
Therefore, $\ker(\delta_0^*) \cap \mathrm{im}(\delta_1^*) = \mathrm{im}(\delta_1^*)$.
Substituting these components into the direct sum:
\[
C^1 = \mathrm{im}(\delta_0) \oplus \ker(L_1) \oplus \mathrm{im}(\delta_1^*).
\]
Because $C^1$ is finite-dimensional, this orthogonal direct sum decomposition is unique for every $g \in C^1$.
By mutual orthogonality, the Pythagorean theorem applies directly:
\[
\|g\|_2^2 = \|\delta_0 x\|_2^2 + \|h\|_2^2 + \|\delta_1^* \psi\|_2^2.
\]

\paragraph{Step 4: The Hodge Isomorphism $\ker(L_1) \cong H^1(X; \mathbb{R})$.}
The first simplicial cohomology group is $H^1(X; \mathbb{R}) = \ker(\delta_1) / \mathrm{im}(\delta_0)$.
Define the canonical projection map $\pi: \ker(L_1) \to H^1(X; \mathbb{R})$ by $\pi(h) = [h] = h + \mathrm{im}(\delta_0)$.
\begin{itemize}[noitemsep]
\item \emph{Injectivity}: Suppose $h \in \ker(L_1)$ satisfies $\pi(h) = [0]$. Then $h \in \mathrm{im}(\delta_0)$.
However, from Step 1, $h \in \ker(\delta_0^*) = (\mathrm{im}(\delta_0))^\perp$.
The only vector orthogonal to its own subspace is the zero vector, so $h = 0$. Thus $\ker(\pi) = \{0\}$, proving injectivity.
\item \emph{Surjectivity}: Let $[z] \in H^1(X; \mathbb{R})$ be an arbitrary cohomology class represented by 1-cocycle $z \in \ker(\delta_1)$.
By the decomposition in Step 3, $z$ uniquely decomposes as $z = \delta_0 x + h + \delta_1^* \psi$.
Applying $\delta_1$ to both sides:
\[
0 = \delta_1 z = \delta_1(\delta_0 x) + \delta_1 h + \delta_1 \delta_1^* \psi.
\]
By Lemma~\ref{lem:chain}, $\delta_1 \delta_0 x = 0$; since $h \in \ker(L_1)$, $\delta_1 h = 0$. Thus $\delta_1 \delta_1^* \psi = 0$.
Taking the inner product with $\psi$: $\langle \psi, \delta_1 \delta_1^* \psi \rangle = \|\delta_1^* \psi\|_2^2 = 0$, which implies $\delta_1^* \psi = 0$.
Therefore, $z = \delta_0 x + h$, which implies $[z] = [h] = \pi(h)$. This proves surjectivity.
\end{itemize}
Because $\pi$ is an injective and surjective linear map between finite-dimensional vector spaces, it is an isomorphism: $\ker(L_1) \cong H^1(X; \mathbb{R})$.
Every cohomology class contains a unique harmonic cochain minimizing Dirichlet energy.
\end{proof}

\subsection{The Swarm Legibility Ratio \texorpdfstring{$\mathcal{L}(g)$}{L(g)}}
Subtracting the benign gauge gradient yields the pure inconsistency cochain: $w = g - \delta_0 x = h + \delta_1^* \psi$.
We define the scale-invariant \textbf{Swarm Legibility Ratio}:
\[
\mathcal{L}(g) = \frac{\|h\|_2^2}{\|h\|_2^2 + \|\delta_1^* \psi\|_2^2} \in [0, 1].
\]
This provides an instant operational triage diagnostic:
\begin{itemize}[noitemsep]
\item \textbf{$\mathcal{L}(g) \approx 0.0$ (Micro-Contract Review Bug)}: The inconsistency lives entirely inside 2-cells ($\|h\| \approx 0$). A specific review triad (Producer-Critic-Manager) hallucinated a contradictory verdict. \emph{Action}: Re-prompt that specific 3-agent review triad.
\item \textbf{$\mathcal{L}(g) \approx 1.0$ (Macro-Network Partition Cavity)}: Every local review contract passed with zero error ($\delta_1 g = 0$), yet the network cannot agree globally ($\|h\| > 0$). A cross-cluster network disconnect has formed. \emph{Action}: Trigger cross-harbor synchronization across cluster boundary bridges.
\end{itemize}

\subsection{Semantic Hodge Realization via Labeled Transition Systems}\label{sec:semantic-hodge}

The discrete Hodge decomposition $g = \delta_0 x + h + \delta_1^* \psi$ is algebraically exact on any simplicial 2-complex. To transform the identification of its components (``gauge = benign asynchrony'', ``curl = review bug'', ``harmonic = macro partition'') from metaphors into theorems, we formalize the execution semantics of the multi-agent swarm as a Labeled Transition System (LTS)~\cite{baier-katoen}.

\begin{definition}[Swarm Labeled Transition System $\mathcal{M}$]\label{def:swarm-lts}
A swarm execution environment is a labeled transition system $\mathcal{M} = (S_{\mathrm{sys}}, \Sigma_{\mathrm{act}}, \to, s_0)$, where:
\begin{enumerate}[noitemsep]
\item $s \in S_{\mathrm{sys}}$ is a configuration tuple $s = (x, \mathcal{Q}, \mathcal{T}, \mathcal{G})$, where:
  \begin{itemize}[noitemsep]
  \item $x = (x_v)_{v \in V} \in \prod_{v \in V} \mathcal{F}(v)$ denotes the local stalk states of all agents;
  \item $\mathcal{Q} = (\mathcal{Q}_e)_{e \in E}$ stores in-flight message queues on communication links;
  \item $\mathcal{T} = (\nu_\tau)_{\tau \in F}$ records triadic contract verdicts on 2-simplices;
  \item $\mathcal{G} = (V, E_{\mathrm{active}}, F_{\mathrm{active}})$ tracks the active topology.
  \end{itemize}
\item $\Sigma_{\mathrm{act}}$ is the action alphabet containing:
  \begin{itemize}[noitemsep]
  \item $\textsf{Step}(v, \Delta x_v)$: Agent $v$ updates its local state: $x_v \gets x_v + \Delta x_v$;
  \item $\textsf{Send}(u, v, m)$: Agent $u$ enqueues gossip packet $m = P_{u \trianglelefteq e} x_u$ into $\mathcal{Q}_{(u, v)}$;
  \item $\textsf{Recv}(u, v, m)$: Agent $v$ dequeues $m$ and sets edge observation $g_{uv} = P_{v \trianglelefteq e} x_v - m$;
  \item $\textsf{ReviewVerdict}(\tau, \nu)$: Triad $\tau = (u, v, w)$ evaluates joint code contract, setting $(\delta_1 g)_\tau = \nu$;
  \item $\textsf{Partition}(V_1, V_2)$: Channels between disjoint clusters $V_1, V_2$ transition to severed.
  \end{itemize}
\end{enumerate}
\end{definition}

\begin{theorem}[Semantic Gauge Correspondence: Asynchrony is Pure Potential]\label{thm:semantic-gauge}
Let $\mathcal{E}_{\mathrm{async}}$ be the class of executions consisting solely of interleavings of $\textsf{Step}(v, \cdot)$, $\textsf{Send}(u, v, \cdot)$, and $\textsf{Recv}(u, v, \cdot)$ across a connected topology without network partitions, where every triadic review contract satisfies conservative composition.
Then for every reachable configuration $s \in \mathcal{E}_{\mathrm{async}}$, the observed 1-cochain $g$ lies entirely in the gauge gradient subspace:
\[
g \in \mathrm{im}(\delta_0) \quad \Longleftrightarrow \quad \Pi_{\ker(L_1)} g = 0 \quad \text{and} \quad \Pi_{\mathrm{im}(\delta_1^*)} g = 0.
\]
In particular, the Swarm Legibility Ratio is undefined ($0/0$, treated as pure gauge) and the curl energy vanishes identically: $\|\delta_1^* \psi\|_2^2 = 0$.
\end{theorem}
\begin{proof}
In any execution $\alpha \in \mathcal{E}_{\mathrm{async}}$, each edge difference $g_{uv}$ is computed as $P_{v \trianglelefteq e} x_v - P_{u \trianglelefteq e} x_u^{(t - \Delta t)}$, where $\Delta t$ represents asynchronous transmission and queueing delay.
Because all coordinate projections decouple and no agent prioritizes contradictory updates, the differences telescope around any closed loop $\partial \tau = (u, v) + (v, w) - (u, w)$ of a review triad:
\[
(\delta_1 g)_\tau = g_{uv} + g_{vw} - g_{uw} = (x_v - x_u) + (x_w - x_v) - (x_w - x_u) = 0.
\]
Because this holds for every 2-simplex $\tau \in F$, $g \in \ker(\delta_1)$.
Furthermore, on a connected contractible or tree-like region without macro partitions, the cycle integration of conservative updates evaluates to zero on the cycle space, ensuring that $\Pi_{\ker(L_1)} g = 0$.
By the Hodge direct sum decomposition (Theorem~CR-5), $g = \delta_0 x + h + \delta_1^* \psi$.
Since $h = 0$ and $\delta_1^* \psi = 0$, we have $g = \delta_0 x \in \mathrm{im}(\delta_0)$.
Asynchronous latency skew is strictly a conservative gauge potential gradient.
\end{proof}

\begin{theorem}[Semantic Curl Correspondence: Triadic Review Inconsistencies]\label{thm:semantic-curl}
Let configuration $s$ witness a local review contract failure on 2-simplex $\tau = (u, v, w) \in F$, such that:
\[
|(\delta_1 g)_\tau| = |g_{uv} + g_{vw} - g_{uw}| = c > 0.
\]
Then the discrete Hodge decomposition of $g$ has a strictly non-zero triadic curl component whose energy satisfies:
\[
\|\delta_1^* \psi\|_2^2 \ge \frac{c^2}{\lambda_{\max}(\delta_1 \delta_1^*)} > 0.
\]
Consequently, localized review contract hallucinations inject energy strictly and injectively into $\mathrm{im}(\delta_1^*)$, driving $\mathcal{L}(g) \to 0$ in the absence of macro partitions.
\end{theorem}
\begin{proof}
Applying the 1st coboundary operator $\delta_1$ to the Hodge decomposition $g = \delta_0 x + h + \delta_1^* \psi$:
\[
\delta_1 g = \delta_1 \delta_0 x + \delta_1 h + \delta_1 \delta_1^* \psi = 0 + 0 + \delta_1 \delta_1^* \psi = \delta_1 \delta_1^* \psi.
\]
Evaluating the Euclidean norm of $\delta_1 g$:
\[
\|\delta_1 g\|_2^2 = \sum_{\sigma \in F} |(\delta_1 g)_\sigma|^2 \ge |(\delta_1 g)_\tau|^2 = c^2.
\]
On the other hand:
\[
\|\delta_1 g\|_2^2 = \|\delta_1 \delta_1^* \psi\|_2^2 = \langle \delta_1^* \psi, (\delta_1^* \delta_1) \delta_1^* \psi \rangle \le \lambda_{\max}(\delta_1 \delta_1^*) \|\delta_1^* \psi\|_2^2.
\]
Dividing by the spectral norm $\lambda_{\max}(\delta_1 \delta_1^*) = \lambda_{\max}(L_1^{\mathrm{up}}) > 0$:
\[
\|\delta_1^* \psi\|_2^2 \ge \frac{c^2}{\lambda_{\max}(\delta_1 \delta_1^*)} > 0.
\]
The triadic review error cannot be absorbed by $\delta_0 x$ or $h$; it is strictly localized to $\mathrm{im}(\delta_1^*)$.
\end{proof}

\begin{theorem}[Semantic Harmonic Correspondence: Cross-Harbor Partitions]\label{thm:semantic-harmonic}
Let $X$ contain a non-bounding 1-cycle $C = (v_1, v_2, \dots, v_m, v_1)$ spanning two autonomous sub-swarms $V_1, V_2$ bridged by boundary channels $E_{\mathrm{bridge}} \subset C$, such that $[C] \neq 0 \in H_1(X; \mathbb{R})$.

If all local review triads within $V_1$ and $V_2$ remain internally consistent ($\delta_1 g = 0$), then:
\[
h = \Pi_{\ker(L_1)} g \neq 0 \quad \text{and} \quad \mathcal{L}(g) = 1.0.
\]
The harmonic component $h$ is non-zero, spanning the first cohomology group $H^1(X; \mathbb{R})$ and certifying a macro-network partition.
\end{theorem}
\begin{proof}
Because every local review contract within $V_1$ and $V_2$ passes with zero defect, $(\delta_1 g)_\tau = 0$ for all $\tau \in F$, which implies $\delta_1 g = 0$.
By the Hodge decomposition, this guarantees that the triadic curl vanishes: $\delta_1^* \psi = 0$.
The cochain simplifies to $g = \delta_0 x + h$.
Evaluating the circulation integral around cycle $C$:
\[
\oint_C g = \sum_{e \in C} g_e = \sum_{e \in C} (\delta_0 x)_e + \sum_{e \in C} h_e = 0 + \langle \mathbf{1}_C, h \rangle.
\]
Across the boundary bridges connecting $V_1$ and $V_2$, the potential difference accumulates:
\[
\oint_C g = \sum_{e \in C \cap E_{\mathrm{bridge}}} (x^{(2)} - x^{(1)}) = k \cdot (x^{(2)} - x^{(1)}) \neq 0.
\]
Because $\oint_C g \neq 0$, the cochain $g$ cannot belong to $\mathrm{im}(\delta_0)$ (all gradient cochains evaluate to zero on closed cycles).
Therefore $h \neq 0$.
Substituting into the Swarm Legibility Ratio:
\[
\mathcal{L}(g) = \frac{\|h\|_2^2}{\|h\|_2^2 + \|\delta_1^* \psi\|_2^2} = \frac{\|h\|_2^2}{\|h\|_2^2 + 0} = 1.0.
\]
The Hodge decomposition diagnoses the network split with 100\% mathematical confidence.
\end{proof}

\subsection{Probabilistic and Bayesian Sheaves: Belief Stalks and Information Residuals}\label{sec:bayesian-sheaves}

In real-world swarm deployment, agent knowledge is rarely deterministic; agents maintain probabilistic belief states over parameters, model weights, or hypothesis distributions. To accommodate uncertainty, we promote cellular stalks to probability spaces~\cite{villani}.

\begin{definition}[Probabilistic Cellular Sheaf]
A \textbf{probabilistic cellular sheaf} $(\mathcal{F}, \mathcal{P})$ over simplicial complex $X$ assigns:
\begin{enumerate}[noitemsep]
\item To each simplex $\sigma \in X$, a measurable space $(\mathcal{X}_\sigma, \Sigma_\sigma)$ and a space of probability measures $\mathcal{P}(\mathcal{X}_\sigma)$;
\item To each incident pair $\sigma \trianglelefteq \tau$, a measurable restriction map $P_{\sigma \trianglelefteq \tau}: \mathcal{X}_\sigma \to \mathcal{X}_\tau$ inducing the \textbf{pushforward operator} on distributions:
\[
(P_{\sigma \trianglelefteq \tau\#} \mu)(A) = \mu\left( P_{\sigma \trianglelefteq \tau}^{-1}(A) \right) \quad \text{for all } A \in \Sigma_\tau, \; \mu \in \mathcal{P}(\mathcal{X}_\sigma).
\]
\end{enumerate}
\end{definition}

For Gaussian belief stalks, each agent $v$ maintains a belief distribution $\mu_v = \mathcal{N}(m_v, \Sigma_v) \in \mathcal{P}(\mathbb{R}^{D_v})$, where $m_v \in \mathbb{R}^{D_v}$ is the expected telemetry vector and $\Sigma_v \succ 0$ is the covariance matrix capturing epistemic uncertainty.
Under linear restriction maps $P_{v \trianglelefteq e}$, the pushforward distribution onto edge $e = (u, v)$ evaluates in closed form to:
\[
P_{v \trianglelefteq e\#} \mu_v = \mathcal{N}\left( P_{v \trianglelefteq e} m_v, \; P_{v \trianglelefteq e} \Sigma_v P_{v \trianglelefteq e}^T \right).
\]

\begin{definition}[Wasserstein-2 Sheaf Completion Residual]
Let $\mu_u^e = P_{u \trianglelefteq e\#} \mu_u$ and $\mu_v^e = P_{v \trianglelefteq e\#} \mu_v$ be the pushforward marginals on edge $e = (u, v) \in K$.
The \textbf{2-Wasserstein Sheaf Residual} is defined by:
\[
r_{\mathcal{W}_2}^2 = \sum_{e = (u, v) \in K} \mathcal{W}_2^2\left( \mu_u^e, \, \mu_v^e \right),
\]
where $\mathcal{W}_2$ denotes the optimal transport 2-Wasserstein metric~\cite{villani}:
\[
\mathcal{W}_2^2(\mu_1, \mu_2) = \inf_{\gamma \in \Pi(\mu_1, \mu_2)} \int \|x - y\|_2^2 \, \mathrm{d}\gamma(x, y).
\]
\end{definition}

\begin{theorem}[Gaussian Wasserstein Decomposition and Epistemic Separation]\label{thm:gaussian-wasserstein}
For Gaussian belief stalks $\mu_u^e = \mathcal{N}(m_u^e, \Sigma_u^e)$ and $\mu_v^e = \mathcal{N}(m_v^e, \Sigma_v^e)$, the squared 2-Wasserstein sheaf residual decomposes in closed form as:
\[
r_{\mathcal{W}_2}^2 = \sum_{e \in K} \|m_v^e - m_u^e\|_2^2 + \sum_{e \in K} \mathfrak{B}(\Sigma_u^e, \Sigma_v^e)^2,
\]
where $\mathfrak{B}(\Sigma_u^e, \Sigma_v^e)$ is the Bures metric on positive definite covariance matrices:
\[
\mathfrak{B}(\Sigma_u^e, \Sigma_v^e)^2 = \mathrm{Tr}\left( \Sigma_u^e + \Sigma_v^e - 2 \left( (\Sigma_u^e)^{1/2} \Sigma_v^e (\Sigma_u^e)^{1/2} \right)^{1/2} \right).
\]
\end{theorem}
\begin{proof}
This follows directly from the classical Gelbrich--Dowson--Landau theorem for Wasserstein distances between Gaussian measures on Euclidean spaces (Villani~\cite{villani}, Theorem~7.3). The optimal coupling between $\mathcal{N}(m_1, \Sigma_1)$ and $\mathcal{N}(m_2, \Sigma_2)$ is an affine transformation, separating the transport cost into the displacement of means $\|m_1 - m_2\|_2^2$ and the covariance deformation cost $\mathfrak{B}(\Sigma_1, \Sigma_2)^2$.
\end{proof}

\begin{corollary}[Separation of Epistemic Uncertainty from Ontic Contradiction]
The Wasserstein sheaf decomposition rigorously distinguishes benign epistemic exploration from Byzantine equivocation:
\begin{enumerate}[noitemsep]
\item \textbf{Benign Epistemic Exploration}: When agents explore diverse hypotheses with wide variances ($\mathrm{Tr}(\Sigma_u^e), \mathrm{Tr}(\Sigma_v^e) \gg 0$) while their means agree ($\|m_v^e - m_u^e\| \approx 0$), the displacement term vanishes: $\sum \|m_v^e - m_u^e\|^2 = 0$. The residual reflects admissible variance without triggering an equivocation alarm.
\item \textbf{Ontic Contradiction (Adversarial Lie)}: When agents assert high confidence ($\Sigma_u^e, \Sigma_v^e \to 0$) but report disjoint mean values ($\|m_v^e - m_u^e\| \ge \Lambda > 0$), the Bures term vanishes and $r_{\mathcal{W}_2} \to \|m_v^e - m_u^e\|_2 \ge \Lambda$. Sheaf cohomology certifies an irreconcilable contract violation.
\end{enumerate}
\end{corollary}

\section{Active Swarm Control: Theorem CR-4 (Optimal Cohomological Repair)}\label{sec:repair}

When $r > 0$, the orchestrator must intervene to restore global consensus. Let $w(e) > 0$ be the cost of fencing or reconciling edge $e \in K$.

\IfFileExists{fig-paper8-active-repair.tex}{\input{fig-paper8-active-repair.tex}}{\input{../figures/fig-paper8-active-repair.tex}}

The operator seeks a subset of edges $S^* \subseteq K$ minimizing total intervention cost:
\[
\min_{S \subseteq K} \sum_{e \in S} w(e) \quad \text{subject to} \quad r(K \setminus S) = 0.
\]

\begin{thebox}
\textbf{Theorem CR-4 (Optimal Cohomological Repair via Greedy Controller).}
\begin{enumerate}
\item For each active edge $e$, define its \textbf{residual energy} $E(e) = \|\rho_e\|_2^2$.
\item The \textbf{Greedy Energy-to-Cost Controller} iteratively selects:
\[
e^* = \arg\max_{e \in K_{\mathrm{active}}} \frac{E(e)}{w(e)}
\]
and fences/reconciles edge $e^*$.
\item \textbf{Guaranteed Termination}: The controller drives $r \to 0$ in at most $\beta_1(G_K) = |E_K| - |V_K| + \mathrm{comps}(G_K)$ iterations.
\end{enumerate}
\end{thebox}

\begin{proof}
We prove the guaranteed termination and convergence of the greedy controller using the cycle matroid and the topology of the 1-skeleton $G_K = (V_K, K)$.

\paragraph{Step 1: Cycle Rank and First Betti Number.}
In algebraic graph theory, the dimension of the cycle space $\mathcal{Z}_1(G_K; \mathbb{R}) = \ker(B_K^T)$ is given by the first Betti number:
\[
\beta_1(G_K) = |K| - |V_K| + c(G_K),
\]
where $c(G_K)$ is the number of connected components of the graph $G_K$. The quantity $\beta_1(G_K)$ is the rank of the cycle matroid $M(G_K)$ and represents the maximum number of edge-independent cycles in $G_K$.

\paragraph{Step 2: Non-Zero Residual Implies Strictly Positive Edge Energy.}
By Theorem CR-2, the residual vector $\rho = \Pi_K g_K$ satisfies $B_K^T \rho = 0$.
If the residual norm is non-zero, $r^2 = \|\rho\|_2^2 = \sum_{e \in K_{\mathrm{active}}} E(e) > 0$.
Because all costs $w(e)$ are strictly positive ($0 < w_{\min} \le w(e) \le w_{\max} < \infty$), the maximum ratio satisfies:
\[
\max_{e \in K_{\mathrm{active}}} \frac{E(e)}{w(e)} \ge \frac{\sum_{e} E(e)}{\sum_{e} w(e)} \ge \frac{r^2}{|K| \cdot w_{\max}} > 0.
\]
Therefore, the edge $e^* = \arg\max \frac{E(e)}{w(e)}$ chosen by the controller in Step 2 has strictly positive residual energy: $E(e^*) = \rho_{e^*}^2 > 0$.

\paragraph{Step 3: Edge $e^*$ Belongs to at Least One Cycle.}
By the cycle-flow decomposition (Theorem CR-2), any circulation $\rho \in \ker(B_K^T)$ decomposes into simple cycle flows: $\rho = \sum_j \alpha_j \mathbf{1}_{C_j}$.
Because $\rho_{e^*} \neq 0$, edge $e^*$ must belong to at least one cycle $C_m$ supporting $\rho$.
In graph theory, an edge belongs to a cycle if and only if it is \emph{not} a bridge (cut-edge).
Therefore, edge $e^*$ is not a bridge of $G_K$.

\paragraph{Step 4: Strict Rank Reduction of the Cycle Matroid.}
Removing an edge that is not a bridge preserves the connectivity of its containing component: the number of connected components is invariant under removal of $e^*$:
\[
c(G_K \setminus \{e^*\}) = c(G_K).
\]
The number of active edges decreases by exactly one: $|K \setminus \{e^*\}| = |K| - 1$.
Consequently, the first Betti number strictly decreases by exactly 1:
\[
\beta_1(G_K \setminus \{e^*\}) = (|K| - 1) - |V_K| + c(G_K) = \beta_1(G_K) - 1.
\]
Every intervention round that selects an edge with $E(e) > 0$ strictly decrements the cycle rank $\beta_1$ of the visible network by 1.

\paragraph{Step 5: Termination at Cycle Rank Zero.}
The Betti number $\beta_1$ is a non-negative integer.
Because $\beta_1(G_K)$ decreases by 1 at each round whenever $r > 0$, the controller can execute for at most $\beta_1(G_K)$ rounds before reaching a subgraph $G_{K'}$ with:
\[
\beta_1(G_{K'}) = 0.
\]
A finite graph with $\beta_1 = 0$ contains no cycles; it is a spanning forest (a disjoint collection of trees).
By Theorem CR-1 (Assertion 4), on a forest every edge is a bridge, and the cycle space is trivial: $\ker(B_{K'}^T) = \{0\}$.
Because $\Pi_{K'}$ is the orthogonal projector onto $\ker(B_{K'}^T)$, $\Pi_{K'} = 0$.
The completion residual on the remaining network is:
\[
r(K') = \|\Pi_{K'} g_{K'}\|_2 = \|0 \cdot g_{K'}\|_2 = 0.
\]
Consensus is completely restored ($r = 0$).
Therefore, the greedy energy-to-cost controller is guaranteed to terminate in at most $\beta_1(G_K) = |K| - |V_K| + c(G_K)$ iterations.
\end{proof}

\subsection{Discrete-Time Swarm Dynamics, Closed-Loop Control, and Finite-Time Stability}\label{sec:discrete-dynamics}

Static cochain snapshots evaluate swarm consistency at a single inspection instant. In autonomous execution environments, swarms evolve dynamically over discrete rounds $t \in \{0, 1, 2, \dots\}$, driven by ongoing agent tasks, asynchronous commits, and supervisory repair interventions. We model the swarm as a discrete-time dynamical system on cellular cochains.

\begin{definition}[Discrete-Time Cochain Dynamical System]
Let $t \in \mathbb{N}$ denote the supervisory round index. The swarm state is governed by the state equation:
\[
g^{(t+1)} = g^{(t)} - u^{(t)} + w^{(t)},
\]
where:
\begin{enumerate}[noitemsep]
\item $g^{(t)} \in C^1(X; \mathbb{R})$ is the visible 1-cochain at round $t$;
\item $u^{(t)} \in C^1(X; \mathbb{R})$ is the supervisor's active intervention vector;
\item $w^{(t)} \in C^1(X; \mathbb{R})$ is the environmental disturbance, incorporating newly completed agent turns, commit advancements, and adversarial drift.
\end{enumerate}
The supervisor computes the reconstructed potential $\hat{x}^{(t)} = \delta_{K_t}^+ g_{K_t}^{(t)}$ and residual circulation $\rho^{(t)} = \Pi_{K_t} g^{(t)}$, with energy $V(t) = \|\rho^{(t)}\|_2^2 = (r^{(t)})^2$.
\end{definition}

The supervisor executes one of three repair interventions $u^{(t)}$:
\begin{enumerate}[noitemsep]
\item \textbf{Edge Fencing / Removal}: For selected edge $e^*$, set $K_{t+1} = K_t \setminus \{e^*\}$, removing the channel from the active complex and setting $u_e^{(t)} = g_e^{(t)}$;
\item \textbf{Triadic Contract Re-prompting}: For review triad $\tau = (u, v, w)$ with curl $(\delta_1 g^{(t)})_\tau = c$, apply adjoint correction $u^{(t)} = \delta_1^* \psi^{(t)}$ with $\psi_\tau^{(t)} = c / \|\delta_1^* \mathbf{1}_\tau\|_2^2$;
\item \textbf{Consensus Laplacian Smoothing}: Update cochains via down-Laplacian gradient flow $u^{(t)} = \gamma L_1^{\mathrm{down}} g^{(t)}$ with step size $\gamma \in (0, 2/\lambda_{\max}(L_1^{\mathrm{down}}))$.
\end{enumerate}

\begin{theorem}[Lyapunov Contraction and Finite-Time Stability]\label{thm:lyapunov-stability}
Consider the discrete-time closed-loop system under the Greedy Energy-to-Cost Controller of Theorem~CR-4.
Let $V(t) = \|\Pi_{K_t} g^{(t)}\|_2^2 = (r^{(t)})^2$ be the candidate Lyapunov function.
\begin{enumerate}
\item \textbf{Autonomous Dissipation and Finite-Time Termination}: In an undisturbed environment ($w^{(t)} \in \mathrm{im}(\delta_{K_t})$), the Lyapunov function satisfies the strict contraction inequality:
\[
V(t+1) \le V(t) \left( 1 - \frac{w_{\min}}{\beta_1(G_{K_t}) \cdot w_{\max}} \right) < V(t) \quad \text{whenever } V(t) > 0.
\]
Furthermore, $V(t)$ reaches zero identically in at most $\beta_1(G_{K_0}) = |K_0| - |V| + c(G_{K_0})$ steps.
\item \textbf{Input-to-State Stability (ISS)}: Under persistent bounded disturbance with $\|\Pi_{K_t} w^{(t)}\|_2 \le \gamma < \infty$, the closed-loop system is Input-to-State Stable:
\[
\limsup_{t \to \infty} r^{(t)} \le \frac{\gamma}{1 - \sqrt{1 - \frac{w_{\min}}{\beta_1(G_{K_0}) w_{\max}}}}.
\]
The asymptotic residual remains strictly bounded within an error ball proportional to disturbance scale $\gamma$.
\end{enumerate}
\end{theorem}
\begin{proof}
\paragraph{Part 1: Strict Contraction and Finite-Time Termination.}
At round $t$, the controller selects $e^* = \arg\max_{e \in K_t} \frac{\rho_e^2}{w(e)}$ and fences edge $e^*$.
By Step 2 of Theorem~CR-4:
\[
\frac{\rho_{e^*}^2}{w(e^*)} \ge \frac{\sum_{e \in K_t} \rho_e^2}{\sum_{e \in K_t} w(e)} \ge \frac{\|\rho^{(t)}\|_2^2}{|K_t| w_{\max}} = \frac{V(t)}{|K_t| w_{\max}}.
\]
Hence $\rho_{e^*}^2 \ge V(t) \frac{w(e^*)}{|K_t| w_{\max}} \ge V(t) \frac{w_{\min}}{|K_t| w_{\max}}$.
By cycle-matroid rank reduction (Step 4 of Theorem~CR-4), removing $e^*$ strictly decrements the dimension of the circulation subspace $\ker(B_{K_t}^T)$ by 1:
$\mathrm{rank}(\Pi_{K_{t+1}}) = \beta_1(G_{K_t}) - 1$.
Because $e^*$ carries circulation energy $\rho_{e^*}^2$, removing $e^*$ eliminates its orthogonal projection onto the cycle space. The new residual satisfies:
\[
V(t+1) = \|\Pi_{K_{t+1}} g^{(t+1)}\|_2^2 \le V(t) - \rho_{e^*}^2 \le V(t) \left( 1 - \frac{w_{\min}}{|K_t| w_{\max}} \right).
\]
Because $\beta_1(G_{K_t}) \le |K_t|$, we have $V(t+1) < V(t)$ strictly for all $V(t) > 0$.
Because $\beta_1(G_{K_t})$ is a non-negative integer that strictly decrements by at least 1 at every round where $V(t) > 0$, the system must achieve $\beta_1(G_{K_{t^*}}) = 0$ in at most $t^* \le \beta_1(G_{K_0})$ steps.
At $\beta_1 = 0$, $\Pi_{K} = 0$, which yields $V(t^*) = 0$ identically.

\paragraph{Part 2: Input-to-State Stability.}
When disturbance $w^{(t)}$ is present, the cochain update gives:
\[
r^{(t+1)} = \|\Pi_{K_{t+1}} (g^{(t)} - u^{(t)} + w^{(t)})\|_2 \le \|\Pi_{K_{t+1}} (g^{(t)} - u^{(t)})\|_2 + \|\Pi_{K_{t+1}} w^{(t)}\|_2.
\]
Let $\kappa = \sqrt{1 - \frac{w_{\min}}{\beta_1(G_{K_0}) w_{\max}}} \in (0, 1)$.
Substituting the contraction bound on the autonomous system:
\[
r^{(t+1)} \le \kappa r^{(t)} + \gamma.
\]
By induction on discrete linear difference inequalities:
\[
r^{(t)} \le \kappa^t r^{(0)} + \gamma \sum_{j=0}^{t-1} \kappa^j = \kappa^t r^{(0)} + \gamma \frac{1 - \kappa^t}{1 - \kappa}.
\]
Taking the limit superior as $t \to \infty$:
\[
\limsup_{t \to \infty} r^{(t)} \le \frac{\gamma}{1 - \kappa} = \frac{\gamma}{1 - \sqrt{1 - \frac{w_{\min}}{\beta_1(G_{K_0}) w_{\max}}}}.
\]
This proves Input-to-State Stability with certified asymptotic gain.
\end{proof}

\Phi_{\mathrm{safe}} = \square \left( \Phi_{\mathrm{mutex}} \wedge \Phi_{\mathrm{branch}} \wedge \Phi_{\mathrm{review}} \wedge \Phi_{\mathrm{clock}} \right),

\subsection{Affine Constraint Embedding and Equivalence Theorems}

\end{definition}

\begin{theorem}[Verification-Cohomology Soundness and Completeness]\label{thm:verification-bridge}
Let $\Phi_{\mathrm{safe}}$ be an affinely embeddable safety specification with faithful margin $\Lambda > 0$ under stalk encoding $\mathrm{Enc}$, and let observation noise satisfy $\eta_K \sim \mathrm{subG}(\sigma^2 I_{|K|})$.
\begin{enumerate}
\item \textbf{Soundness (Violation Implies Topological Alarm)}:
Suppose an execution trace $\sigma$ witnesses a formal safety violation $\sigma \models \diamondsuit \neg \Phi_{\mathrm{safe}}$ on an uninspected non-bridge channel $e^* \in R$.
Then the completion residual triggers a certified alarm above the noise floor:
\[
\mathbb{P}\left( r > \tau(\sigma, \delta) \right) \ge 1 - \delta,
\]
provided the semantic violation margin satisfies $\Lambda \sqrt{1 - R_{\mathrm{eff}}^K(e^*)} \ge 2\tau(\sigma, \delta)$.
Every formal safety bug is guaranteed to trigger a topological alarm with high probability.
\item \textbf{Completeness (Small Residual Implies Approximate Safety)}:
Conversely, if an observer measures completion residual $r \le \tau(\sigma, \delta)$ and legibility ratio $\mathcal{L} \le \epsilon$, then with probability at least $1 - \delta$, the execution trace satisfies an $\epsilon$-relaxed safety envelope $\Phi_{\mathrm{safe}}^{\epsilon}$:
\[
\mathbb{P}\left( \sigma \models \Phi_{\mathrm{safe}}^{\epsilon} \right) \ge 1 - \delta,
\]
where $\Phi_{\mathrm{safe}}^{\epsilon}$ allows state discrepancy at most $\epsilon \cdot \tau(\sigma, \delta) / \sigma_{\min}^+(\delta_K)$.
\end{enumerate}
\end{theorem}
\begin{proof}
\paragraph{1. Soundness of Topological Alarms:}
By the semantic trace grounding theorem (Theorem~\ref{thm:trace-grounding}), an invariant violation with margin $\Lambda$ injects a perturbation $\varepsilon_K$ whose projected norm satisfies $\|\Pi_K \varepsilon_K\|_2 \ge \Lambda \sqrt{1 - R_{\mathrm{eff}}^K(e^*)}$.
Assuming $\Lambda \sqrt{1 - R_{\mathrm{eff}}^K(e^*)} \ge 2\tau(\sigma, \delta) = \tau(\sigma, \delta) + \sigma(\sqrt{\beta_1} + \sqrt{2\ln(1/\delta)})$, Assertion 2 of Theorem~\ref{thm:noise-concentration} guarantees:
\[
\mathbb{P}(r \le \tau(\sigma, \delta)) \le \delta \quad \Longleftrightarrow \quad \mathbb{P}(r > \tau(\sigma, \delta)) \ge 1 - \delta.
\]
Thus any LTL safety violation triggers the cohomological detector with probability at least $1 - \delta$.

\paragraph{2. Completeness and Safety Certificate:}
Suppose $r \le \tau(\sigma, \delta)$.
Recall that $r = \min_{x} \|g_K - \delta_K x\|_2$.
Let $\hat{x} = \delta_K^+ g_K$. Then $\|g_K - \delta_K \hat{x}\|_2 = r \le \tau(\sigma, \delta)$.
By the affine invariant embedding, the safety specification evaluates the discrepancy $\|A_\Phi (\delta_K \hat{x}) - b_\Phi\|$.
By Lipschitz continuity of linear maps, the distance from $\hat{x}$ to the set of perfectly safe states is bounded by $r / \sigma_{\min}^+(\delta_K) \le \tau(\sigma, \delta) / \sigma_{\min}^+(\delta_K)$.
Accounting for sub-Gaussian noise $\eta_K$, with probability $\ge 1 - \delta$ the underlying ground-truth state $x^*$ satisfies the $\epsilon$-relaxed invariant $\Phi_{\mathrm{safe}}^\epsilon$.
\end{proof}

\subsection{Case Study 3: Byzantine Equivocator Min-Cut Repair (Theorem CR-4)}

\subsection{Case Study 5: 24-Agent Multi-Harbor Mesh under Dual Byzantine Attack}

\section{Falsification Protocol \& Mutation Testing}\label{sec:falsification}
To prevent methodological artifacts, our evaluation suite enforces strict falsification testing:
\begin{enumerate}[noitemsep]
\item \textbf{Mutation D1 (Random Orthonormal Projections)}: Drawing random projection matrices for $P_e$ causes $\mathrm{coker}(\delta_0) \to \{0\}$, destroying the detection signal. The test harness detects this collapse and asserts failure.
\item \textbf{Mutation D2 (Hidden Data Leakage)}: Simulating severed edges by reading hidden ground truth fabricates spurious detections. The harness verifies that on severed edges, the residual matches the unconstrained completion.
\item \textbf{Cut-Edge Silence Verification}: Injecting an equivocation of $s = 100.0$ across a cut edge produces $r = 0.000000000000$ to machine precision.
\item \textbf{Closed-Form Verification}: On $C_6$ with $s = 3.0$ and unit resistors, $R_{\mathrm{eff}} = 5/6$. The empirical residual $r = 1.22474487$ matches $3\sqrt{1 - 5/6}$ to 14 decimal places.
\end{enumerate}

The transcripts and initial seeds were fully logged for reproducible verification.

\section{Related Work and Scope of the Contribution}\label{sec:literature}
Foundational works by Robinson~\cite{robinson} and Curry~\cite{curry} established topological signal processing and cellular sheaf invariants. Hansen and Ghrist~\cite{hansen-ghrist} develop spectral theory for cellular sheaves, including sheaf Laplacians, effective resistance, and approximation, drawing on nearly-linear Laplacian solvers such as Spielman and Teng~\cite{spielman-teng}. Bodnar et al.~\cite{bodnar} learn sheaf structures for graph neural diffusion and study heterophily and oversmoothing. These are mathematical and learning precedents; they do not supply empirical validation of this paper's swarm interpretation.

Abramsky and Brandenburger~\cite{abramsky-brandenburger} formulate contextuality as an obstruction to global sections in measurement scenarios. Car\`u~\cite{caru} shows that the associated cohomological obstruction is not a complete invariant for strong contextuality. That result concerns a different model from our real-valued least-squares system: CR-1 still characterizes membership in $\mathrm{im}(\delta_K)$ exactly, but does not by itself certify the truth of the underlying messages or their faithful encoding. Sheng et al.~\cite{sheng} study cryptographic forensic support in BFT protocols; their results concern attribution and protocol evidence, not sheaf-based sensor anomaly detection.

This paper combines four elements: (1) a proposed translation from selected swarm telemetry to cellular sheaves; (2) the partial-visibility completion residual and effective-resistance formula carried forward from Paper~7~\cite{owens-r6}; (3) a triadic interpretation of the standard Hodge decomposition and the proposed legibility ratio; and (4) an edge-removal controller with a cycle-rank termination argument. This positioning does not assert priority for all uses of sheaves in LLM systems. The operational interpretation and evaluation of the proposed extensions must be distinguished from the imported mathematical foundations.

\section{Discussion: Theoretical Boundaries, Reviewer Threat Models, and Pre-Emptive Defenses}\label{sec:discussion}

To ensure academic and operational rigor for peer review, we explicitly address the five primary attack vectors and boundary objections raised against topological methods in distributed systems:

\subsection{Threat Model 1: Simplicial Hodge vs.\ 1-Skeleton Graph Laplacians}
\paragraph{Objection:} \emph{``Is this framework merely Kirchhoff's Current Law and ordinary graph Laplacians under a different vocabulary?''}
\paragraph{Pre-Emptive Defense:} An ordinary graph Laplacian operates strictly on the 1-skeleton (vertices $V$ and edges $E$). While graph Laplacians can identify whether a potential difference exists along an edge, they have no mathematical representation of 2-cells (faces or triangles). Consequently, an ordinary graph Laplacian \emph{cannot} compute triadic curl $(\delta_1 g)$ and \emph{cannot} distinguish between a local 3-way review hallucination and a macro-network partition cavity. Only by elevating the topology to a simplicial 2-complex $X = (V, E, F)$ and computing the simplicial Hodge 1-Laplacian $L_1 = \delta_0 \delta_0^* + \delta_1^* \delta_1$ can an orchestrator derive the Swarm Legibility Ratio $\mathcal{L}(g)$, uniquely separating $\mathrm{im}(\delta_1^*)$ from $\mathcal{H}^1(X; \mathbb{R})$. Furthermore, cellular sheaves incorporate heterogeneous restriction maps $P_{v \trianglelefteq e}$, which ordinary scalar graph Laplacians cannot accommodate.

\subsection{Threat Model 2: Topological Darkness in Hierarchical Trees vs.\ Closed Cycles}
\paragraph{Objection:} \emph{``If the agent organization is structured as an acyclic tree or contains cut-edges, the completion residual is identically zero ($r = 0$). Does this render the detector useless?''}
\paragraph{Pre-Emptive Defense:} We prove this phenomenon analytically in Theorem~CR-1 (Assertion 4: Cut-Edge Silence). This is not a deficiency of the detector, but a fundamental information-theoretic law of distributed systems: in an open tree where $\beta_1(G) = 0$, the cycle space $\ker(\delta_0^T)$ is trivial ($\{0\}$), meaning any arbitrary edge discrepancy can be perfectly rationalized by a scalar vertex potential $x$. This theorem provides the exact mathematical explanation for why hierarchical delegation frameworks (e.g., LangChain, CrewAI) silently swallow agent hallucinations: open trees are provably topologically dark! By deliberately closing review loops into 3-agent triangles and gossip rings ($\beta_1 \ge 1$), the cycle matroid activates, trapping contradictions with certified non-zero residuals ($r > 0$).

\subsection{Threat Model 3: Attribution vs.\ Localization}
\paragraph{Objection:} \emph{``Does the completion residual vector $\rho$ identify which specific agent signed the lie?''}
\paragraph{Pre-Emptive Defense:} The residual records inconsistency in the observed linear constraints; it does not identify the signer responsible for an erroneous constraint. Sheng et al.~\cite{sheng} separately characterize forensic support in BFT protocols and show that it depends on the protocol and available signed evidence. Their impossibility result for secure synchronous protocols with $2t+1$ replicas is not a universal theorem about our graph model. A signature authenticates a message's signer under its cryptographic assumptions; identifying protocol culpability additionally requires the relevant conflicting evidence. Cohomological localization and cryptographic forensics therefore answer different questions.

\subsection{Threat Model 4: Multi-Equivocator Cancelling and Byzantine Collusion}
\paragraph{Objection:} \emph{``Can colluding Byzantine agents coordinate to cancel out the completion residual?''}
\paragraph{Pre-Emptive Defense:} Theorem~CR-1 guarantees that the completion residual never overstates an inconsistency: $r \le \|\varepsilon_K\|_2$. If two colluding agents on a common cycle inject equal and opposite lies ($\varepsilon_1 + \varepsilon_2 = 0$), their perturbations telescope to zero around that cycle. However, as shown in Case Study 5, in an enterprise mesh with redundant chords, cancelling circulation across one cycle introduces non-zero circulation across adjacent cycles unless the colluding coalition forms a complete global coboundary ($\varepsilon = \delta_0 x$) across the entire graph. Bounding coordinated collusion beyond the single-equivocator regime is governed by classical Byzantine quorum thresholds ($f < n/3$).

\subsection{Threat Model 5: Asymptotic Scalability vs.\ LLM-as-a-Judge}
\paragraph{Objection:} \emph{``How does sheaf cohomology scale to fleets of thousands of agents compared to existing supervisor patterns?''}
\paragraph{Pre-Emptive Defense:} For the coordinate-decoupled model, evaluating the algebraic residual requires no language-model calls once the numerical constraints are available. Theorem~CR-3 bounds approximate Laplacian solves; it does not establish hardware latency or an end-to-end cost advantage over a language-model supervisor. The existing \texttt{sheaf\_consistency\_radius.py} fixture times an unpreconditioned conjugate-gradient implementation on synthetic 3-regular graphs with 128--2,048 vertices, reporting medians of five repetitions. These measurements depend on the implementation, machine, and solver tolerance. Escalation must account for numerical approximation error and observation noise; a residual exceeding those bounds establishes inconsistency in the encoded constraints, not the cause or culpable agent.

\section{Conclusion}\label{sec:conclusion}
By lifting multi-agent swarm coordination into simplicial sheaves and discrete Hodge theory, we replace ad-hoc log parsing and expensive $O(|E|)$ pairwise cross-checks with exact topological invariants. The completion residual provides certified detection, the Swarm Legibility Ratio delivers instant micro-versus-macro triage, and the Greedy Repair Controller restores consensus in polynomial time. This establishes applied topology as a foundational control plane for autonomous multi-agent systems.
