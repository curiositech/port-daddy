## Reproduction

Use Node with `stripTypeScriptTypes` support (observed Node v26.7.0).
Copy the runner and protocol unchanged into a fresh directory under
`~/coding/tmp/`, then run from there:

```sh
node coverage_experiment.mjs --root /absolute/path/to/book-figures-reconciled --out run-01
```

The runner verifies both complete source hashes and extracts only reviewed
pure declarations. It refuses drift and existing output; each VM call has a
two-second bound. It does not import canonical modules. Both scanners are clean
stubs; redaction is identity. A VM context is not a sandbox-security claim.
Maximum input/output sizes are bounded. No paid experiment is necessary.

At a new directory the synthetic workspace path, capsule hash and approximate
byte-based token estimate may change. Compare requirement coverage, selected
source IDs, omission counters and controls; do not call path-dependent hash
differences evidence of behavioral drift. The parent run used the original
directory and consequently permits the stronger exact comparison above.
