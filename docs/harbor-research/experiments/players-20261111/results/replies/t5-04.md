- **CR-06:** The new `at` field is left out of the entry's hash, so `verify` misses an edit to it (breaks R9).
- **CR-08:** `share` takes basis points, so `LATE_FEE = 5` charges 0.05%, not 5%. A 1000-cent stake pays no fee at all.
- **CR-09:** `transfer` puts the money back into the source bond instead of the target, so nothing moves.
- **CR-10:** The draw now depends on the completion time, which the agent chooses, so an agent can move its own draw (breaks R7).
- **CR-11:** `renew` checks `now > deadline` instead of `>=`, so a claim can still be renewed at its deadline (breaks R6).
- **CR-12:** The bounty and pool values are swapped in the journal entry.
- **CR-14:** The pool's part is rounded down on its own, so the two parts can fall short of the slash: 999 splits into 249 and 749 (breaks R2).
- **CR-15:** `tail(0)` returns every entry instead of none.
- **CR-16:** `expire` no longer checks that a claim is open. It expires released or done claims and releases their stake a second time, which can free money held by other claims.
