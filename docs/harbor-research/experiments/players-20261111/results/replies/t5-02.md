- **CR-07:** `reopen` works on an audit that is already settled, so the stake can be slashed a second time (breaks R8).
- **CR-08:** the new `at` field is not part of the hash, so `verify` cannot catch an edit to it (breaks R9).
- **CR-11:** `transfer` tops up the source bond instead of the target. Its test still passes because the total does not change.
- **CR-12:** the draw now depends on the completion time, which the agent controls (breaks R7).
- **CR-13:** a claim can still be renewed when `now == deadline`, which breaks R6.
- **CR-15:** the fee of 5 is passed where basis points are expected, so it charges 0.05% instead of 5%. The fee on a 1000-cent stake is 0.
- **CR-16:** the rate check joins its two bounds with `and`, so it never fires and any rate is accepted.
