- **CR-10** (journal.py:44): `tail(0)` returns every entry instead of none.

- **CR-13** (audits.py:55): the audit draw now depends on when the agent completes the claim, so the agent can move its own draw (R7).
- **CR-14** (audits.py:89): `reopen` also works on an audit that is already settled, so that audit can be settled twice (R8).
- **CR-15** (audits.py:52): the range check uses `and`, so it can never fail and any rate is accepted.
- **CR-16** (claims.py:95): the check uses `>` instead of `>=`, so the holder can still renew at the deadline itself (R6).
