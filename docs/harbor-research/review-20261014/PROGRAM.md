## Workflow and evidence

Workflow: queued -> requested -> acknowledged -> working -> submitted -> independently checked -> integrated. Also blocked, rejected, superseded, or deferred. Evidence class is separate: conjecture, derived-under-assumptions, finite-check, reproducible-experiment, source-supported, counterexample, unresolved. Prefer the canonical manifest's vocabulary after reconciling its current definitions; do not silently create synonyms.

A finding records ID; exact source revision/anchor; quoted claim or asset; assumptions; evidence; counterexample or uncertainty; proposed minimal repair; acceptance check; dependencies; actual author/reviewer receipts; disposition/rationale. A changed shared definition invalidates approvals for affected summaries, figures, captions, exercises, answers, index entries, public excerpts, and skills. Re-run those checks at the resulting SHA.
