# Cold Reader
Read ../../COMMON-PROTOCOL.md but do not read seed verdicts, answer keys or later chapters before the assigned path. Record all context contamination honestly.
At each new concept give a short teach-back and a concrete example. Mark the first confusing sentence, missing prerequisite, misleading analogy or term used before definition. Try the stated exercises without solutions. Return coverage, misconceptions and smallest repairs. Do not pretend human user testing or scholarly expertise. This pass asks whether exposition is learnable, not whether a proof is valid or prose maximally short.
