# Harbor Coordination Papers -- Critique Ledger

Purpose: the complete inventory of every actionable item raised in the review memoranda on the
Harbor coordination papers, so "did we go through all of this" becomes a query against this
table (filter by `Status`) instead of a memory someone has to hold. Extraction only -- rows
record what a reviewer said, not whether it is right; no row implies agreement.
Id scheme: `#` is `<PREFIX>-<NNN>`, one prefix per source document below (`HAH`, `RT`, `PD`,
`RP`, `PP`, `CPR`, `XS` for the exposition-review corpus), numbered in the order the item
appears in its source. Ids are permanent -- never renumber or reuse one; retire a row via
`Status` instead.
To add a row: append it to the right source's table with the next unused number in that
source's sequence, add the identical object to `critique-ledger.json`, then run
`python3 scripts/harbor-research/check_critique_ledger.py` before committing.
`Status` and `Notes` are left blank throughout for the author to fill in (`Status` values:
empty, `DONE <sha-or-PR>`, `IN-WAVE-<n>`, or `DECLINED -- <reason>`).
See `docs/harbor-research/LIBRARY-SYSTEM.md` (forthcoming) for how this ledger fits the
broader research-library workflow.
