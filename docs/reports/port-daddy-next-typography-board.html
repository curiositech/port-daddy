02 / Role-based contract

The type system should be semantic, not page-specific.

The website needs stable typographic roles that survive page redesigns. Page templates should consume roles like display, surface title, proof, and ledger instead of inventing local sizes.

Role Size Weight Behavior Port Daddy use
Display editorial clamp(4.2rem, 3.1rem + 4.4vw, 7.4rem) 500 text-wrap: balance, tracking zero, max 11 to 13 characters. Home hero, paper hero, major feature opening.
Page title clamp(2.4rem, 1.9rem + 2.2vw, 4rem) 500 Medium weight, generous line height, never poster-huge in docs. Docs, tutorials, examples, whitepaper pages.
Surface title clamp(1.55rem, 1.22rem + 1.1vw, 2.35rem) 500 Dense enough for dashboards, drawers, bento expansions. FleetBar, Fleet Console, feature-detail modules.
Body reading clamp(1rem, 0.95rem + 0.24vw, 1.125rem) 400 text-wrap: pretty, line height 1.55, measure 45 to 65 characters. Docs prose, tutorial explanation, blog body.
UI label 0.75rem to 0.8125rem 700 All caps allowed, tracking 0.075em, no novelty font. Nav, status, captions, figure labels.
Code proof 0.94rem to 1rem 400 Tabular nums, slashed zero, output required after every command. CLI examples, docs snippets, tutorial agent layer.
Numeric ledger Depends on density 500 font-variant-numeric: tabular-nums slashed-zero. Budget, ports, sessions, claims, token cost, readiness counts.
03 / Better page mechanics

Less poster. More proof architecture.

The core improvement is not a prettier H1. It is a page system where evidence, human control, and agent execution are always visible in the composition.

Hero rule

Keep hero H1s smaller than the old comp.

Use scale for hierarchy, but cap it before it turns into a poster. The supporting proof grid should share the first viewport.

Docs rule

Surface before command.

Every docs page explains the human layer first, then the agent CLI layer. Naked pd ... examples are invalid.

Tutorial rule

Teach a real job.

A tutorial starts with the operator task, shows the Fleet Console, then proves the agent behavior through output and recovery state.

Amber rule

Amber is state, not decoration.

Amber means human review, caution, budget pressure, or readiness. Never yellow headline words. Never yellow text on beige.

Mono rule

Proof text is a product surface.

Code blocks need labels, expected output, numeric stability, and enough density to avoid huge dead terminal panels.

Dark mode rule

Do not bump weight in dark mode.

Prefer a grade axis when available. If not, use a tiny optical adjustment and verify line wraps do not move.

04 / Implementation contract

Make the trial enforceable in code.

This is the shape I would put into the website once we pick the face: one display family, one text family if needed, one mono, metric overrides, semantic roles, and no arbitrary component typography.

CSS contract sketch
:root {
  --font-display: var(--font-brand-sans);
  --font-body: var(--font-brand-sans);
  --font-proof: var(--font-brand-mono);

  --type-display-size: clamp(4.2rem, 3.1rem + 4.4vw, 7.4rem);
  --type-display-weight: 500;
  --type-display-line: 0.98;
  --type-display-tracking: 0;

  --type-page-size: clamp(2.4rem, 1.9rem + 2.2vw, 4rem);
  --type-page-weight: 500;
  --type-page-line: 1.04;

  --type-surface-size: clamp(1.55rem, 1.22rem + 1.1vw, 2.35rem);
  --type-surface-weight: 500;
  --type-surface-line: 1.12;

  --type-body-size: clamp(1rem, 0.95rem + 0.24vw, 1.125rem);
  --type-body-line: 1.55;

  --type-label-size: clamp(0.75rem, 0.72rem + 0.12vw, 0.8125rem);
  --type-label-tracking: 0.075em;
}

.pd-display { text-wrap: balance; }

05 / Recommendation

Buy one trial, then compare real pages.

Do not decide from fallback renderings. The next real decision is: install trial files for the paid candidates, rerun this exact board, and compare page behavior, not alphabet samples.

First trial Söhne because it is the most likely to improve authority without making Port Daddy cold or fashionable.
Second trial Suisse Int'l if we want a more canonical Swiss manual/documentation system.
Third trial Graphik if the blog, papers, and product essays need a more editorial product-publication feel.
Fallback Keep Radnika, but lock the role tokens and remove the Black cut from all public H1 usage.
Non-negotiable No decorative headline amber, no naked command boxes, no local typography variants in tutorial/docs components.
