Port Daddy Söhne trial direction

Use Söhne as the working brand face.

This board drops the comparison exercise. The trial direction is Söhne: Medium-weight headlines, denser proof structures, separate human and agent layers, and no decorative amber. If the trial files are not installed, this page falls back to Radnika while preserving the contract.

01 / home page

The public story becomes less poster, more operating surface.

Söhne should make Port Daddy feel like a disciplined control plane: sharp, modern, Swiss enough, and not cute. The first viewport should show claim, proof, and human entry point at once.

Agents do the work. The console keeps it accountable.

Port Daddy gives coding agents a shared place to leave intent, claim files, publish signals, and recover handoffs. Operators see launch blockers, budgets, credentials, and next actions in FleetBar and the Fleet Console.

02 / docs and tutorials

Teach the operator layer before the agent layer.

Söhne does not fix bad information architecture by itself. The docs still need a strict pattern: human surface, agent command, expected output, and the visible result in the control plane.

Human layer / Fleet Console

Approve the run from a visible control surface.

The operator reviews provider readiness, spend ceiling, launch blockers, and open handoffs. They are not asked to run routine CLI.

Human gate Choose backend, confirm spend ceiling, assign work. Ready
Handoff Attach task brief, relevant files, and acceptance proof. Queued
Review Inspect changed files, screenshots, and validation. Open
Agent layer / CLI proof

Agents leave evidence while they work.

The terminal is an agent proof surface. It must show output and the next visible state in Fleet Console.

03 / Söhne role contract

The trial succeeds only if it becomes a typed system.

The production decision is not “buy Söhne and keep all the old local font chaos.” The decision is a semantic type contract consumed by every docs, tutorial, landing, blog, and feature component.

Display 500, balanced, max 11 to 13 characters. Use for homepage, feature, and paper openings.
Page title 500, smaller than the poster comps. Use for docs, tutorials, examples, whitepaper pages.
Surface title 500, compact. Use for dashboards, bento expansions, Fleet Console references.
Body 400, line-height 1.55, pretty wrapping, measure 45 to 65 characters.
Labels 700, uppercase, tracked. No novelty second font.
Proof Mono with tabular numbers, slashed zero, and expected output after every command.
