02 / docs landing

Docs become a control-plane map.

The docs page should be dense, searchable, and honest. Commands always show expected output or observable state; conceptual pages start from the operator problem, not internal primitives.

03 / tutorial page

Tutorials teach a job, not a primitive.

Each tutorial should show the human layer in Fleet Console screenshots and the agent layer in terminal output. The reader should know who does what before seeing any command.

Human layer / Fleet Console

Approve the run from the console.

The operator checks launch blockers, budget, provider readiness, and open handoffs in the Fleet Console. They do not run CLI for routine setup.

Agent layer / CLI and notes

Agents leave evidence while they work.

Agents claim files, write notes, publish handoffs, and report validation. The terminal is proof for agents, not the operator UI.
