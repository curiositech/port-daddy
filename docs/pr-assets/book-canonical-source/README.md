# Book source download visual acceptance

Real production-build browser captures for the canonical source/download change.
Phone and desktop images show the complete download section in light and dark mode.
The phone recording exercises normal page scrolling, keyboard-accessible links,
About disclosure, chapter navigation and Back. The production download itself is
verified separately by hashing the unauthenticated response against the source receipt.

Browser regression: ten layouts across both themes, 320/390px phones, landscape,
desktop and 200% text; keyboard order through PDF, facing copy, source archive and
chapter links; 44px targets; no horizontal overflow; book-area automated accessibility
and text contrast passed. This is browser evidence, not physical-device certification.

The source archive compiles with redistributed open fonts. Published Suisse typography
requires a separately licensed font directory; private fonts are never in the archive.

The oracle-audit caption proof shows the supporting chart with its complete caption
inside the margin. All three supporting studies that failed standalone compilation
now compile. The oracle chart passes figcheck; the two standalone diagrams remain
unplaced studies with geometry findings, not publication-approved Book figures.
None of these three files is consumed by the accepted 844-page Book.
