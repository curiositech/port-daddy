# Visual Proof — `claude/white-paper-pr-review-uncpxg`

Provenance for the Reader's-map artifacts. Both images are rendered from **real
`harbor-economy.tex` builds run in this environment** — one from `origin/main`'s
source, one from this branch's — using the repository's own paper root.
`sourceLabel: real`. No fixture, no mock, no retouching.

## Why this PR needs visual proof

`VISUAL_SURFACE_RE` in `scripts/lib/user-visible-surfaces.mjs` matches anything
under `website-v2/` unconditionally, and this diff edits
`website-v2/public/whitepaper/harbor-economy.tex`. A `visual-exempt` marker is
therefore not available for this path prefix, and none is claimed. The change is
in any case a genuinely visible one: it moves a section number off a heading and
renumbers every section after it.

## What the artifacts prove, read off the pixels

- BEFORE: `1 Reader's map`, `2 The thesis...`, `3 What a "side" is...`, ..., `7 Conservation under composition`.
- AFTER: `Reader's map` (no number, still in the Contents at page 5), `1 The thesis...`,
  `2 What a "side" is...`, ..., `6 Conservation under composition`.
- Page 5's heading loses its `1`.
- Table 1's in-paper cross-references follow automatically: the founder row reads
  `S2 (thesis) -> S11 (hosted trust)` BEFORE and `S1 (thesis) -> S10 (hosted trust)`
  AFTER. Those are `\ref` resolutions, which is the evidence that no internal
  reference was left pointing at the old numbering.

## What is NOT shown, and why

The published artifact `website-v2/public/whitepaper/harbor-economy-whitepaper.pdf`
is byte-identical between `origin/main` and this branch head
(`c956105762ea44458c9867beb09b00ce79ff5584` on both), so the PDF committed in the
repository still carries the OLD numbering. The images above are local builds of
the new source, not a screenshot of a committed artifact, and are labelled as
such. `.github/workflows/whitepaper-build.yml` rebuilds and commits changed PDFs
on a same-repository PR, so the artifact is expected to be regenerated by CI on
this PR rather than by hand.

## How to reproduce

```
git archive <branch> website-v2/public/whitepaper | tar -x -C after --strip-components=3
cp -r after/. before/ && git show origin/main:website-v2/public/whitepaper/harbor-economy.tex > before/harbor-economy.tex
( cd before && latexmk -pdf -interaction=nonstopmode -halt-on-error harbor-economy.tex )
( cd after  && latexmk -pdf -interaction=nonstopmode -halt-on-error harbor-economy.tex )
```

then render page 3 and page 5 of each with PyMuPDF at `Matrix(150/72, 150/72)`.
