# Rube Goldberg machines built from cascading pd tubes

Eight concrete patterns the tube->spawner router unlocks once tubes **cascade** and
every spawn carries a loop-guarded `delegationChain`. Each chains multiple
backends across multiple channels, tiers cheap-local (ollama) up to cloud
(gemini/claude/codex), and names the exact moment a loop guard (depth /
ping-pong / fan-out budget / blocked-upward) keeps it from running away.

> Generated by a claude-cli agent spawned through the router itself
> (`backend: claude-cli`, $0 marginal) — the feature brainstorming its own uses.

---

## 1. THE TEST WHITTLER

**Chain:**
`failing:tests` → **ollama** (triage: flaky vs real regression) → `real-failures` → **codex** (write minimal fix) → `verify:fixes` → **ollama** (diff sanity + regression check) → `pr:ready`

**Payoff:** CI red doesn't page a human. Ollama filters the noise (flaky = requeue, real = escalate). Codex writes the fix only for confirmed regressions. The whole loop runs in the background on every push.

**Loop-guard moment:** Codex can't re-delegate back up to `failing:tests` when it can't reproduce the regression — depth cap fires at hop 4, emits to `triage:human` instead of spawning another triage agent.

```bash
pd tube publish failing:tests "$(cat test-output.json)"
```

## 2. THE ADVERSARIAL REVIEWER

**Chain:**
`pr:diff` → **fan-out × 3 ollama** (correctness / security / perf lenses, parallel) → `converge:review` → **claude-sonnet** (synthesize conflicts, write final verdict) → `pr:comment`

**Payoff:** Three cheap local reviewers in parallel run in ~10s. The synthesizer only fires once all three fan-out slots resolve. Disagreements between lenses surface as explicit conflicts in the PR comment rather than average-wash prose.

**Loop-guard moment:** Global fan-out budget (3) stops the synthesizer from spawning its own reviewer fleet when it disagrees with one ollama finding. It must resolve disagreements with what it has.

```bash
pd tube publish pr:diff "$(gh pr diff 314)"
```

## 3. THE CRASH ARCHAEOLOGIST

**Chain:**
`crash:log` → **ollama** (parse stack, name 2-3 suspect functions) → `reproduce:attempt` → **codex** (write minimal repro script) → `verify:repro` → **ollama** (exec repro, confirm crash fires) → `fix:write` → **claude-sonnet** (write real fix + test) → `pr:patch`

**Payoff:** A production 500 becomes a merged PR with no human ever reading a stack trace. Codex writes throwaway repro scripts; claude-sonnet writes the actual fix only after the crash is confirmed reproducible — avoiding wasted cloud tokens on phantom bugs.

**Loop-guard moment:** Structural ping-pong detection fires if codex→ollama→codex→ollama bounces more than twice on the same crash signature. Breaks the loop, escalates to `crash:human-review` with full chain attached.

```bash
pd tube publish crash:log "$(tail -50 error.log)"
```

## 4. THE DOC ROT HUNTER

**Chain:**
`docs:scan` → **ollama** (extract all `code ref` claims: "function X returns Y") → `claim:verify` (one message per claim, fan-out) → **ollama** per claim (grep actual source, confirm or refute) → `stale:claims` → **gemini** (batch-write corrections as diff) → `pr:docs`

**Payoff:** Catches the silent rot where the docs say `fetchUser()` returns `{id, name}` but the code now returns `{userId, fullName}`. Runs nightly. Gemini only sees the stale ones, not the whole doc corpus.

**Loop-guard moment:** Fan-out budget prevents one doc page from spawning 400 per-sentence ollama agents. Budget = 50 per run; overflow emits to `docs:backlog` for next night's run.

```bash
pd tube publish docs:scan "$(find docs/ -name '*.md' | xargs cat)"
```

## 5. THE SECURITY BOUNTY HUNTER

**Chain:**
`security:scan` → **fan-out ollama** per module (injection / auth / crypto lenses) → `findings:raw` → **ollama** (dedup + severity triage) → `findings:confirmed` → **claude-sonnet** (write CVE writeup + patch) → `pr:security` (draft, not auto-merge)

**Payoff:** Full codebase security audit costs roughly $0.00 (all ollama) unless a real finding is confirmed — only then does a cloud token get spent writing the writeup. You get a free Bandit/Semgrep-style scan with narrative.

**Loop-guard moment:** Fan-out budget fires hard when pointed at a monorepo (could spawn 800 agents). Budget = 40 per invocation; overflow queues onto `security:backlog` so the next run continues from the module boundary.

```bash
pd tube publish security:scan "$(ls src/)"
```

## 6. THE LIVING CHANGELOG

**Chain:**
`git:push` → **ollama** (diff → plain-English bullet summary) → `changelog:draft` → **gemini** (enrich with context from recent issues, propose semver bump) → `changelog:review` → **ollama** (strip jargon, flag vague bullets) → `changelog:final` → append to `CHANGELOG.md` + publish to `pr:changelog`

**Payoff:** CHANGELOG.md stays honest and current automatically. Gemini adds the "why this matters" context that commit messages never have. The final ollama pass is the copy editor that catches "refactor internals" cop-outs.

**Loop-guard moment:** Ping-pong detection blocks the jargon-checker from routing "unclear bullet" back to gemini for re-enrichment in a loop. After one enrichment pass it must accept the output or flag for human.

```bash
pd tube publish git:push "$(git log -1 --format='%H')"
```

## 7. THE ON-CALL WHISPERER

**Chain:**
`alert:fire` → **ollama** (classify: DB? network? code? infra?) → `runbook:{category}` → **codex** (read runbook + recent git log, draft patch or config change) → `verify:patch` → **ollama** (static sanity: does patch touch the right files?) → `oncall:gate` (human approval required before apply)

**Payoff:** On-call engineer wakes up to a classified alert, a runbook excerpt, a proposed patch, and a one-line sanity verdict — not a raw PagerDuty ping. They approve or reject; the machine never self-merges.

**Loop-guard moment:** Upward delegation is blocked — codex cannot spawn a new alert classifier when it encounters ambiguity. It must emit a `?` verdict to `oncall:gate` and let the human sort it. No recursive triage loops.

```bash
pd tube publish alert:fire "$(cat pd-alert.json)"
```

## 8. THE DEBT SNAKE

**Chain:**
`debt:scan` → **ollama** (inventory TODOs + estimate LOC effort: small/medium/large) → `debt:small` **→ codex fan-out** (fix each small TODO in parallel worktrees) + `debt:medium` **→ claude-sonnet fan-out** → `verify:all` → **ollama** (confirm test suite still green per worktree) → `pr:debt-batch` (squash all passing worktrees into one PR)

**Payoff:** Technical debt that lives forever because "it's too small to prioritize" gets eaten automatically on a weekly cron. Codex handles the rote stuff; claude-sonnet handles the nuanced refactors. One PR, one review, done.

**Loop-guard moment:** Fan-out budget (20 concurrent worktrees max) stops it from spawning one agent per TODO comment in a 10-year codebase. Overflow lands on `debt:backlog` for next week's snake run. Depth cap stops a fixed TODO from re-entering the scanner and being "fixed" twice.

```bash
pd tube publish debt:scan "$(grep -rn 'TODO\|FIXME\|HACK' src/ | head -200)"
```
