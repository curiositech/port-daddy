Ship Grammar

IDENTITY → ShipPlan → SIDE-PROFILE SVG · LIVE 3D IN THREE.JS

Given <fleet_prefix>:fleet:<agent_name>, a pure function produces ship geometry: hull dimensions, core color, sigil, trim, towers, nacelles, clusters. Commonality from the agent name (silhouette). Drift from the fleet prefix (livery). 864 distinguishable fleet signatures with only 4 palette colors + 8 sigils.
