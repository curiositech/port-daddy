Click a ship to select it — its core emissive lerps to its primary color. In the full pipeline, a BloomPass picks that up and a Bayer 8×8 DitherEffect quantizes the result to the 5-color palette, giving the chunky pixel halo we want. This v0 is lit but undithered; see COMPONENT-BRIEF.md §R3F for the full pipeline and SHIP-GRAMMAR.md §6 for motion + material semantics.
Vanilla Three.js (no React) for portability. Production scene is R3F with <EffectComposer> + <BloomPass> + <DitherEffect>. Mesh geometry is identical — the grammar's plain-data ShipPlan drives both.
