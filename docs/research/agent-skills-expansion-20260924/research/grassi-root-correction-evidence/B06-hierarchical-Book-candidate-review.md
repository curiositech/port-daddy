Goal G: classify evidence for candidate revision r, not merge it. Plan: identify r; compare receipt revision; if mismatched classify stale; if matching inspect suite/scope and outcome; classify failed, current-within-scope, or unknown. A request to run tests is a separate authorized workflow, outside this exercise.

## Extension C: composition preserves a specified interpretation

**Placement:** optional Trace alongside Anchor `ex:anchor-model-vs-code`, 1446 onward, or the existing semantic-integration exercise. Reader asks which equality was proved and which implementation obligation remains.

Use typed operations h:X→A1, g:(A1,A2)→B, f:(B,C)→D with a fixed slot map. In a compatible Set interpretation on integers, h(x)=x+1, g(u,v)=u+v, f(w,c)=wc. ## Terminology boundary for HTP

Gui et al.'s May 2025 HTP uses a task-specific rule library and hierarchical outline, then refinement and content integration. A parent-to-child-set rule does not by itself establish independence or worker parallelism. Keep construction and content generation distinct. [Gui et al., v1, §§3–4](https://arxiv.org/html/2505.02322v1). Luna's detailed algorithm/benchmark audit is inherited; no aggregate performance claim is imported here.

Formal query/CSP hypertree decomposition instead uses a decomposition tree, variable bags, covering hyperedges and structural conditions, with a defined width; the connection to query tractability is theorem-specific. [Gottlob–Leone–Scarcello primary report](https://arxiv.org/abs/cs/9812022), [MFCS survey, Definition 11](https://www.dbai.tuwien.ac.at/proj/games/papers/mfcs2001.pdf). This source depth is inherited from Luna. Pilot context clusters are local execution doctrine. These three meanings need a terminology note if co-mentioned, not a new Book result; no claim of exhaustive competing literature or global novelty is made.
