## Research anchors and limits

- Theorem source: [Dilworth, “A decomposition theorem for partially ordered sets” (1950)](https://scispace.com/papers/a-decomposition-theorem-for-partially-ordered-sets-9m9h6qxi0l), bibliographic/abstract metadata only in this pass; theorem: for a finite poset, minimum chain-cover size equals maximum antichain size. The skill must identify the poset relation and not infer weighted schedule optimality from the theorem. A [1970 paper on chain decomposition](https://www.sciencedirect.com/science/article/pii/S002198007080059X) was opened for statement of Dilworth relation, not used as a substitute for original.
- DAG scheduling: [Graham’s greedy scheduling bound as stated in a current paper](https://link.springer.com/article/10.1007/s11241-020-09346-z) opened; the bound assumes a work-conserving greedy scheduler and the paper states a specific model. It is not evidence of real agent duration, communication, setup, or interference costs. Work/span discussion also appears in [CMU course notes](https://www.cs.cmu.edu/afs/cs/academic/class/15210-f17/www/concurrency.html), secondary teaching material.
- Operad primary sources opened at arXiv: [Spivak, wiring diagrams](https://arxiv.org/abs/1305.0297) supports composition/hierarchy of wiring diagrams, relations and recursive circuits; [Vagner, Spivak & Lerman, open dynamical systems](https://arxiv.org/abs/1408.1598) supports a specific operad/algebra semantics for interconnected dynamical systems. Neither proves arbitrary multi-agent task correctness, authority or runtime behavior.
- [Stanton, “Hierarchical task analysis: Developments, applications, and extensions” (2006)](https://doi.org/10.1016/j.apergo.2005.06.003): source identity and abstract/text excerpts were opened; it describes HTA as a goal/sub-goal representation used for further analysis, with analytical stopping tied to the purpose. Full publisher paper not independently obtained in this pass.
- No manuscript search was performed. All Book candidates below are leads, not novelty findings.

### `dag-chain-decomposition` — 226 lines; 9 refs; 5 ASCII candidates
**Source/access depth:** full skill; inspect primary theorem sources above; exact “Chen’s stratification” source was not resolved and must be verified before retaining. **Practical extension:** state finite poset assumptions and define dependency order; compute maximum antichain/minimum chain cover only if relevant. This gives a lower bound on the number of chains, not minimum agents, makespan, or best weighted schedule when tasks have durations/resources/communication. The worked microservice example’s claimed width 6 and “minimum agents needed = 6” require actual poset listing/proof and are not established by its narrative. Replace width heuristics with a small explicit graph and machine-checkable chain cover plus antichain witness. **Worked trace:** nodes A,B,C,D with A→C, B→C, C→D: cover `{A,C,D},{B}` and antichain `{A,B}` establish width 2; scheduling capacity still measured separately. **Diagrams:** poset/chain cover with antichain witness; weighted schedule Gantt/resource view. **ASCII:** 5 candidate blocks; inspect 9 refs for diagrams and source. **Book lead:** separate order-theoretic lower bounds from execution capacity; manuscript absence unknown.

### `dag-dynamic-replanner` — 184 lines; 0 refs; 4 ASCII candidates
**Source/access depth:** full skill only; no referenced research/source bibliography. **Practical extension:** treat changes as versioned proposals against a DAG snapshot; validate cycle freedom, node contracts, already-committed outputs, idempotency, resource constraints and downstream invalidation before atomic publish. Never mutate executing state implicitly; define cancel/drain/compensate policy. Thresholds `<3`, `3–5`, `>5` affected nodes, 120%/150% resource budgets and `<50%` critical-path increase are unsubstantiated local heuristics; remove or mark configurable hypotheses measured against a workload. “Retry with increased timeout” requires retry safety/idempotency and a bounded budget. **Worked trace:** failure in an upstream dependency proposes a fallback; validator finds schema mismatch, rejects proposal, preserves old graph version, routes to operator. **Diagrams:** graph revision transaction state machine; invalidation/recovery graph with immutable run snapshot. **ASCII:** 4 candidate blocks. **Book lead:** auditable replanning transaction and downstream invalidation; manuscript absence unknown.

### `dag-fast-decomposition` — 251 lines; 7 refs; no ASCII candidate
**Source/access depth:** full skill plus refs `width-as-coordination-complexity`, `transitive-structure-as-compression-opportunity`, and `constant-time-reachability-through-indexing`; source claims “85–95% transitive edges,” “5–10% of optimal,” 10–20x compression and O(1) query need primary-paper/algorithm identity and benchmark details before use. **Practical extension:** separate known theorem/algorithm complexity from workload measurement; specify graph class, reduction algorithm, index, update regime, memory, query mix and correctness check. ### `hypertree-planning` — 250 lines; 7 refs; no ASCII candidate
**Source/access depth:** full skill and high-level refs on branching/context partitioning; exact empirical source behind depth/error accumulation and “hypertree” advantage needs review. **Practical extension:** call hypertree a planning representation/hypothesis unless a result is formalized; quantify dependency depth, cut cost, context duplication, merge risk and evidence handoff. ### `operad-task-decomposition` — 282 lines; 0 refs; 0 ASCII candidates
**Source/access depth:** full skill; primary Spivak and Vagner–Spivak–Lerman sources opened, plus inherited quality gates. **Practical extension:** the skill correctly warns that an operad models compositional syntax and an algebra provides semantics; retain that boundary.
