# B08 — Orchestration and execution research

**Coverage:** all 12 B08 targets. Each full skill body reviewed; no product implementation execution. Main-file candidate ASCII counts below are inventory leads only; support documentation still needs conversion review. No skill/catalog files edited.

## Source anchors and limits

- [W3C PROV-O](https://www.w3.org/TR/prov-o/) was opened for provenance vocabulary (entity/activity/agent relations), not for proof that an output is true.
- [JSON Schema 2020-12 core](https://json-schema.org/draft/2020-12/json-schema-core) was opened as a schema contract reference; schema validity proves structural conformance only.
- [OpenTelemetry trace semantic conventions](https://opentelemetry.io/docs/specs/semconv/) was opened for telemetry naming; convention does not guarantee coverage, causal completeness, or observability of all effects.
- Across these skills, many numeric thresholds (confidence 0.6, impact 0.1, max 10 parallel nodes, 3 retries, 5% overhead) are unreferenced. Treat as defaults to remove or label local, configurable and experimentally justified. A retry must be conditioned on idempotency, side-effect state and a bounded retry budget.

### `dag-hallucination-detector` — 168 lines; 0 refs; 1 ASCII candidate
