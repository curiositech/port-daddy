## Evidence anchors

- Typed dependency workflows should distinguish readiness/data edges from preference/order edges. This is a proposed modeling discipline; it does not follow from DAG acyclicity alone.
- B07’s main measurable trap is false precision: generic confidence cutoffs, fixed parallelism percentages, and token budgets are not portable without calibration. For probability statements, define an event/outcome, collect held-out predictions and labels, and measure calibration separately from ranking accuracy. Avoid treating an LLM self-reported confidence as a probability.
- Relevant current references opened: [CloudEvents 1.0 specification](https://github.com/cloudevents/spec/blob/v1.0.2/cloudevents/spec.md) for event identity/context semantics (not workflow correctness); [W3C PROV-O](https://www.w3.org/TR/prov-o/) for provenance entities, activities and agents (not proof of truth); [OpenTelemetry trace semantic conventions](https://opentelemetry.io/docs/specs/semconv/) for trace/span attribute conventions (not proof that a trace is complete). These constrain terminology only.
