# Activation cases

Activate this skill to partition an already-defined, trust-typed context inventory across already admitted targets.

Do not activate it to choose worker count from provider quota, issue a dispatch, select a lifecycle action, or turn context pressure into a spawn recommendation. Those are outside the bundle contract.

Use the supplied inventory's completeness flag. Missing required item or target evidence returns UNKNOWN; known incompatibility or insufficient capacity returns INFEASIBLE. A FEASIBLE proposal remains relative to the supplied root and does not imply successor admission.
