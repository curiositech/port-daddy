# Model checking and satisfiability ask different questions

## Scope

Model checking asks whether a formula holds in a supplied model. Satisfiability asks whether some model satisfies a formula. Neither result substitutes for the other.

## Method and fixture

For surveillance design, satisfiability can explore whether a specification is internally possible under a formal vocabulary; model checking evaluates a chosen camera model. Complexity claims require the exact logic fragment.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
