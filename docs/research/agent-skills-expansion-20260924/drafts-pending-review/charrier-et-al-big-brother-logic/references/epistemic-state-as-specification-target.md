# Epistemic state as a specification target

## Scope

Specify both world facts and knowledge facts: for example, an object is visible, camera i knows it is visible, and a group knows a report was received. Each predicate needs an observation or transition definition.

## Method and fixture

Model checking answers whether the formula holds in the declared finite model. It does not establish that the model captures noisy deployments or privacy obligations.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
