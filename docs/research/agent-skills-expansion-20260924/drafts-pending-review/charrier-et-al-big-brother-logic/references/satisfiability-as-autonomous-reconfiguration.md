# Satisfiability is not autonomous reconfiguration

## Scope

A satisfiability result says a formula has a model in a logic. It does not choose, authorize, or execute a camera reconfiguration.

## Method and fixture

A reconfiguration controller needs state transitions, resource/authority checks, and observed postconditions. The paper’s stationary model should not be presented as a mobile-controller algorithm.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
