# Satisfiability and perceptual planning

## Scope

Planning requires actions, goals, transitions, observations, costs, and stopping conditions. Satisfiability may test logical possibility in an abstract vocabulary, but it is not a complete planning algorithm.

## Method and fixture

For a camera orientation change, state allowed rotations and observation update. Mark the result as an illustrative extension because mobile-camera analysis is future work in the paper.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
