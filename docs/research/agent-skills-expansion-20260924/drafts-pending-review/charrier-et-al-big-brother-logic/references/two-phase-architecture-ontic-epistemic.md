# World state and epistemic state

## Scope

Separate ontic transitions (what changes in the modeled world) from epistemic transitions (what agents learn). A report can change knowledge without changing the observed object; an action can change an object without informing every agent.

## Method and fixture

This separation makes it possible to test formulas against a finite model and to identify missing observation/communication assumptions.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
