# Perception as a modeled knowledge foundation

## Scope

A perception relation maps world states to possible observations. Knowledge follows from which worlds remain compatible with an observation; it does not follow merely from sensor availability.

## Method and fixture

Use the stationary-camera abstraction only when its geometric and exact-position assumptions hold. Sensor confidence scores need a different probabilistic or nondeterministic model.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
