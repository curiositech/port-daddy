# Common knowledge requires a protocol

## Scope

Common knowledge C_G p is stronger than every participant knowing p. It is a property of reachability in a possible-world model, not a synonym for broadcast or shared storage.

## Method and fixture

A failed acknowledgement can leave E_G p false or leave higher-order uncertainty even when a message was delivered. Model delivery, receipt, and awareness separately before diagnosing coordination.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
