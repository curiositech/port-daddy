# Public announcement as model restriction

## Scope

In public-announcement logic, announcing p restricts a model to worlds where p holds. This semantic operation presumes a truthful, publicly received announcement in the formal model.

## Method and fixture

Implementation logs can support an abstraction but do not automatically justify model restriction. If some recipients may miss the message, use individual or distributed update relations instead.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
