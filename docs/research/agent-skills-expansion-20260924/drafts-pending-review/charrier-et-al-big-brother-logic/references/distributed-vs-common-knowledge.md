# Individual, distributed, and common knowledge

## Scope

K_i p concerns one agent's alternatives. Distributed knowledge combines information partitions; common knowledge closes mutual knowledge under repeated accessibility. State the group and the relations before using any operator.

## Method and fixture

Compute on a finite model by enumerating the accessible worlds. A real distributed service needs a justified abstraction from its observations to these worlds.

## Evidence boundary

This reference distinguishes a formal or constructed model from observed runtime behavior. Record model version, inputs, assumptions, and outcome evidence before drawing a conclusion.
