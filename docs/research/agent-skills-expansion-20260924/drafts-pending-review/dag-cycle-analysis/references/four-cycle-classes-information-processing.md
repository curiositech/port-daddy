# Generalized cycle classes

After restoring directed metadata and contracting eligible neutral wedges:
feedback is a directed-cycle defect; shortcut has a direct source-to-sink edge;
diamond has one indirect source/sink pair and intermediate antichain; mixer has
multiple source/sink pairs and non-unitary source/sink antichains. These are
paper-defined structural images. “Resilience,” “mixing,” or “barrier” remain
hypotheses needing independent runtime evidence.
