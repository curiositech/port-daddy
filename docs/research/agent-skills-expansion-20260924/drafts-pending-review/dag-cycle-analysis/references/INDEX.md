# Cycle-analysis references

All notes apply the paper-specific method in the active skill. They preserve
structural definitions and hand checks while excluding runtime/synchronization
claims. The primary source is [Vasiliauskaite, Evans & Expert 2022](https://discovery.ucl.ac.uk/id/eprint/10154887/1/1-s2.0-S0378437122001340-main.pdf),
whose full body was inspected in the inherited source ledger.

- `when-does-dag-analysis-apply.md`: graph and metadata assumptions.
- `minimal-cycle-basis-as-mesoscopic-descriptor.md`: circuit rank, MCB identity,
  algorithm provenance, and non-uniqueness.
- `four-cycle-classes-information-processing.md`: the four contracted classes.
- `antichains-and-hierarchical-coordinates.md`: incomparability, height, stretch,
  and cycle coordinates.
- `metadata-localizes-topology.md`: orientation metadata and descriptive metrics.
- `transitive-reduction-information-minimization.md`: reachability preservation
  and changed cycle space.
- `dag-decomposition-for-hierarchical-reasoning.md`: reporting procedure.
- `failure-modes-hierarchical-analysis.md`: counterexamples and stop conditions.
