# Cycle-space basis

For an underlying graph, circuit rank is `E−N+n_c`. An MCB minimizes total cycle
length among cycle-space bases; it can be non-unique. Log graph identity,
algorithm/library/version, seed/tie treatment, selected edge sets, and any
across-run descriptor variation. The paper uses De Pina. “Fundamental” must be
scoped to the selected algorithm/paper statement, not used as a tautological
MCB definition.
