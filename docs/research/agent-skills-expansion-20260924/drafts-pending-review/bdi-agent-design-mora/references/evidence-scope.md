## What it supports

It supports the source-specific concepts used in `bdi-agent-design-mora`. The skill deliberately avoids treating it as proof of a universal threshold, security property, legal conclusion, commercial comparison, or local runtime result.

## Use rule

For a current framework or provider claim, re-open the authoritative documentation on the implementation date and record the checked version or update date. For local behavior, attach a reproducible test and observed receipt.
