See [the semantic briefs](../../BOOK-FIGURE-BRIEFS-3-5.md) and [Astra review](../../ASTRA-BOOK-REVIEW.md) for exact placement, reader questions, evidence, counterreadings and required tests. These are constructed teaching examples and proposed contracts, not new empirical results.

The TikZ ports use a judge/evidence/error matrix, a receipt-invalidation table, and a textual-overlap/integration-outcome matrix, respectively. Each preserves the relations in its Mermaid source while replacing the generic flow layout with the appropriate Book grammar. Stable IDs: `draft/judge-dependence-premises`, `draft/typed-plan-revision`, `draft/conflict-four-cells`.

Standalone rendering and manuscript integration require separate receipts.
