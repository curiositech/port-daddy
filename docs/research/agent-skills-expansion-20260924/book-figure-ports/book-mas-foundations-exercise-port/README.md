## Meaning and arithmetic

The constructed game has pure equilibria (A,A) and (B,B), with unilateral deviation payoffs 0 from own payoffs 3 and 2 respectively. (B,B), total payoff 4, refutes the claim that every Nash equilibrium has sum at least 5. This counterexample remains valid when mixed equilibria are allowed; the enumeration itself covers pure profiles only. A capacity of one on A makes (A,A) infeasible. We intentionally do not solve an underspecified revised game. Observation, authorization and effect confirmation remain separate operational duties. payoff-checks.json records exact enumeration. No new theorem or empirical novelty is claimed.
