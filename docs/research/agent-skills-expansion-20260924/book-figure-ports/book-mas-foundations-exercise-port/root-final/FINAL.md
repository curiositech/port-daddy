# Swiss-only multi-agent foundations worksheet candidate

This PR retains one Swiss TikZ/page worksheet as a planning draft. No manuscript integration or teaching efficacy is claimed, and rendered PDFs/PNGs are kept outside the repository.

The constructed payoff matrix has two pure Nash equilibria: (A,A) and (B,B). The (B,B) payoff sum of four refutes the proposed universal sum-of-five claim. Changing capacity to allow at most one worker to choose A makes (A,A) infeasible, so its old equilibrium certificate cannot be reused; no new game is solved by that observation. Execution authority remains a separate question.

Earlier offline review checked arithmetic, geometry, fonts, and a Swiss page preview. The current PR retains source and receipts only, so a new compile and visual inspection against the active Book preamble are required before placement. PyMuPDF figcheck and full-book certification remain unproven.
