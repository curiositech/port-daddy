# Agent-related skills worth exploring

All 755 requested source entries are represented in the reconciled worktree. The per-entry judgments are in [the full CSV catalog](skill-catalog.csv), [A–M inventory](a-m-inventory.json), and [N–Z inventory](n-z-inventory.json). Categories are agent judgments based on the entrypoints and supporting content; reference counts measure bundled depth, not accuracy or proven usefulness.

The inventory groups 152 entries as core agent systems/theory, 36 as adjacent decision research or agentic product planning, 171 as broad development support, and 396 as general-domain/design skills. This distinction keeps a large cloud-provider reference library from being mistaken for an agent-coordination theory skill.

Below is a curated starting shelf, not an exhaustive list. Counts exclude navigation indexes and machine caches. See the research reports for the selected skills strengthened after this initial inventory. Counts below and in the CSV were refreshed after the research pass.
