### P1 — FormalJudge reference attributes invented Lean results to a placeholder citation

[`skills/provable-action-adjudicator/references/formaljudge-zhou-2026.md:3`](../../../skills/provable-action-adjudicator/references/formaljudge-zhou-2026.md#L3), especially lines 9–19 and 23–33, says the source is `arxiv:2026.XXXXX, pending`, then attributes a Lean 4 pipeline, Claude Opus 3.7/GPT-5-mini experiments, 91%/74% syntactic-validity results, and microsecond checks to that paper. The actual primary paper titled *FormalJudge: A Neuro-Symbolic Paradigm for Agentic Oversight* is [arXiv:2602.11136](https://arxiv.org/abs/2602.11136); its abstract describes Dafny specifications with Z3 solving and reports different results (16.6% average improvement, seven agent models, and a deception-detection result). It does not support the Lean pipeline or 91%/74% metrics. The separate [Lean-Agent Protocol paper, arXiv:2604.01483](https://arxiv.org/abs/2604.01483), is a different source and its own claims do not validate the FormalJudge numbers. **Minimal correction:** replace the placeholder and rewrite this reference from the actual paper, removing unsupported numbers and Lean integration claims; keep any proposed integration as an explicitly local hypothesis.

### P1 — Operad laws are presented as runtime and behavioral guarantees

[`skills/operad-task-decomposition/SKILL.md:145`](../../../skills/operad-task-decomposition/SKILL.md#L145), lines 159–163, 212–213, 234, 347, and 381 overstate what the algebra establishes. Associativity is an equality of composites in an operad (and of their interpretations only in a compatible algebra); it does not ensure an arbitrary LLM/task execution returns the same result under changed delegation. Associativity is not “approximate” merely because a task operation is nondeterministic. Acyclicity is a useful restriction for a DAG workflow, not what distinguishes an operad from a category. A type-compatible graph likewise does not prove runtime safety or that a scheduler has reached its maximum feasible parallelism. These claims survive the source merge and are central to the skill's practical guidance. **Minimal correction:** retain the typed-composition model, but state DAG/runtime constraints as chosen workflow assumptions and require a semantics/effect model before inferring result equivalence, safe substitution, or parallelizability.
