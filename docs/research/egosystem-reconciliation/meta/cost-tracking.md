# Cost and Complexity Envelope

The budget is expressed as bounded reasoning work, not a fabricated dollar total. Provider and model costs are not assumed without a current price source and an actual configured backend.

## Cost controls

- Reuse current repository truth and primary sources; do not ask multiple agents to repeat the same inventory.
- Reserve multi-agent work for divergent judgment, adversarial review, and fresh-eyes checks.
- Keep implementation out of scope so no speculative runtime branches or migrations are created.
- Stop a research lane once it has sourced the decision-relevant claim; collect no broad personal or organizational history.
- Discount novelty that does not change user value, authority, risk, or implementation order.
- Prototype only replacement previews needed to test comprehension.
- Record uncertainty instead of buying more inference when the missing fact requires human authority.
