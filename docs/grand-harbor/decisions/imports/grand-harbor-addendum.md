## Motivation preserved

The addendum reframes the product around one durable program authority rather than scattered roadmap, issue, document, chat, and runtime truths. Chartroom is intended to hold one hypertree that preserves:

- exact source revision;
- owner and authority;
- implementation truth;
- dependencies;
- disposition;
- proof/evidence;
- Now / Next / Later projections.

It identifies authority, identity, and evidence as the critical path. It proposes the causal vocabulary:

```text
Stimulus → Perception → Governed action → Durable evidence
Genesis → Voyage → Wake → Logbook → Receipt
```

It treats operator surfaces as projections of one authority, not independent stores. Apple virtualization is an optional containment tier, not the definition of Harbor.
