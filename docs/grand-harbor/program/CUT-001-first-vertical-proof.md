# GH-CUT-001 — First vertical proof

**Status:** PROPOSED FUNDED CUT  
**Desired result:** Erich makes and proves one tiny live-browser change using pd-console as the workplace while the architecture survives interruption and body loss.

## Scenario

Erich tells Builder to make a small change to a live browser app. Chartroom captures and accepts the intention. Builder claims the component. Erich interrupts with a second idea; the first commitment remains. Nemesis claims the test seam. Builder's body dies and a provider-neutral successor proves continuity. A prior contrary decision opens a Parley. Builder requests a narrowly scoped GitHub write. The adjudicator issues a target-bound permit; the actuator holds the credential and performs read-after-write observation. The browser embodiment demonstrates the behavior. Porthole reconstructs the evidence chain. The operator makes the outcome judgment.

## Failure variants required

- provider accepts the GitHub request, then the connection dies;
- test evidence belongs to a stale head;
- new instruction contradicts rather than refines;
- pheromone recommends an unauthorized actor;
- body returns after resurrection;
- permit is present at body loss but inheritance policy is unresolved;
- GitHub publication succeeds while browser acceptance fails;
- claim becomes stale and requires salvage;
- replay is opened during a live session.

## Exit criteria

- GH-P-001 through GH-P-006 and GH-P-008 pass at exact revisions or each missing link is explicitly named;
- pd-console is sufficient for capture, work, action judgment, evidence, and outcome judgment;
- disabling pheromones changes no hard decision;
- no reusable secret enters a body process;
- every external effect is denied, permitted/observed, partial, or indeterminate—never merely “probably done.”
