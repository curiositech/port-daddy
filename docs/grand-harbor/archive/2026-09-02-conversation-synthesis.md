## Product shift preserved

The older center of gravity was daemon + sessions + agents + claims + Fleet + Git workflow + context. The proposed center is a trusted authority/evidence kernel controlling replaceable cognitive bodies and real-world effects.

The primary object shifts from a task to a durable program of intentions, actors, resources, commitments, governance, budgets, and evidence. Context hints remain a cognitive-assistance plane; they are no longer asked to enforce safety. pd-console shifts from terminal monitor to the workplace. The market becomes the same replaceable-extension seam used locally rather than a bolted-on second product.

## The anti-drift correction

The conversation itself exposed its failure mode: a chat answer presents a sampled, locally coherent view, does not edit shared authority, and can sycophantically replace a hard-earned constraint when an attractive edge case arrives.

The response was the architecture-ledger pattern now implemented by this folder:

- difficult-to-overturn invariants;
- one vocabulary and authority map;
- executable contract registry;
- relationship classification for every new idea;
- open questions and irreducible tensions;
- protected hypotheses for weird ideas;
- evidence-backed maturity;
- dependency graph rather than narrative roadmap;
- Erich-centered acceptance experiences;
- machine-readable skill grafts;
- a completionist review profile;
- repository state now, signed Chartroom authority later.

## Corrections made during repository audit

The earlier conversation over-described some status:

- Claim-tree ADR-0038 is proposed, and the runtime landed differently as Claim Forest; it is not simply an accepted future design.
- Non-forgeable identity ADR-0040 is proposed despite substantial implementation; universal write gating is missing.
- Pheromones already have narrower local runtime and tests, not merely research, but full diffusion is not present.
- Parley is already a substantial durable protocol runtime; FIPA work should graft into it, not replace it.
- Relay is already substantial; the missing part is not “build Relay from nothing,” but stronger grant/evidence semantics and proof of current deployment.
- Porthole replay and Agent Harbor event/evidence substrates exist separately; the evidence explorer is the unbuilt join.
- Chartroom remains largely intended/draft authority, so this ledger must not call itself canonical Chartroom state.
- Generic `ActionIntent/Permit/Receipt` symbols and actuator interface are absent on main despite real governance gates and receipts.

Those corrections are part of the preserved motivation: the ledger exists to force future prose to confront code and decision status.
