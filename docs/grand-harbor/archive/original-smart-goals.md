| Parley | By 2026-11-15, convert three real contradictions into structured protocols |
| Actuator boundary | By 2026-11-30, mediate GitHub, shell/process, filesystem, and actor spawn |
| Receipts | By 2026-11-30, every significant “done” reaches evidence or an honest gap |
| Porthole | By 2026-12-15, replay a real feature from instruction to publication |
| Stigmergy | By 2026-12-15, display decaying activity/risk/opportunity without changing authority |
| Claim topology | By 2026-12-15, expose concurrent semantic work and unsafe overlap |
| Convoy workstation | By 2026-12-31, ship one app without a provider coding UI as the primary workplace |
| Relay | By 2027-01-31, cooperate across another machine and another human through explicit grants |
| Skills | By 2027-01-31, compare replaceable cognitive modules with versioned selection evidence |
| Evaluation | By 2027-02-28, improve held-out selection through witnessed outcomes |
