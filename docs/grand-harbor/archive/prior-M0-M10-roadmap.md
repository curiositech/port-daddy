# Prior M0–M10 roadmap

**Status:** ARCHIVED LINEAR PLAN  
**Superseded as program authority by:** [04-program.md](../04-program.md)  
**Preserved because:** it contains implementation motivation and proposed skill work not captured by a dependency diagram alone

## M0 — Ratify the kernel model

Consolidate Operator, Harbor, Convoy, AgentNode/actor, Body/incarnation, Office, belief, goal, intention, commitment, tension, Parley/role, ActionIntent/Permit/Receipt, actuator, observation/evidence/outcome, skill/binding/evaluator, grant/resource/budget, claim, and pheromone. Proposed skill: `port-daddy-kernel-ontology` to reject category collapse.

## M1 — Non-forgeable person/body split

Reconcile actor roster, actor souls/body leases, resurrection, episodic memory, session/Fleet/MCP/Relay identity, claims, obligations, budgets, and outcomes around daemon-minted durable identity. Acceptance: provider-A → provider-B body continuity.

## M2 — Provable action kernel

Ratify typed requests, decision evidence, permits, denials, receipts, and one GitHub `UpdatePullRequestBody` actuator proof. Proposed skill: `actuator-contract-designer`.

## M3 — Chartroom intent graph

Canonical Intent, Requirement, Decision, Hypothesis, Question, Tension, Supersession, Dependency, and EvidenceLink; models propose interpretation, authority commits. Borrow BDI semantics without requiring an AgentSpeak interpreter. Proposed skill: `operator-intent-reconciler`.

## M4 — Keel and confinement

Harbor-owned spawn → sandbox profile → body lease → grants → capability endpoint → body. Keep provider credentials and cost truth at the boundary. Proposed skill: `same-uid-agent-confinement`.

## M5 — pd-console workstation

Simultaneous editor, Claim Forest/tree, Chartroom, and Porthole, with actor cards. Claims are hard; pheromones overlay attention/freshness/contention/uncertainty/risk/novelty/abandonment/opportunity and decay.

## M6 — Porthole evidence explorer

Unify events and evidence across actors, operator, intent, Parley, action, observation, terminal, browser, simulator, GitHub, and artifacts. Proposed skill: `evidence-chain-debugging`.

## M7 — Embodiment runtime

Common `observe`, `availableActions`, governed `perform`, `snapshot`, and `attachEvidence` semantics for browser, terminal, iOS Simulator, and macOS.

## M8 — Experience, selection, and skill competition

Record decision episodes across replaceable decomposers, matchers, schedulers, selectors, memory/context modules, merge ordering, and evaluators. Proposed skills: `skill-credit-assignment` and `selection-policy-experimentation`.

## M9 — Relay federation

Sovereign Harbors exchange actor/resource assertions, grants, protocol messages, evidence commitments, subscriptions, and action requests—not databases or implied consensus.

## M10 — Remote Harbor and Anchor

After identity/outcome/grant truth, separate coordination, economic, and confidential-execution protocols. Add attestation, independent settlement, and markets only when prerequisites pass.

## Why the linear form was demoted

It implied a canonical ordering even where work is parallel and concealed which proofs block which economic claims. The dependency graph now decides funding cuts. This archive prevents that correction from throwing away the implementation detail.
