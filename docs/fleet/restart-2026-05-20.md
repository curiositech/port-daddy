# Fleet Restart — 2026-05-20

The fleet (`pd-fleet.yml` at the repo root) had been dry-docked for an
unknown stretch — `pd fleet status` reported "Fleet 'port-daddy' defined in
pd-fleet.yml but not running." We brought it back up today, deliberately, with
a constrained ship list.

## Why now

Two pressures lined up:

1. The operator asked, in so many words: *"How to make sure our tests aren't
   bullshit? Don't we have a ship in the fleet for that? Does it not do
   anything?"* — the answer was "yes, but the fleet is off."
2. Adversarial reviews keep finding bugs that `qa` and `test-hunter` were
   built to catch on commit (issue #126 family). With the fleet down, every
   commit ships unreviewed by the fleet.

So: turn it back on. Carefully.

## How it was started

Because the CLI's `pd fleet up` reads project state from `process.cwd()` and
this restart was performed from a worktree, we used the daemon HTTP API
directly:

```bash
curl -fsS -X POST http://localhost:9876/fleet/start \
  -H 'Content-Type: application/json' \
  -d '{
    "projectDir": "/Users/erichowens/coding/port-daddy",
    "enabledAgents": ["gardener","qa","test-hunter","documentarian","cartographer"]
  }'
```

The daemon's `enabledAgents` knob is the only place today where you can start a
*subset* of the configured ships. There is no CLI flag for it yet — see
`docs/fleet/known-issues.md`.

## Kill switch (how to turn it back off cleanly)

If cost, noise, or instability becomes a problem again, in order from least to
most aggressive:

1. **Pause one noisy ship.** Use the dashboard `Agents` surface or:
   ```bash
   curl -fsS -X POST http://localhost:9876/fleet/agent/pause \
     -H 'Content-Type: application/json' \
     -d '{"projectDir":"/Users/erichowens/coding/port-daddy","agentName":"qa"}'
   ```
2. **Stop just this project's fleet** (daemon stays up for other projects):
   ```bash
   curl -fsS -X POST http://localhost:9876/fleet/stop \
     -H 'Content-Type: application/json' \
     -d '{"projectDir":"/Users/erichowens/coding/port-daddy"}'
   ```
   Or `pd fleet down` from the main repo working tree.
3. **Global panic** — arms the two-step kill switch, refunds bonds, drops every
   spawn:
   ```bash
   pd fleet panic
   ```
4. **Take the whole daemon down**: `pd stop` (last resort — affects every
   project on this machine, not just port-daddy).
