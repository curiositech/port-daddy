The machinery is built. It was never plugged in.

Salvage, checkpoints, transcripts, compaction, briefings, context economics, and subagent splitting are one story — and they all wait on a single missing pipe.

▲ The keystone

Nothing emits a schema-valid ContextEnvelope on agent heartbeats. That one signal is what would tell the daemon to compact a full context, spawn a successor, salvage a dying agent, or split work across subagents. Emit it and roughly a milestone of already-tested code comes alive at once.

Invariants applied across the plan

  • Rebuild from primary roots, never the last summary. Every packet, briefing, and cheap-summary re-derives from transcript events, git, and notes each round, with citation-grounding (not just presence) — so summaries can't drift into confident fiction.
  • Trust but verify every self-reported signal. The daemon estimate is the floor; the agent's envelope is advisory. Classify on the higher of the two, and flag divergence.
  • Scoped capabilities, never bare pointers. A blob pointer carries session, partition, and TTL caveats and fails closed — otherwise it's a cross-agent read oracle that also breaks subagent scope.
  • Rank and validate with different signals. Cosine ranks a skill; an independent outcome label decides whether its centroid earned its place.
  • Width is the coordination floor. The coupling graph's max antichain caps subagent count; hot shared files run serially, not smeared across racing agents.
Decisions needed before lock-in

Open questions

O1

One episodic store. Confirm Tier A's episodic_memory table is the store of record and Tier B's logic ports onto it. Two stores is rejected.

O2

Envelope producer site — hook/harness self-report vs daemon estimate as default. Both may coexist behind a confidence flag.

O3

Build-step trigger — pd setup, daemon-startup reconcile, schedule, or all three. First run is ~1,500 skills; must be incremental and resumable.

O4

Buffering default — output-spill on for all agents, or opt-in per compliance level.
