Invariants across the plan

  • Rebuild from primary roots. Packets, briefings, and summaries derive from transcript events, git, notes, and live rows, never from the previous summary.
  • Verify self-reported pressure. The daemon estimate is the enforcement floor; classify on the higher of the self-report and the estimate.
  • Use scoped capabilities. Blob pointers carry session, agent, partition, range, and TTL caveats and fail closed.
  • Separate rank from validation. Similarity can rank a skill; an independent outcome label decides whether the graft worked.
  • Let coupling set the fleet width. Shared hot files serialize after disjoint lanes converge instead of becoming conflict magnets.
Decisions required before lock-in

Four questions block the implementation contract

O1

One episodic store. Confirm Tier A’s episodic_memory table as the store of record and port Tier B’s logic onto it. Two stores remain rejected.

O2

Envelope producer. Choose hook or harness self-report versus daemon estimate as the default. Both can coexist behind source and confidence fields.

O3

Build trigger. Decide whether eager tool2vec reconciliation runs during setup, daemon startup, on a schedule, or all three. It must stay incremental and resumable.

O4

Buffering default. Choose on-by-default output spill for every agent or opt-in behavior by compliance level.
