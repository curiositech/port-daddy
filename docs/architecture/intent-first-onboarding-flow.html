PORT DADDY · intent-first agent onboarding — the push-first happy path
Coordination redesign · proposal

Declare your intent. Then just work — the harness feeds you.

Onboarding today is "here's global state, figure it out yourself." The redesign makes the agent's stated purpose load-bearing and pushes everything relevant to it — so the agent stops querying and starts building.

Old · pull

The agent must remember to run pd sitrep, pd attention, pd briefing — then interpret a global dump itself. Friction every session.

→
New · push

The agent says what it's here for once. The harness pushes an Arrival Brief, ambient nudges, and a live PR feed — matched to intent. The pull loop disappears.

Two invariants wrapped around it

Buffer for the agent · log for us

The same stored object serves both — truncation is lossless at rest.

Input buffering (= ch.27 W8)

  • Spill, don't dump. Big tool outputs and big briefs/feeds go to the blob store; the agent gets a preview + a scoped pointer.
  • Page on demand. read_buffer(id,off,lim) / grep_buffer / summarize_buffer — window as RAM, blob as disk.
  • The harness budgets itself. The envelope is ≤3 items, TTL'd, semantically deduped, summarized when large — the coordination layer never overflows the context it protects.

Harnessed-reality logging

  • Nothing is logged today. The harness injects (persona, envelope, PR alerts) but records none of it — the agent's real context is invisible.
  • New context_injection event records source, payload (blob-referenced), the matched intent + why, TTL, and acted? — did the agent take the suggestion.
  • Payoff: a replayable timeline of what the harness fed each agent, and a precision metric (accepted / injected) to kill noisy sources.
The consequence you flagged

Pull commands, demoted

If the harness pushes, the agent's pull loop vanishes. These three don't disappear — they change role.

pd attentionNo longer a loop the agent runs — its items are pushed into the envelope. Survives as the expand of a pushed preview (page the pointer) and as an operator surface.
pd briefing / sitrepPrimarily operator/human survey surfaces now. For agents, the un-filtered fallback ("show me everything, not the top-3") — with an intent lens. Not on the harnessed happy path.
pd whoamiThe agent's cheap re-orient: what I'm here for + my_injections() (what the harness fed me, did it help). Replaces the sitrep self-check habit.
