Website And Docs Task List

This is the source-backed execution list for the `agentsd.ai` reset track: the proposed public shell, the developer docs system, and the truth-alignment cleanup around them. It is planning research, not authority for the live `website-v2` surface.

Critical Contradictions

  • The working tree currently restores a top-level /whitepaper route, while docs/AGENTSD_AI_SITE_CONTRACT.md bans that route and says everything public must live under /docs/**.
  • docs/recovery/CURRENT-WORK.md says the active direction is a hybrid preservation pass, not an agentsd.ai replacement, while the agentsd site-contract docs describe a full public reset.
  • The docs-system plan assumes a clean docs information architecture, but the current website working tree is split across modified tracked files and new untracked shell files under website-v2/src/components/site/, website-v2/src/data/publicSite.ts, website-v2/src/docs-content/, and website-v2/src/public-shell-contracts.test.ts.
  • There are two public whitepapers in the repo, not one: whitepaper/anchor-protocol-whitepaper.tex and whitepaper/agent-transactions-whitepaper.tex. The site has to surface them intentionally, not speak about "the whitepaper" as if the distinction does not matter.

What This Task List Is For

  • Choose one public route contract and make the code, tests, and docs agree.
  • Replace fragmentary docs-shell placeholders with real developer documentation.
  • Stop public pages from reading like repo-autopsy notes or internal cleanup tickets.
  • Force design-system and content-system rigor so the site cannot drift again.
