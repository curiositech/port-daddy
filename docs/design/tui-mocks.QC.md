## Top 3 wins

1. **The DAG Braille edges in `pd watch` (lines 717–737).** The catenary-curve glyph strings (`⢀⡠⠔⠊⠉`, `⠈⠉⠒⠤⢄⡀`) physically demonstrate "things people don't know TUIs can do" — they read as actual non-linear pipeline edges, not stock arrows, and they map cleanly to `ctx.draw(&Line { ... })` with `Marker::Braille` per the implementation note. This is the most distinctive moment in the file and it earns the maritime ambition.
2. **The Mike-flag rendered at 8×8 cells inside the `pd vibe` mock (lines 601–612).** Flag DNA escapes "tooltip-only" by being drawn *as terminal cells* using `▜▙▟▛` quadrant glyphs on a `bg-blood` field with mustard chrome. This is the right kind of literal: it shows the reader that the maritime vocabulary is the running surface, not decoration. Strong proof-of-concept for the `Canvas + Marker::HalfBlock` claim.
3. **Per-widget implementation notes are exhaustive and accurate (25 cards across four mocks).** Every widget has a crate path, every effect names a `tachyonfx` function with interpolation curve and duration, and the third-party-vs-core color coding on the `.crate` pill is genuinely useful. A Rust dev could ship most of this without follow-up DMs. The `HEAVY_UNREAD` border::Set fragment (lines 1017–1023) is the most concrete handoff artifact in the file.

## Top 3 flaws (must-fix before approval)

1. **Maritime DNA collapses to tooltips in mocks 02–04.** The page chrome (perf-pills, legends) shows flags via `<use href="#flag-...">`, but inside the `.tui` frames, only `pd vibe` actually renders a pixel-art flag glyph. `pd watch`, `pd costs`, `pd inbox` use bracketed-letter codes `[K]` `[P]` `[V]` `[F]` `[D]` `[I]` `[C]` `[R]` `[N]` instead of flag glyphs. The user's contract was "physically present in every mock — as agent avatars, performative pills, severity headers, distress indicators — not just hover tooltips." Right now flags are present inside one of four mocks. **Fix:** in `pd watch` (line 717+), draw the Victor/Foxtrot/Delta/India/Charlie flags as 2-cell-wide HalfBlock micro-glyphs at the left of each severity-ledger row, not just the letter code. In `pd inbox` (lines 959–984), render a 2×1 cell flag swatch beside each performative pill (the pill currently shows `[K] REQUEST` as text — should show flag-glyph + text). In `pd costs` (lines 853–868), one ICS flag per backend row would map cleanly onto an "actor identity" column. The file *defines* canvas micro-glyphs in `pd vibe`; it must *use* them across the other three mocks.
2. **Tabs strip in `pd inbox` (line 954) renders as fragile single-line ascii pipes (`┃`) — not the neobrutalist filled-edge.** The impl note (line 1001) says "divider: `symbols::line::VERTICAL_HEAVY` (┃ — already neobrutalist-thick)." That is *not* the neobrutalist filled-edge the rest of the file uses. Elsewhere the mock uses `▓` for "filled brutalist edge"; the tabs should too — `▓` between tabs, or `▓` underline on active tab — to match the cinnabar-underline rule from the impl note (which claims `highlight_style(Style::new().fg(cinnabar).underline())` but the rendered mock shows underline via `class="u"` on text only, no actual `▓▓▓▓` filled-edge underline). **Fix:** either (a) render `▓▓▓▓▓▓▓▓▓▓` directly under the active tab name in cinnabar, OR (b) replace `┃` dividers with `▓` and document a `Block::border_set` override using `▓` for the tab-strip's bottom edge under the active tab. The current rendering doesn't sell "neobrutalist tabs," it sells "default ratatui Tabs widget."
3. **`pd costs` is the weakest mock for physical ambition (lines 831–871) — it's "stock ratatui widgets nicely arranged" not "things people don't know TUIs can do."** The hero is `tui-big-text` (good), but the 24h cumulative chart is one `Chart` widget, the table is one `Table`, the sparklines are inline glyphs in a cell. Compared to `pd watch`'s Braille DAG edges, `pd costs` reads as default-ish. The research's distinctive moves — `BorderType::QuadrantOutside`, drop-shadow trick, `Marker::Octant` at 12×12 cells, `tui-piechart` high-res mode, per-cell RGB gradient on a 2–3 cell accent strip — appear in *zero* of the costs mock. **Fix:** at minimum, add (a) a `QuadrantOutside` border around the hero scoreboard for "pressed depth" (matches the user's neobrutalist-pressed vocabulary); (b) replace the inline `▁▂▃...█` sparkline cells in the 7-day-trend column with a per-row 16-wide Braille `Canvas` mini-spark — that's the move `bottom` makes that "stock-ratatui boxes" don't; (c) consider a `tui-piechart` donut for "share of spend by backend" in the empty space below the hero (visible at lines 832–838 — there's a lot of negative space in that title block). Right now `pd costs` is the mock most likely to read as "a Stripe dashboard in monospace" rather than "Port Daddy's maritime ratatui voice."

5. **Accessibility — contrast: 4/5.** Spot-checked five pairs:
   - **paper #F5F5F0 on ebony #1E1B18.** Computed ≈ 15.4:1. File claims 15.6:1. ✅ AAA.
   - **canary #FFDB33 on ebony.** Computed ≈ 12.3:1. File claims 15.0:1 (overstated). ✅ AAA either way.
   - **cinnabar-lit #FF9081 on ebony.** Computed ≈ 6.9:1. File claims 7.0:1. ✅ AAA.
   - **paper #F5F5F0 on cinnabar #CC3D2E (user bubble bg, lines 567–572, 588–592).** Computed ≈ 4.5:1. File claims 5.0:1. ⚠️ Right at the AA Normal threshold (4.5:1). Passes, but no headroom. If the cinnabar value drifts or a developer renders this on a slightly darker bg, it tips into failure. Consider documenting this as the tightest pair and asking the user whether to lift to `paper-soft #FFFFFF` on cinnabar (computes to ~5.2:1).
   - **ebony #2B2A26 on canary #FFDB33 (performative pill, line 964).** Computed ≈ 14.5:1. File claims 15.0:1. ✅ AAA.
