1. Systems Primer: Core Concepts Explained Simply

Before diving into code and diagrams, let us define the key concepts and mental models from first principles.

What is an API?

The Restaurant Analogy: Think of a restaurant. You are the customer sitting at a table in the dining room. The kitchen is where the chefs store ingredients and cook meals. You do not walk into the kitchen and touch the stoves yourself. Instead, the restaurant provides a menu (the specification) and a waiter (the API). You give the waiter a structured order, the waiter communicates with the kitchen, and your meal is brought back in a predictable format.

In Software: An Application Programming Interface (API) is a formal contract allowing two computer programs to exchange clean, structured data (like JSON) directly over standard internet pipes, rather than having a robot simulate mouse clicks on a graphical browser.

What is Cloudflare?

The Global Network Analogy: Traditional web hosting is like renting an office in Chicago. If a user visits your website from London or Tokyo, their network packets must travel across oceans and back, causing lag and crashing if Chicago loses power.

Cloudflare operates thousands of miniature data centers across more than 330 cities worldwide. When you deploy code to Cloudflare, your application runs simultaneously in every city on Earth, executing code milliseconds away from whoever triggered it.

What is a Serverless Worker?

A traditional server is like a taxi with the meter running 24 hours a day: you pay rent every second, even at 4:00 AM when nobody is riding in it.

A Worker is like renting an electric scooter for exactly 15 milliseconds. It sleeps at zero cost, wakes up in under 5 milliseconds when a scheduled cron triggers or an email arrives, runs your calculation code, saves the result, and immediately vanishes. When it is idle, it costs exactly $0.00.

What is Cloudflare D1?

SQLite is the most widely deployed database in human history—it runs inside every iPhone, Android, and web browser. Cloudflare D1 is SQLite built directly into Cloudflare's global edge network.

It gives you full relational database capabilities (SQL tables, unique constraints, foreign keys, transactions) without needing to configure complex database servers or pay monthly database hosting fees.

Why Float Math Fails: The 0.1 + 0.2 Trap

Computers store decimals using binary floating-point arithmetic (IEEE-754). Because fractions like 0.1 cannot be represented cleanly in binary: 

// The JavaScript Floating Point Trap:
console.log(0.1 + 0.2); // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3); // FALSE!

// BAD: Doing financial reconciliation with floating numbers
const currentBalance = 120.45;
const addedDelta = 10.10;
const total = currentBalance + addedDelta; // 130.55000000000001 (Comparison checks fail!)

// GOOD: The Integer Cents Pattern
const currentBalanceCents = 12045; // Stored as integer
const addedDeltaCents = 1010;      // Stored as integer
const totalCents = currentBalanceCents + addedDeltaCents; // 13055 (100% Exact!)

// Format to dollar string only when rendering the final email:
const formattedDollars = "$" + (totalCents / 100).toFixed(2); // "$130.55"

6. Error Handling, Circuit Breakers & Log Governors

How to prevent background retry storms and disk-filling log loops.

Circuit Breaker Finite State Machine

SRE Resilience Standard

When an external dependency (like the Landry's portal or Google's servers) goes down, continually retrying every few seconds hammers the struggling service into a cascading failure. A Circuit Breaker acts like an electrical safety switch: after repeated failures, it trips to OPEN and fails immediately without sending network requests.

Full Jitter Exponential Backoff (AWS Standard)

Exponential backoff without jitter synchronizes retries into devastating spikes called retry storms. AWS demonstrated that Full Jitter (randomizing delay between 0 and the exponential cap) is mathematically optimal: 

export function calculateDelayMs(
  attempt: number, 
  baseMs = 100, 
  capMs = 30000
): number {
  const maxDelay = Math.min(capMs, baseMs * (2 ** attempt));
  return Math.floor(Math.random() * maxDelay);
}

The Google SRE Two-Budget Defense

  • Per-Request Budget: Maximum 3 retry attempts per operation.
  • Per-Client Budget: Retries must not exceed 10% of total outgoing requests across a 2-minute rolling window.
  • Why? 4 layers with 3 retries each = 43 = 64× amplified load on a dying database!

The Log Governor: Preventing Unrotated Disk Storms

In a background loop, logging errors unconditionally can produce hundreds of megabytes of log spam overnight. A LogGovernor caps output to a small burst limit and flushes a single rollup: 

export class LogGovernor {
  private counts = new Map();

  log(key: string, message: string, limit = 3, windowMs = 60000) {
    const now = Date.now();
    const state = this.counts.get(key) || { count: 0, firstSeen: now };

    if (now - state.firstSeen > windowMs) {
      if (state.count > limit) {
        console.warn(`[SUPPRESSION ROLLUP] ${state.count - limit} duplicate logs suppressed in last ${windowMs/1000}s`);
      }
      state.count = 0;
      state.firstSeen = now;
    }

    state.count++;
    this.counts.set(key, state);

    if (state.count <= limit) {
      console.error(`[${key}] ${message}`);
    }
  }
}
