Typography

Fraunces. IBM Plex Sans. JetBrains Mono.
Three families. Variable everything.

Display headlines run on Fraunces at three axes — weight, width, optical size — to swing from whisper to slam within the same family. Body type is IBM Plex Sans. All numerics are tabular by default. Fractions render as 1/2, 3/4, 7/12. Small caps for actor names and performatives.
