Proposal 01
FleetBar research report ×
story palette (PR #455)
4 patterns · 6 states · 4 zones
One variable font file
The FleetBar research found the grammar. The story palette supplies the meaning. This proposal marries them into one system for the website.

The research report resolved fractional borders into four load-bearing patterns: corner brackets for panel scope, left-edge stripes for state, midline rules for division, and a single color zone for the primary thing. Its discipline rules — max two patterns per surface, one zone per view, color never the sole signal — are adopted wholesale.

What the report lacked was semantic color. Its stripes used ad-hoc status hues. The story palette (PR #455) replaces them: every stripe, zone, and chip now pulls from tokens where hue = a layer of the ADR-0048 stack. A violet stripe isn't decoration — it says waiting on a person. The current site's heavy border-2 boxes stay on primary panels; everything secondary sheds its chrome for linework. The page you are reading is set entirely in Recursive — the variable file already shipped in public/fonts/ — and built from the system it proposes.

§ 01
The six primitives
four from the report · two carried with them

Each primitive is rendered live below, with the CSS token recipe it would ship as. The rule from the research holds: if you removed the linework, hierarchy must still survive on color, spacing, and type. Linework is refinement, never scaffolding.

panel scope
LW-1 · from pattern 2.1
Corner brackets
Four L-ticks declare "this area is framed" without enclosure. Reserved for panels that hold live or primary content: fleet cards, code blocks, spec sheets.
--lw-bracket: 14px;
--lw-weight: 1.5px; /* ink, always */
state carrier
LW-2 · from pattern 2.4
Left-edge stripe
The feature pattern. A 3px inset stripe is the border, the status, and the row divider at once. The only place status color is allowed to touch chrome.
box-shadow: inset 3px 0 0 var(--story-*);
/* hue = state or stack layer */
divided · continuous
LW-3 · from pattern 2.3
Midline rule
A hairline spanning only the middle third — or 64px anchored left — where a full border would sit. Divides sections while the column stays continuous.
background: linear-gradient(to right,
  transparent 0 32%, var(--hair) 32% 68%,
  transparent 68%) bottom / 100% 1px;
primary state
LW-4 · from pattern 2.8
Color zone
No border at all: a saturated panel bounds itself by contrast with the cream matrix. The Vignelli move. Exactly one zone per view — the thing happening right now.
background: var(--brand-primary);
color: var(--brand-primary-foreground);
running · 18s
LW-5 · state grammar
Pulse ring
An 8px dot with a 1.8s expanding ring. Animates only while work is in flight — never on idle, done, or failed. One animation per surface; no spinners beside it.
animation: lw-pulse 1.8s ease-out infinite;
/* running state only */
24 merges · 7d
LW-6 · instrumentation
Sparkline
Tufte-plain: no axis, no legend, direct label. Line takes the zone's hue; the end-of-line dot goes amber when the last reading is the actionable one.
stroke: var(--brand-primary);
end dot: var(--status-warning)

One font file, every voice

Display · weight 900 · CASL on the em-word
Local control plane for coding agents.
Body · weight 400–560 · CASL 0.12

Port Daddy is the daemon your fleet reports to: deterministic ports, file claims, coordination notes, and a kernel of truth that outlives every session. Body text never drops below 14px.

Metrics & code · MONO axis pinned to 1
$ pd begin --identity myapp:api:main
claimed :9876 · session anchored · 2m 14s
queries/user.ts:47 · 412/1840 files

Inter and Geist read as everyone's dashboard. The site already ships something better: Recursive, a single variable woff2 with weight, slant, MONO, and CASL axes. This proposal promotes it from type-switcher option to the system voice.

The move that makes it ours: the casual axis is the italic. Where the research report reached for a serif (Fraunces) to mark the em-word, we flip CASL 0 → 1 instead — the letterforms soften into brush-informal while staying the same family. One file covers display, body, metrics, and code: one kernel, many surfaces — the type system repeats the product's architecture.

The mono voice (MONO 1) owns everything instrumental: eyebrows, timestamps, counts, code, state labels. The sans voice owns everything human. That split — instrument vs. prose — is the same line the linework draws between chrome and content. IBM Plex stays available as the body fallback in the switcher; Radnika retires to the archive.

§ 05
Adoption — tokens, rules, rollout
ships as css custom properties + utilities
The discipline
  • Max two linework patterns per surface. Brackets + stripes on a fleet card. Midlines + one zone on a page. Never three.
  • One zone per view. The zone is "the primary thing right now." A second concurrent thing stays in the list with a pulsing stripe.
  • Stripes carry state or layer; ink carries structure. Brackets and midlines are always ink — story hues never touch them.
  • Color, label, and relative time — always together. Never color alone; the stripe re-states the dot for color-blindness.
  • Primary panels keep the 2px hard border. Linework replaces chrome on secondary surfaces only — the hierarchy gains a rung, it doesn't lose its anchor.
  • Everything lands on the 4px grid — brackets 12–18px, stripes 3px, midlines 64px or middle-third.
Refuse on sight
  • Brackets under 10px — reads as a render glitch, not a frame.
  • Story hues on brackets, borders, or backgrounds of prose surfaces — accents, never chrome.
  • Box-shadows stacked under fractional borders — collapses the entire idea.
  • Dashed/segmented strokes as persistent UI — permanent "draft mode."
  • A pulse ring on anything that is not actively working.
  • Decorative brackets on every card — if everything is framed, nothing is.
/* tokens.semantic.css — proposed additions (both themes) */
--lw-weight: 1.5px;        /* all fractional linework */
--lw-bracket-sm: 12px;  --lw-bracket: 14px;  --lw-bracket-lg: 18px;
--lw-stripe: 3px;          /* state + layer edge stripes  */
--lw-midline: 64px;        /* anchored-left rule length   */

/* utility classes (styles/linework.css, ~90 lines total) */
.lw-brackets        /* 4 corner L-ticks, ink            */
.lw-stripe-[state]  /* running|ready|warn|error|blocked */
.lw-stripe-[layer]  /* l0|l1|l2|l3 via --layer-*        */
.lw-midline         /* section rule, middle third       */
.lw-zone-[story]    /* primary|federation|reputation|identity|economy */
.lw-pulse           /* running dot, honors prefers-reduced-motion */
