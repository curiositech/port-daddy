The reframe

The fleet is plumbing. The front door is intent.

The previous mockup put agents at the center of the panel — but Port Daddy is a control plane for humans, not a roster admin tool. The user verbs are intent-shaped: "I want to do X" · "Resume project Y" · "Show me what you built" · "Authorize the swarm." The fleet exists, but it's a drawer you open occasionally, not the home screen.

Before · agent-roster home

  • Opens to a list of running agents
  • Color zone for "now running" agent
  • Pulse rings everywhere — visually busy
  • Fleet activity feed is the primary surface
  • HITL approvals are not architecturally privileged
  • Cost shown per agent — fetishizes spending
  • User has to translate intent → agent

After · intent-first home

  • Opens to a command bar — "what do you want to do?"
  • HITL approvals at the top — the only thing that demands you
  • "Resume" projects with thumbnails — physical re-entry
  • Four quick actions: build, catch-up, talk, fleet
  • The fleet drawer is reachable but secondary
  • Cost is shown when authorizing — at the gate, not by default
  • The user expresses intent · the plumbing routes it
