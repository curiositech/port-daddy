## Note on the 5,373 arbitrary-tailwind "errors"

The auditor's heuristic flags any Tailwind arbitrary-value bracket
(`text-[length:var(--type-X)]`, `border-[var(--border-strong)]`, etc.)
as a violation. In this codebase, those brackets are exactly how design
tokens get consumed in Tailwind classes — it is the project's blessed
pattern. The genuine token-discipline failure mode (raw hex / RGB /
HSL / OKLCH literals) is captured separately and correctly by the
`raw-color` rule.

We should not chase the 5,373 figure. Track `raw-color` and
`primitive-bypass` instead.

Most of these can move to a small `chartTokens.ts` file colocated with
`tokens.semantic.css`, or be ported to CSS variables consumed via
`color-mix()`. The logo SVG is the only place where raw hex is
genuinely the right answer — exempt and document.

### Tier 2 — design-system primitives (taste calls, not mechanical)

34 `primitive-bypass` warnings flag interactive native elements built
without composing from the design system primitives. Some are correct
(the whitepaper paper-picker uses `aria-pressed` on `button` deliberately;
that is the accessible pattern). Others are real shortcuts that should
become primitives or compose existing ones. Worth a per-warning review
session.

### Tier 3 — Storybook / content / architecture

57 missing-component-story warnings: the design-system primitives ship
without Storybook stories. Adding stories pays off the moment we want
visual regression or a public component playground.

11 content warnings: thin or possibly-fake content. Worth eyeballing.

6 single-instance architectural warnings:

- `observability`: no Sentry. We have a daemon, the website is the
  storefront — adding error reporting on the storefront is cheap
  insurance.
- `seo`: framework metadata surface not detected. We do generate
  per-route SEO via `scripts/inject-route-html.mjs`; the auditor may
  not recognize the pattern. Worth confirming with a Lighthouse pass.
- `plan`: no on-disk pessimistic plan in the repo root. We have
  `docs/plans/`; consider linking from a single canonical location.
- `sustainability`: no payload-budget evidence. The largest non-vendor
  bundles are at ~500 KB (Mermaid). Worth a budget-doc pass.
- `ai-risk`: AI feature surface detected without an AI-risk register.
  This is a real gap; we should write one.
- `trust`: not enough evidence that visible claims (proofs, mech
  status, conformance) are linked to durable artifacts. The whitepaper
  rounds page now does this for the papers; we should do it for the
  rest of the site (uptime, recovery claims, etc.).
