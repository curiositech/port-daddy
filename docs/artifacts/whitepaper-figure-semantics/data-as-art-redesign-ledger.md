# Coordination Papers: data-as-art redesign ledger

This ledger is the pre-render contract for the analytical figures. An existing
figure is never a candidate grammar. Each entry starts from the reader question
in the surrounding argument, records a second plausible grammar, and names the
false reading that the selected geometry must prevent.

## Corpus-wide controls

- Neutral ink carries structure. Teal means verified, selected, conserved, or
  valid. Amber means hazard, missingness, superseded logic, or retained override.
  Cobalt is reserved and is not a default accent.
- Color is always redundant with position, shape, weight, dash, or pattern.
- Canvas prose is limited to direct labels. Explanation and caveats live in the
  caption unless a status label is necessary to prevent an empirical overclaim.
- No maritime, pirate, parchment, antique-book, or scenic metaphor may function
  as an analytical substrate.
- Generated art begins with zero entitlement to a page. It must survive a
  separate editorial-plate review and can never substitute for analytical marks.
