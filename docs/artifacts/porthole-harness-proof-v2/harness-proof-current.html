What is a harness?

The agent still writes code and runs commands. The harness is the layer around those actions: it can provide timely context, check a risky edit, and leave a trace. Port Daddy keeps the team state durable. Porthole is the window that lets you replay and inspect the evidence.

01 · agentThe worker at the keyboard

Chooses commands, edits files, runs tests, and explains the result.

02 · harnessSeat belt + dashboard + flight recorder

Connects before a turn, before an edit, and after a tool without replacing the worker.

03 · Port DaddyThe durable team control plane

Owns identity, worktrees, claims, inbox delivery, Parley, limits, and receipts.

04 · PortholeThe inspectable evidence window

Replays real terminal bytes and source time. It shows the run; it does not invent the decision.
