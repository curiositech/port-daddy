Rust desktop can be hot.

A visual board for building modern, buttery, cross-platform Rust desktop apps. The lesson: use Rust's speed and safety, but steal taste from the products that already feel expensive.

How to use this Pick one reference for layout, one for rendering/feel, and one for release polish. Then translate the reference into tokens, states, platform affordances, and verification gates.
RustGPUIGPU-native editor

Zed: dense, fast, quiet, alive

Zed is the current north star for high-end Rust desktop product feel: low visual noise, serious density, beautiful dark chrome, and AI/collaboration woven into the editing surface instead of bolted on.

StealPanel hierarchy, muted borders, GPU fluidity, agent progress inside the workspace.
AvoidCopying its editor-specific density into apps with less expert users.
Source: zed.dev

Rusteguiwgpu

Rerun: egui taken seriously

Rerun shows what happens when immediate-mode UI is treated as a product system: multimodal data, 3D views, timeline controls, and dense debugging UI in one coherent app.

StealTimeline-first controls, viewport composition, direct manipulation.
AvoidAssuming default egui style is enough for a consumer-grade app.
Source: rerun-io/rerun

Yaak is clean, offline, themeable, local-first, and Git-friendly. Study it for restrained API-client density and an app that does not bury the primary workflow under account chrome.

Framework/Tutorial Picks

Use these as starting paths. The "sexy" outcome still depends on a product-specific design system, not the default scaffold.

Stack Best Starter Visual Ceiling Watch Out
Tauri 2 create-tauri-app plus a real web design system Highest if you want web-grade UI plus native shell Capabilities, IPC, signing, updater, and WebView security must be first-class
Dioxus Desktop Desktop guide and `dx new` templates Great for Rust component teams that still want HTML/CSS mental models Desktop renderer is WebView-backed; browser APIs are not the same promise as web deployment
Slint slint-rust-template or Material template Excellent for custom native, embedded-adjacent, and touch-friendly products Requires learning `.slint` and designing component/token structure early
egui/eframe eframe_template Excellent for tools, inspectors, visualizers, and control panels Default egui can feel like a debug panel without disciplined styling
iced iced examples Strong for typed native apps with Elm-style architecture Documentation assumes Rust fluency and the ecosystem is still moving
Floem Floem examples/widget gallery Promising for reactive native Rust UI with GPU rendering Maturing API; choose it when you accept framework evolution
Makepad UI Zoo tutorial High for shader-fluent, live-designed, ambitious UI Experimental feel; best for teams willing to work close to the framework
