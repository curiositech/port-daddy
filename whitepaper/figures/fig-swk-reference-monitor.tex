\caption{The kernel as a reference monitor --- and the honest correction it forces.
Anderson's reference monitor must be \emph{always invoked on the request path},
\emph{before} the operation commits. The \textbf{uniqueness constraint / boot gate}
(cobalt) meets this for double-claims, duplicate-identity squatting, and the
serve-from-test-database guard: it rejects \emph{before} the WAL write. The
\textbf{policy monitor} (teal) does not: it is a subscriber to the operation log
that fires \emph{after} the event is already durable. By Schneider's
theorem~\cite{schneider2000} (\S\ref{sec:enforcement}) a monitor downstream of the
commit line enforces no safety property --- it can only \emph{detect and
compensate}. We therefore reserve ``physically unreachable'' for the regimented set
and say ``detected within a bounded window, then halted or compensated'' everywhere
else.}
