\caption{The kernel as a reference monitor --- and the honest correction it forces.
Anderson's reference monitor must be \emph{always invoked} on the request path
(complete mediation), \emph{tamper-evident}, and \emph{small enough to verify}. The
\textbf{uniqueness constraint / boot gate} (cobalt) meets the first property by
construction --- the single SQLite file lock means every double-claim,
duplicate-identity squat, or serve-from-test-database attempt is rejected
\emph{before} the WAL write. The \textbf{policy monitor} (teal) does not: it is a
subscriber to the operation log that fires \emph{after} the event is already
durable, and by Schneider's theorem~\cite{schneider2000} (\S\ref{sec:enforcement}) a
monitor downstream of the commit line enforces no safety property --- it can only
\emph{detect and compensate} within a bounded window. Tamper-evidence (a
hash-chained audit log) is re-scoped to the economy layer (\S\ref{sec:merkle});
smallness is the point of one writer over one file. We therefore reserve
``physically unreachable'' for the regimented set and say ``detected, then halted or
compensated'' everywhere else.}
