\caption{The kernel as a reference monitor --- and the honest correction that the
Harbor Volume's stitch report (C1) forces. Anderson's reference monitor must be
\emph{always invoked on the request path}, \emph{before} the operation commits.
The \textbf{PK constraint / boot gate} (cinnabar) meets this for double-claim,
PID-squatting, and the prod-DB-in-test guard: it rejects \emph{before} the WAL
write. The \textbf{Arbiter} (patina) does not: \texttt{arbiter.ts:328} is an
\texttt{activityLog.subscribe(...)} callback that fires \emph{after} the event is
already durable. By Schneider's theorem (\S\ref{sec:enforcement}) a monitor
downstream of the commit line enforces no safety property --- it can only
\emph{detect and compensate}. We therefore reserve ``physically unreachable'' for
the regimented set and say ``detected within a bounded window, then
halted/compensated'' everywhere else.}
