\caption{Five read-surfaces, each a token-compaction of the raw trajectory produced
for a specific reader (\S\ref{sec:tokens-digest}): briefing is external note-taking,
attention is precision compaction, episodic memory is recall-then-precision,
pheromone is time-decay (forgetting), resurrection is a handoff summary. Viewed
correctly, the swarm's coordination layer is a \emph{distributed compaction engine}
--- and because each surface is a compaction, each is governed by the same
cost-and-legibility economics, the same recency-decay (Prop.~\ref{prop:decay}), and
the same one law (Def.~\ref{def:zoom}).}
