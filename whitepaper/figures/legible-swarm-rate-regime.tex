% Brief (tikz-diagram-craft), register row ch4-32.
% Reader question: once some misses are tolerated, how cheap can the digest
%   get, and where does that price collapse to zero?
% Claim: the two-constraint rate R(delta,f) is fully pinned only in a wedge
%   of the (delta,f) plane -- below it the miss budget is infeasible, above
%   the line f=1-delta/p an independent flagger already meets the miss
%   budget and the true rate is exactly 0; the zero-miss corner (delta=0,
%   f=p) recovers the source's full entropy.
% Evidence: p=0.05; R(0,0.05)=0.2864 bits (corner=H(p)); R(0,0.10)=0.1864;
%   R(0.04,0.06)=0.0087 [internal, b1_frontier.py, run this pass]; boundary
%   lines f=p-delta and f=1-delta/p from Thm.~pinned-joint's closed form.
% Must distinguish: the infeasible strip (f<p-delta) from the priced wedge
%   (pinned joint, R>0) from the zero-rate region (f>=1-delta/p); the corner
%   value from the two interior worked points.
% Grammar chosen: phase-boundary/regime plot on (delta,f) axes, the priced
%   wedge tinted between the two boundary lines, three marked data points.
% Grammar rejected: a single R-vs-f curve at fixed delta=0 would state the
%   corner and one slice but hide the two-dimensional feasibility structure
%   -- in particular that the *zero-rate* region is reached by moving f, not
%   only by moving delta, which is the chapter's own point about the digest
%   going to bits=0.
% Five-second test: "does the marked (delta,f) point sit in the priced
%   wedge, and if so, how close is it to the zero-rate line?"

\caption{The two-constraint digest rate $R(\delta,f)$ of
Theorem~\ref{thm:pinned-joint} on tolerated miss mass $\delta$ against flag
budget $f$, at the chapter's Bernoulli rate $p=0.05$. The tinted wedge is
where both constraints bind and the joint is fully pinned; below the floor
$f=p-\delta$ (shaded) no digest can meet the miss budget at all, and above
the line $f=1-\delta/p$ an $X$-independent flagger already meets it on its
own, so the true rate is exactly $0$. The zero-miss, tightest-flag corner
$(\delta,f){=}(0,p)$ recovers the source's full entropy, $H(0.05)=0.2864$
bits; tolerating $\delta=0$ but widening the flag budget to $f=0.10$ drops
the price to $0.1864$ bits, and tolerating $\delta=0.04$ at $f=0.06$ drops it
to $0.0087$ bits, a hundredth of the zero-miss corner. [internal,
\texttt{b1\_frontier.py}]}
