\caption{The four-layer coordination stack. Each layer serves a different
\emph{whom} (machine, agents, operator, market). \textbf{Chapter II owns the two
lowest layers}: all of the substrate (the kernel) and the implemented carrier half
of coordination (the message bus, stigmergic markers, commitments, the cryptographic
authorization chain, the policy monitor); the coordination \emph{semantics}
(protocol state machines, the agent sandbox) and the whole legibility layer belong
to Chapters~I and~IV (Chapter~I: \emph{The Legible Swarm}; Chapter~IV: \emph{The Harbor Economy} owns the
market rung). From the machine the substrate \emph{assumes} only an advisory file
lock, one clock, and a supervisor; upward it \emph{provides} atomic TTL'd claims, a
durable bus, the deontic split, and an audit log. Later chapters build on or
cross-cut this floor; chapter numbers are not layer numbers.}
