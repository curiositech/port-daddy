% Figure 1 -- architectural section through the coordination stack.
% Five rungs: the four coordination layers over the host floor they stand on.
% Three columns of information at almost no extra ink -- a left badge column
% naming the part and chapters that own each rung (numbers read from
% whitepaper/textbook.json through figures/pd-textbook-map.tex, so a renumbered
% book cannot leave a stale number here), the rung itself, and a right-hand
% audience column naming the whom it serves. Every gap between rungs carries the
% relation in both directions, provides up and assumes down: that relation, not
% the stacking, is the whole content of a stack map.
%
% No node below sets a font. Five groups used to -- the badge column, the
% audience column, "assumed, not built", "this chapter" and "in part" -- and a
% local font= replaces a house role's font ENTIRELY, family included, so in the
% Book those five never received the edition's grotesk: 158 of the drawing's 486
% characters printed in the body serif while the other 328 printed in sans,
% measured from the compiled PDF. Each now names a `pd *` role and lets the
% edition decide the face. See craft-rules.md 7.9.

\caption{The four-layer coordination stack, drawn over the host floor it stands
on. Each rung names the audience it serves, and the margin names the part and
chapters of this book that own it. The filled rung is this chapter --- the
transactional substrate, whose one-writer record, claims, and sessions
everything above rests on. Coordination is outlined in the same accent but left
unfilled, because this chapter specifies only its implemented half and
Chapters~\csname pdchapternumberofanchor\endcsname--\csname
pdchapternumberofsealed\endcsname\ carry the rest. The floor is dotted and
unbadged because the book builds none of it: a file lock, a clock, a socket,
and a supervisor are assumed of the host. Chapter~\csname
pdchapternumberofstp\endcsname\ owns no rung --- the durable identity it builds
leans on this substrate and is priced on the market above. [internal]}
