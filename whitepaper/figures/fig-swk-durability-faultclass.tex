\caption{A returned success has different durability status under two fault classes.
For a daemon-process crash, the acknowledged write survives because the operating
system's page cache survives the daemon (I1a). For an OS crash or power loss,
the same write is not guaranteed until the next WAL checkpoint forces durable media
(I1b). The amber interval is therefore not a second storage tier or a generic
``failure'' state: it is the specific loss window created by the default WAL
\texttt{synchronous=NORMAL} policy. The remedy for I1b is full synchronization or
a checkpoint on the commit path; the kernel does not pay that cost by default.}
\label{fig:swk-durability-faultclass}
