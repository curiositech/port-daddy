\caption{Durability by fault class --- the single most important correction to the
kernel's foundational promise. The unqualified claim ``a write that returned success
survives a crash'' is true for a \emph{process} crash (I1a: the OS page cache
persists past the dying daemon) but \emph{not guaranteed} for an OS crash or power
loss (I1b), because under normal synchronization the WAL is synced only at
checkpoints. This is exactly the Gray--Reuter atomicity-versus-durability
distinction, and it is the one fault class a ``the file survives every agent's
death'' framing most invites the reader to over-assume. We split the invariant
accordingly: I1a is \textsf{implemented}; I1b is \textsf{not guaranteed} under the
default WAL configuration.}
