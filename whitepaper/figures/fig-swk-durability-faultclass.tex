\caption{Durability by fault class. Under the default WAL configuration, a returned
write survives a process crash (I1a), because the operating system remains live,
but it is not guaranteed to survive an OS crash or power loss (I1b), because normal
synchronization may defer persistence to checkpoint. Full synchronization or a
checkpoint on the commit path changes the latter boundary; the kernel does not pay
that cost by default.}
