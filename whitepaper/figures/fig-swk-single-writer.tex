\caption{\textbf{Single-writer serialization.} Concurrent callers converge on
one daemon-owned request queue; only the sole write connection can append to the
WAL commit spine. The queue supplies the architectural discipline, while SQLite's
file lock is the correctness backstop. With one decider there is no agreement
protocol to run; adding a second daemon would cross the chapter's fault boundary.}
\label{fig:swk-single-writer}
