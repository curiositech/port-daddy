\caption{The single-writer serialization. Concurrent command-line and agent requests are
assigned one queue order; the daemon is the sole active read--write connection, so
each successful mutation enters one durable commit history. There is no agreement
protocol inside this machine: the system has one decider. The model ends if a second
daemon shares the file, which is a cross-machine problem rather than a kernel
property.}
\label{fig:swk-single-writer}
