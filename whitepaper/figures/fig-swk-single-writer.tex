% requests may arrive together, but one daemon admits them to an ordered write
% ledger.  The file lock is a backstop; the daemon queue determines the order.

\caption{Many requests may arrive in overlapping intervals, but the daemon assigns one
admission order and commits that order to a single SQLite write-ahead log.  The queue,
not a visual hub, is the operative serialization point; the OS-level file lock is the
backstop if a second writer ever appears.  With one decider on one machine, there is no
distributed agreement problem to solve: the boundary becomes a distributed problem only
when another daemon is permitted to write the same state.}
\label{fig:swk-single-writer}
\end{figure}
