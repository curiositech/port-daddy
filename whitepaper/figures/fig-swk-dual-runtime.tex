\caption{The dual-runtime substrate, a genuine kernel property the seeds treat as
an implementation detail. One \texttt{DatabaseInstance} interface is satisfied by
\emph{two} SQLite bindings: \texttt{better-sqlite3} under jest (where invariants
are \emph{verified}) and \texttt{bun:sqlite} in the compiled daemon (where truth
is actually \emph{computed}). A pragma/option shim bridges them, but the bridge is
not a proof: an invariant green under test can be 500 in production if the
bindings diverge in lock or pragma semantics --- the recurring
``green-in-jest, 500-in-bun'' failure. Invariant I11 (runtime parity) is
therefore \textsf{BUILT-WEAK}, and open problem OP-3 asks for the differential-test
harness that would make it a theorem.}
