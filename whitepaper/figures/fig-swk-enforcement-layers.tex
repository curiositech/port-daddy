% Reader question: which layer of enforcement actually stops a

%   process -- is a real wall; the three layers below it are proofs and
%   tripwires a determined same-user agent can still step around.

%   Coordination Guard, shim and hook harness (Built, in-band, advisory);
%   a server-side branch-protection-plus-push-broker (Designed); a
%   credential broker (Vision); a separate-user kernel (Vision, the only
%   layer that removes the capability rather than refusing the verb).
% Must distinguish: what each layer stops, in one clause, so a reader
%   cannot mistake "verified" for "compulsory"; that only the top band is
%   built from a different primitive (removes capability, not verb).
% Grammar: maturity stack, full-width bands, the one real wall highlighted
%   at the top. Rejected: a 2x2 (proves x compels), which would flatten
%   four distinct layers into one boolean and lose the "only the top layer"
%   claim.
