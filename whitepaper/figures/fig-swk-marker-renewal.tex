% Brief (tikz-diagram-craft).
% Reader question: why does a stale marker never need cleaning up?
% Claim: a marker lives exactly as long as someone keeps renewing it; a crashed
%   agent's markers are gone 90 minutes after its last mark, deleted by nobody.
% Evidence: lib/pheromone.ts as shipped (server.ts uses the defaults):
%   decayRate 0.95 per 60 s interval; deleted when below 0.01; spray() SETS the
%   strength, so a re-mark resets it to 1. 0.95^89 = .0104 > .01 > .0099 =
%   0.95^90. Live agent re-marks every 25 min (illustrative cadence): its
%   strength never falls below 0.95^25 = .277. [analytic, from the code]
% Must distinguish: renewed vs abandoned; the deletion threshold; when.
% Grammar: snapshots of the shared board (dot area = strength) on the same time
%   axis as the strength traces, log y so decay is a straight line.
%   Rejected: the w(t) curve alone (fig-swk-marker-decay) -- it shows the
%   arithmetic, not that renewal is what keeps a signal alive.
% Five-second test: "the blue dots stay, the grey dots fade out by minute 90".
% CAPTION IS A DRAFT FOR THE AUTHOR.
