\node[organ,below=4mm of resource] (oblig)
  {{\bfseries Obligation \& enforcement}\\ Arbiter (regiment/detect) + commitments (enforce).\\

\node[organ,below=4mm of identity] (cont)

\caption{The kernel as \emph{seven organs}, each a contract the daemon must hold
for the stack above to be coherent. Six organs are, mechanically, just tables
\emph{with discipline} over a single shared file --- the \textbf{substrate
organ}, the single-writer transactional floor. The substrate's pragma set
\emph{is} the kernel's durability claim; everything else is convenience built on
top of it. Honest labels (\textsf{BUILT} $\cdot$ \textsf{BUILT-WEAK} $\cdot$
\textsf{DESIGNED} $\cdot$ \textsf{VISION}) are per organ; note that the identity
organ is BUILT but \emph{self-asserted}, the gap the Anchor Protocol proper
(L3) eventually closes.}
