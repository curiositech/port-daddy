\caption{The claim lifecycle is a three-state durable-row model with a separate
transition ledger.  Atomic acquisition makes one row the unique holder (I2); a
same-actor re-claim and release are idempotent (I3); and an expired row returns to
free only when a later read deletes it (I4).  There is deliberately no \textsc{queued}
state: the kernel has no fairness primitive, so a fast agent can repeatedly win a
hot resource.  That missing state is open problem OP-1, not an invisible property of
the diagram.}
