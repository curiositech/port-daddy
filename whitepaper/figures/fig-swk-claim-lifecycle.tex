\caption{The claim/lock lifecycle as a finite-state machine, exhibiting the four
properties on which L1 builds typed ownership. \emph{Acquire} is an atomic
\texttt{PRIMARY KEY} insert (I2: a concurrent acquirer loses cleanly to
\texttt{SQLITE\_CONSTRAINT} and is handed the holder). \emph{Re-claim} and
\emph{release} are idempotent (I3): safe to retry, safe to double. Expiry is
\emph{lazy-swept} on the next read (I4), not on a timer. The conspicuous missing
state is \textsc{queued}: there is no fairness primitive, so a hot resource can
starve a slow agent --- open problem OP-1, which asks whether bounded-wait can be
added without dragging a scheduler down into the kernel.}
\label{fig:swk-claim-lifecycle}
\end{figure}
