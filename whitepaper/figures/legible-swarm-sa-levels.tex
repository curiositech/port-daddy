% Reader question: which of Endsleys three levels of situation awareness
%   does digest-with-zoom actually reach, and which is missing?
% Claim: SA has three levels (perception, comprehension, projection);
%   digest-with-zoom is a perceive-and-comprehend instrument, so projection
%   -- what the swarm will do next -- is the missing, needed third level,
%   validated by a freeze-probe.
% Evidence: sec:sa, whitepaper/legible-swarm.tex (Endsley 1995, Endsley and
%   Kiris 1995), this pass.
% Must distinguish: the two levels digest-with-zoom already reaches from
%   the one it does not; that the missing level is forward-looking, the
%   named complement to the backward-looking forensic time axis.
% Grammar chosen: block stack, three levels with a bracket for the missing
%   one, since the claim is a containment/coverage relation (which levels
%   a given instrument reaches), not a quantity or a sequence of events.
% Grammar rejected: a timeline of past/present/future (already the chosen
%   grammar for Sec. timeaxis, fig ch4-58) would restate the temporal axis
%   rather than Endsleys own perceive/comprehend/project hierarchy, which
%   is a level of processing, not a point in time.
% Five-second test: how many of the three levels does digest-with-zoom
%   reach today, and which one is still missing?
