% Reader question: when can Maya and the routing agent share one ranking?
% Claim: a strict reversal, not a difference in units or a tie, prevents
% one order from satisfying both readers at every selection budget.
% Evidence: synthetic ordinal ranks over three proposals named for real
% lib/ artifacts; the complete data is pdRankSamples below. Checked by
% tests/harbor-research/test_legible_swarm_split_ranker.py; no measured scores.
% Must distinguish: readers (left/right) from alternative cases (top/bottom);
% rank 1 is highest on BOTH sides. Only the briefing/attention pair reverses.
% Grammar: Tufte classical slopegraph, identical geometry and direct baseline labels.
% Reject: oversized geometric marker badges, raw fit-versus-loss units, or unified scores.
% Five-second test: Maya puts attention.ts first while the router puts
% briefing.ts first; resurrection.ts remains third for both.
% Width: the 4.5-inch Book column, unscaled. All type inherits shared roles.
% Design references: https://charliepark.org/slopegraphs/ (ordinal scales,
% ties, direct labels); https://www.edwardtufte.com/notebook/
% sparkline-theory-and-practice-edward-tufte/ (words and graphics together).
\begin{figure}[H]

\pdfigurehue{pdteal}%
\begin{tikzpicture}[pd figure,x=1cm,y=1cm]

  \def\panelpitch{3.55}
  % artifact / routing rank / Maya agreement rank / Maya dispute rank / role tag
  \def\pdRankSamples{%

      \draw[draw=pdink!15,line width=0.4pt] (\rx,0.18) -- (\rx,-1.85);
      \foreach \artifact/\route/\agreement/\dispute/\role in \pdRankSamples {
        \pgfmathtruncatemacro{\readerRank}{ifthenelse(\panel==0,\agreement,\dispute)}

        \pgfmathsetmacro{\yR}{-(\readerRank-1)*\rankpitch}

            {\texttt{\artifact}\quad\textbf{\route}};

            {\textbf{\readerRank}\quad\texttt{\artifact}};
