% Restyle of fig-split-ranker to the tikz-diagram-craft v2 standard (v1
% names and raw colours migrated to roles; slope-chart layout unchanged,
% ch4.md restyles). Fixes the clipped end glosses: they now sit on a wider
% grid with enough margin that "safe, calm" and the other three-word tags no
% longer run off the picture's own edge.
%
% Reader question: how can one substrate support two incompatible rankings?
% Claim: discovery rank and attention rank are not monotone rescalings of
% each other -- two candidates (A, B) fully invert, and a smaller pair
% (C, D) swap one adjacent step, the same non-comonotone fact in miniature.
% Evidence: candidates A (best fit, safest to skip) and B (poor fit, most
% dangerous to miss), whitepaper/legible-swarm.tex [internal].
% Must distinguish: the full inversion (A, B) from the adjacent swap (C, D);
% which end of each axis a candidate sits at, named at both ends so no
% legend is needed.
% Grammar chosen: paired ranked lists (slope chart) -- two rank columns,
% one line per candidate; a shared substrate splitting into two scoring
% lanes is exactly this grammar's reading.
% Grammar rejected: a single weighted score would erase the claim, which is
% that no single rescaling reconciles the two orders.
% Five-second test: which candidate is safe to skip but dangerous to miss?
\begin{figure}[H]
\centering
\pdfigurehue{pdteal}%
\begin{tikzpicture}[pd figure,x=.60cm,y=1cm]

    {rank by discovery\\(fit)};
  \node[pd title,text=pderror,anchor=south,align=center] at (\rx,6.05)

    \node[pd label,anchor=east] at (\lx-.30,\y) {\rank};
    \node[pd label,anchor=west] at (\rx+.30,\y) {\rank};}

  % A: discovery rank 1 -> attention rank 4 (safe to ignore)

  \node[pd focus label,anchor=east,align=center,text width=2.3cm]

\caption{One candidate pool under two loss functions, ranks 1--4 on both
axes. Discovery ranks by fit; attention ranks by expected regret if ignored.
Candidate A is the best fit but safest to skip, while B is a poor fit but the
most dangerous to miss, so their ranks fully invert (1--4 against 4--1). C
and D swap one adjacent pair, the same non-comonotone fact at smaller scale.
Shared candidate generation and recency decay do not make the two scoring
heads interchangeable [internal].}
