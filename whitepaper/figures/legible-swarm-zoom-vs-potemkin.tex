% Reader question: can each claim a digest makes reach reviewable evidence?
% Claim: two summaries of identical shape differ entirely in whether their
% claims resolve to anything -- one is an index, the other terminates early.
% Evidence: PR 123's three claims (auth refactor, tests pass, one critique)
% each resolving to a named artifact, versus a same-shaped "ALL GREEN"
% summary resolving to nothing, whitepaper/legible-swarm.tex [internal].
% Must distinguish: a claim that resolves to a named artifact (solid arrow,
% pd state box) from a claim that resolves to nothing (dashed arrow, pd
% breach datum), holding the tree shape identical between the two trees.
% Grammar chosen: two claim trees, aligned (S1-style before/after) -- the
% same shape twice is the whole point; a single annotated tree would hide
% that a Potemkin digest can advertise the same claim count.
% Grammar rejected: a Venn of worlds or a prose list would lose the tree's
% own claim-to-evidence edges, which are the fact being compared.
% Five-second test: which tree's leaves are things an operator can open?
