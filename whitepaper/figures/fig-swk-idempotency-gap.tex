%   redelivered, with and without an idempotency key?

%   same semantic effect -- silent, but conventional, not explicit. An
%   envelope idempotency key would make retry safety explicit: a stored
%   receipt, not a convention.

%   key is currently absent, the coordination layer's debt);
%   Exercise~\ref{ex:swk-redelivery} and its solution.
% Must distinguish: both panels reach the same operator-visible outcome
%   (one act); what changes is HOW the duplicate is recognized, and that
%   even the fixed version does not guarantee exactly-once for an
%   unbrokered external effect.

%   what changes between the two panels.

%   one by a stored receipt".
