% Figure 9 — typed evidence passes a narrow closure aperture.
% Redrawn: the previous version spread the four oracle-vocabulary arrows and
% the OPEN/DONE row across a nearly 9-unit-tall canvas with nothing in the
% middle third but a bare vertical rule and the words "typed oracle" -- ink
% proportional to the number of things being said, not to how much page it
% is allowed to take. Tightened so every element sits within about 5 units,
% the gate is one short segment instead of a nearly full-height rule, and
% the four vocabulary arrows converge from a compact stack that clears the
% OPEN/DONE row instead of overlapping it.
\begin{figure}[H]

\caption{Typed evidence passes through a narrow closure aperture. A
commitment closes as done only when the daemon can re-run a check from the
finite oracle vocabulary: a released claim, merged commit, passing test id,
or satisfied policy sub-check. A free-text assertion is refused and the
commitment remains open. The deadline is set by the daemon, not the agent.
[internal]}
