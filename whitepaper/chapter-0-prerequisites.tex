\begin{abstract}
Before constructing an operating kernel for autonomous systems, we must establish the physical and theoretical ground upon which modern AI agents stand. This chapter establishes the five core foundations assumed by the subsequent eight chapters: (i)~classical multi-agent systems and intentional agency (the BDI model, Hewitt--Agha actor concurrency, and FIPA speech acts); (ii)~the physical mechanics of autoregressive transformers and the memory asymptotics of the key-value (KV) cache; (iii)~the agent harness lifecycle, tool dispatch turn-loops, and hook-based observation injection; (iv)~the compute topology separating frontier cloud reasoning from local host actuation; and (v)~the architectural necessity of an external kernel, proving why generative models cannot act as their own operating system.
\end{abstract}

\section{Introduction: The Lineage of Agency}

Autonomous AI agents did not begin with large language models. The problem of coordinating multiple independent computational processes, each pursuing distinct local goals under incomplete information, has occupied distributed systems and artificial intelligence research for more than four decades.

When modern developers observe an LLM invoke a bash shell, parse the JSON output, and plan its next move, they are observing the convergence of two previously separate research lineages:
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt]
  \item \textbf{Symbolic Multi-Agent Systems (1975--2010):} Formal architectures for intentional agency, asynchronous message passing, contract negotiation, and communicative action.
  \item \textbf{Statistical Connectionism (2017--2026):} Deep autoregressive sequence prediction trained over planet-scale code and text corpora, capable of flexible semantic synthesis and zero-shot reasoning.
\end{enumerate}

The tension between these lineages defines the subject of this textbook. Modern frontier models supply unprecedented semantic reasoning, but possess neither persistent memory, monotonic security boundaries, nor physical execution guarantees. To scale from an isolated interactive assistant to an autonomous engineering fleet, we must place statistical models inside a rigorous structural envelope.

\section{Classical Multi-Agent Foundations}

Three classical formulations provide the mathematical and conceptual language for reasoning about multi-agent systems: the BDI model of mental states, the Actor model of asynchronous concurrency, and the theory of communicative speech acts.

\subsection{The BDI Architecture (Beliefs, Desires, Intentions)}

Formalized by Rao and Georgeff~\cite{rao1991modeling,rao1995bdi} following Michael Bratman's philosophical account of practical human deliberation~\cite{bratman1987intention}, the \textbf{BDI} architecture models an agent as a bounded rational system governed by three primary mental attitudes:
\begin{itemize}[leftmargin=1.8em,itemsep=3pt]
  \item \textbf{Beliefs ($\mathcal{B}$):} The agent's information about the state of the world, itself, and other agents. In an LLM agent, $\mathcal{B}$ is represented in-flight by the contents of the context window (system prompts, user instructions, file listings, tool execution outputs).
  \item \textbf{Desires ($\mathcal{D}$):} The motivational states or potential objectives allocated to the agent. A software development agent may desire to ``fix bug \#412'', ``maintain 100\% test coverage'', and ``minimize execution latency''.
  \item \textbf{Intentions ($\mathcal{I}$):} The subset of desires to which the agent has actively committed resources and execution time. Commitments persist across discrete actions until achieved, recognized as impossible, or superseded by higher-priority events.
\end{itemize}

\begin{pdclaim}{Design invariant}{Commitment Persistence}\label{inv:commitment-persistence}
An agent's intention $\iota \in \mathcal{I}$ must not be abandoned merely because a single step incurs a transient tool failure. Intention reconsideration is an explicit state transition triggered by invariant failure or objective discharge, not an accidental consequence of context window truncation.
\end{pdclaim}

In classical BDI interpreters (such as PRS, dMARS, or Jason), intention maintenance was regimented by a deterministic execution cycle. In an LLM agent, where deliberation occurs through autoregressive generation, intentions are fragile: attention dilution or misleading intermediate tool errors routinely cause models to wander into unrelated sub-tasks---a pathology known as \emph{intention drift}.

\subsection{The Hewitt--Agha Actor Model}

Concurrency in multi-agent environments cannot safely rely on shared-memory synchronization with raw threading primitives. The theoretical foundation of modern agent message fabrics is the \textbf{Actor Model}, pioneered by Carl Hewitt~\cite{hewitt1973actor} and formalized by Gul Agha~\cite{agha1986actors}.

In the Actor model, the primitive unit of computation is the \emph{Actor}. Each actor possesses:
\begin{enumerate}[nosep]
  \item Private, unshared internal state.
  \item A sequential mailbox queue.
  \item The ability to send a finite number of messages to addresses it possesses.
  \item The ability to create a finite number of new actors.
  \item The ability to designate the replacement behavior for the next message.
\end{enumerate}

\begin{equation}
\text{Actor}(S, m) \;\xrightarrow{\text{atomic}}\; \big( S',\; \{m_1, m_2, \dots, m_k\},\; \{\alpha_{\text{new},1}, \dots, \alpha_{\text{new},j}\} \big)
\end{equation}

The Actor model enforces \emph{share-nothing isolation}. Modern agent harnesses mirror this structure: an autonomous agent runs in an isolated operating process or sandbox, interacts with peers exclusively via structured message buses (such as Swarm Radio or Relay), and delegates tasks by spawning subagents with scoped authority.

\subsection{Speech Acts and Communicative Performatives}

Agents do not merely transmit unstructured data; their messages constitute actions that alter social and legal commitments. Based on Austin's speech act theory~\cite{austin1962how} and Searle's philosophy of language~\cite{searle1969speech}, the Foundation for Intelligent Physical Agents (\textbf{FIPA}) standardized Agent Communication Language (\textbf{ACL}) performatives~\cite{fipa2002acl}:
\begin{itemize}[leftmargin=1.8em,itemsep=2pt]
  \item $\mathtt{inform}(i, j, \phi)$: Agent $i$ asserts to $j$ that proposition $\phi$ holds.
  \item $\mathtt{request}(i, j, a)$: Agent $i$ asks $j$ to perform action $a$.
  \item $\mathtt{propose}(i, j, a, c)$: Agent $i$ offers to perform action $a$ under condition $c$.
  \item $\mathtt{agree}(i, j, a, c)$: Agent $i$ commits to perform action $a$.
  \item $\mathtt{refuse}(i, j, a, r)$: Agent $i$ declines request $a$ with explanation $r$.
\end{itemize}

In this volume, communicative acts cease to be informal JSON payloads. They become cryptographically bound, verifiable transactions: an $\mathtt{agree}$ corresponds to an accepted Float Plan (§\ref{pre:sec:kernel-gap}), while an $\mathtt{inform}$ must be backed by an append-only cryptographic receipt.

\section{Transformer Mechanics and Memory Scaling}

Modern agents deliberate by querying an autoregressive transformer. Understanding the computational and physical constraints of this inference engine is essential for building an operating kernel.

\subsection{Autoregressive Inference and Attention Complexity}

Given a sequence of input tokens $x_{1:t} = (x_1, \dots, x_t)$, a decoder-only transformer computes the conditional probability distribution over the vocabulary for the next token $x_{t+1}$:
\begin{equation}
P(x_{t+1} \mid x_1, \dots, x_t) \;=\; \mathrm{softmax}\left( \frac{Q_t K_{1:t}^\top}{\sqrt{d_k}} \right) V_{1:t}
\end{equation}
where $Q, K, V$ are the query, key, and value projections. For a sequence of length $T$, computing full self-attention requires $O(T^2)$ floating-point operations across all query-key pairs.

\subsection{The KV-Cache Asymptotics}

During generation, past key and value vectors are cached in GPU memory to avoid recomputing past token representations at step $t+1$. For a model with $L$ layers, $N_h$ key-value heads, dimension per head $d_h$, and precision bytes $b_p$, the memory footprint of the KV-cache for a context of length $T$ is:
\begin{equation}
\mathrm{Memory}_{\mathrm{KV}} \;=\; 2 \times L \times N_h \times d_h \times T \times b_p \quad \text{bytes}
\end{equation}

For a typical 70-billion parameter model ($L=80, N_h=8, d_h=128$, 16-bit FP16 precision $b_p=2$), each token in the context consumes:
\begin{equation}
2 \times 80 \times 8 \times 128 \times 2 \;=\; 327{,}680 \;\text{bytes/token} \;\approx\; 320 \;\text{KB/token}
\end{equation}
At a context length of $T = 128{,}000$ tokens, the KV-cache for a \emph{single} agent process consumes approximately $40.96$ GB of high-bandwidth VRAM---exceeding the entire parameter storage of smaller models.

\begin{pdclaim}{Theorem}{The Ephemeral Memory Limit}\label{thm:ephemeral-memory}
The context window of a transformer is volatile, expensive, and subject to attention dilution (effective information retrieval degrades with sequence depth~\cite{liu2024lost}). Consequently, long-term system state cannot be maintained by continuously appending tool execution logs to the prompt. Durable state must reside in an external, indexed, and ACID-compliant storage engine.
\end{pdclaim}

The harness operates as a deterministic finite-state machine driving an indeterminate generator:
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt]
  \item \textbf{Pre-Invocation:} The harness assembles the system prompt, environment variables, tool schemas, and recent message history.
  \item \textbf{Inference:} The prompt is transmitted to the inference provider (local or remote). Tokens are streamed until an end-of-turn or tool-use stop token is encountered.
  \item \textbf{Interception \& Validation:} The harness extracts the tool call arguments (e.g., `bash`, `write_file`, `http_request`). Before execution, the harness verifies permission parameters against local policies.
  \item \textbf{Execution:} The command executes inside an operating sandbox or local process.
  \item \textbf{Observation Injection:} The raw stdout/stderr output is sanitized, truncated if necessary to respect budget bounds, formatted as a tool-result block, and appended to the context.
  \item \textbf{Evaluation:} The harness inspects whether terminal conditions (objective satisfied, unrecoverable crash, or budget exhaustion) are reached; if not, the cycle repeats.
\end{enumerate}

Because cloud reasoning is high-latency and probabilistic, it is incapable of resolving local race conditions. If two cloud agents concurrently attempt to edit line 42 of the same file, relying on their internal world models to avoid collisions guarantees data corruption. The resolution must be executed locally by a synchronous, zero-latency authority.

\section{The Kernel Gap: Why LLMs Cannot Be Their Own OS}\label{pre:sec:kernel-gap}

A seductive but fatal fallacy in modern AI engineering is the belief that an LLM can serve as its own operating system kernel---that prompts such as ``\emph{Please do not modify files currently being edited by other agents}'' are sufficient to preserve system integrity.

We term this discrepancy the \textbf{Kernel Gap}. Language models fail as operating systems across four fundamental dimensions:

\subsection{1. Non-Determinism vs. Invariant Regimentation}
An operating system kernel must enforce \emph{regimented invariants}: physical guarantees that cannot be bypassed by any user process (e.g., memory page protection via MMU hardware). Prompts are mere suggestions. Even fine-tuned models exhibit a non-zero probability of instruction failure, hallucination, or adversarial prompt injection. A security policy enforced solely by a prompt is an advisory boundary, not an invariant.

\subsection{2. Concurrency and the Mutual Exclusion Anomaly}
In any concurrent system with two or more uncoordinated writers, atomic mutual exclusion is required to prevent race conditions. Without an external serialized lock broker, concurrent LLM agents exhibit the classic lost-update anomaly: Agent A reads version $v_0$, Agent B reads $v_0$, Agent A writes $v_A$, and Agent B subsequently overwrites with $v_B$, silently destroying Agent A's work without compiler or runtime warning.

\subsection{3. Attenuation and Privilege Escalation}
In classical capability-based operating systems (e.g., KeyKOS, EROS, Capsicum), authority flows monotonically downward: a child process can never possess more capability than its parent. When an LLM delegates sub-tasks by synthesizing new prompt instructions, authority frequently inflates due to broad, imprecise system instructions. True privilege containment requires cryptographically unforgeable, attenuated tokens (Harbor Cards, Chapter 2).

\subsection{4. Mortality and Economic Accountability}
Subprocesses are transient. An agent can crash, get SIGKILLed, or reset its context, discarding all local history. If reputation, debt, and liability exist only in process RAM, defecting agents face zero consequence for bad actions. Accountability requires persistent outcome ledgers, Merkle-backed event histories, and economic escrows that survive the death of the acting process (Chapters 5--7).

\section{Chapter Map and Structure of the Book}

The remainder of this textbook is organized into eight cumulative chapters across four distinct operational levels:

\begin{itemize}[leftmargin=1.8em,itemsep=4pt]
  \item \textbf{Chapter 1: The Single-Writer Kernel (Ground Truth).} We construct the minimal deterministic local kernel using SQLite WAL mode, establishing serializability, synchronous state decidability, and crash durability across process failures.
  \item \textbf{Chapter 2: The Anchor Protocol (Capability Delegation).} We design cryptographically verifiable capability tokens (Harbor Cards) and prove that delegated authority can only narrow at every hop.
  \item \textbf{Chapter 3: The Sealed Harbor (Confinement \& Leakage).} We construct isolated execution harbors that bound information leakage between distrustful principals under strict egress quotas.
  \item \textbf{Chapter 4: The Legible Swarm (Human Supervision).} We derive the information-theoretic cost of supervisory attention, proving how digests must retain evidence paths without drowning the operator in raw telemetry.
  \item \textbf{Chapter 5: From Spawn to Person (Durable Agency).} We define persistent agent identity, append-only outcome ledgers, and reputation mechanisms that survive process restarts.
  \item \textbf{Chapter 6: The Harbor Economy (Markets \& Clearing).} We establish bilateral clearing, underwriting reserves, and dynamic pricing for scarce host resources.
  \item \textbf{Chapter 7: The Bonded Commons (Game-Theoretic Governance).} We formalize claim signaling as an incentive-compatible repeated game, proving when cooperation is sustained under bonded escrow.
  \item \textbf{Chapter 8: The Federated Harbor (Cross-Machine Consensus).} We extend governance across distrustful host boundaries via witness logs and sheaf-theoretic consistency without central sovereignty.
\end{itemize}
