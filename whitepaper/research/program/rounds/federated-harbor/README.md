# Federated Harbor research rounds

This directory is the canonical output root for future Federated Harbor author,
adversarial-review, and defense rounds. A round should keep probes, responses,
adjudication, changed claims, unresolved carryovers, and artifact references in
one versioned directory.

Round records are research-process evidence. They are not formal proof. A model
mentioned here becomes corpus evidence only after its source, run receipt, and
status are registered in `whitepaper/corpus.json`. Planned paths must use the
`MECHANIZATION-PENDING:` marker; synthetic skill examples remain labeled as
fixtures and may not be cited as executed results.
