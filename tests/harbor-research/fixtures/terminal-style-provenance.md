# Terminal frame regression proof

This fixture proves layout, not a new research result. It loads the actual Book
preamble and `figures/session-fh-rollback.tex` directly. No transcript copy is
checked in. The exact-byte regression hashes the entire canonical recorded
excerpt, including comments, caption, blank lines, and output.
Its existing provenance remains `scripts/harbor-research/record_sessions.sh`;
that command is **not** rerun by this fixture.

The long specimen is actual stdout from a read-only inventory of 48 existing
figure sources. The builder captures it, then wraps those bytes in one
`pdsession`. The output stays under the requested build directory and is not
source material to commit. The short completion marker is also captured from
a local `printf`; neither command contacts a service or invokes Port Daddy.

From the repository root, with Tectonic's bundle already cached, librsvg and
Poppler available, and `PD_BOOK_FONT_DIR` pointing to licensed Suisse OTFs:

```sh
python3 scripts/harbor-research/build_terminal_style_fixture.py \
  --out-dir .cache/terminal-style-proof --font-dir "$PD_BOOK_FONT_DIR" \
  --mono-font-file /System/Library/Fonts/Menlo.ttc
BOOK_TERMINAL_PDF=.cache/terminal-style-proof/terminal-style-book.pdf \
  python3 tests/harbor-research/test_terminal_style.py -v
```

The optional Menlo argument reproduces the parent's focused macOS proof; it
is an explicit system-font choice, not an absolute lab path. Omit it to use
the Book's normal mono family. Without licensed fonts the builder labels the
output **open-proof**, whose pagination is not Suisse evidence. The optional
rendered tests target the three-page Suisse/Menlo witness; source checks need
no fonts or renderer. On machines with a broken Homebrew Python XML module,
use system Python for the tests. No dependency installer is run automatically.

The builder converts the already-vendored terminal SVG to a vector PDF **only
inside its output directory**. No icon download, canonical asset write, PD
process, or full Book compilation is involved. It records source SHA-256s,
captured stdout/transcript SHA-256s, and font choices in
`terminal-provenance.json`. Logs and 120dpi color page images are retained.

The existing full `figures/lucide/LICENSE` remains unchanged: ISC plus Feather
MIT; terminal is explicitly among the Feather-derived icons. Production PDFs
can be regenerated by the updated `vendor_lucide_book_icons.sh`, or locally
with `rsvg-convert --format=pdf1.5`; PDF binaries are not embedded in the patch.

Manual gates after compilation: inspect every page at full-page and 100%
views; all split pieces must have a full perimeter and asymmetric teal corners;
native 8.6/10.6pt mono text must fit the inset; Listing 2 must cross pages with
one caption; the rail must remain free of frame/text collisions; synthetic
sample data must remain neutral feed-paper. Automated checks cover exact
canonical bytes, rendered text through wrapping, page count, bounds, numbering,
source identities, and the warning/convergence log. They do not independently
prove frame geometry. The direct framed margin note is an allocator check,
**not** a bibliographic-citation-renderer check. Middle pieces of a three-piece
split and full-Book integration remain outside this focused fixture.
