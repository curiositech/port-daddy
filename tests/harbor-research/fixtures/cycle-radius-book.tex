\section*{The visible loop sets the certificate}
\begin{pdexample}{one altered edge in a visible cycle}
\marginnote{\input{figures/spark-fh-cycle-radius}\par
Unit-weight visible cycles, one altered edge. Longer loops certify a smaller
fraction of the lie; a bridge certifies zero.}
For a unit-weight visible cycle $C_n$ and one altered edge of magnitude $|s|$,
the consistency residual is $r=|s|/\sqrt n$. At $n=4$ it certifies half the
alteration; at $n=24$ it certifies about one fifth. These are exact-model
calculations, not observations of a deployed federation.
\[r(C_6,|s|=3)=3/\sqrt6\approx1.2247.\]
The cycle must exist in the visible coordinate graph $K_c$. A nominal loop
with a severed link does not supply the same evidence.
\end{pdexample}
