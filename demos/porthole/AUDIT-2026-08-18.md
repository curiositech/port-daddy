# Terminal Recording Audit — portdaddy.dev (website-v2)

*Read-only audit, 2026-08-18, session cli-output-capture-viz. All 47 casts under
`website-v2/public/casts` decoded and read in full; both recorder scripts, the gate, the
manifest, all five consumers, and 20 VHS tapes read.*

## 1. Headline verdict

The operator's three suspicions (errors on camera, truncation/flashing, staleness/staging) are
all confirmed, and there is a fourth problem that is worse than any of them:

**The most prominent "real recording" surface on the landing page is not a recording at all.**
`src/components/landing/TerminalDemos.tsx` declares `gif:` and `caption:` fields for every demo
— and never renders them. There is no `<img>` in the file. It renders `CommandTerminal` with
hand-authored `code:` strings through a typewriter animation, under the section copy *"See it
run for real … These are real recordings, with the daemon answering back."*
(`TerminalDemos.tsx:139`). The fabricated output does not match the CLI (e.g. `Session started ·
port 9201 · identity photoapp:api` at `TerminalDemos.tsx:17` — `pd begin` prints no such line).

## 3. Systemic problems, ranked

1. Landing page presents hand-written fiction as recordings (zero gate coverage).
2. The gate is structurally blind: typed commands are char-split across events so every
   path/secret regex misses; root casts unscanned; CI regenerates assets into a throwaway
   runner and never validates what is committed; job is path-gated so green usually = skipped.
3. Errors and empty output ship as marketing (12 casts).
4. `sed -n '1,18p'` silently amputates payoffs; 80→110-col geometry mismatch corrupts typed lines.
5. `object-cover` CSS crops 13%+ off terminal GIFs (`AgentsPage.tsx:1800`, `HarnessPage.tsx:878,900`,
   `MacWorkflowDemos.tsx:155`).
6. Fabricated/spliced provenance (spliced cast; "recorded from real…" watermark baked into
   frames; `gen-tapes.sh` plants the steering alert it presents as organic, tapes never committed).
7. Product bugs preserved on camera (actors --limit, wrong actor, services column overflow).
8. Privacy/hygiene leaks (home paths, worktree names, internal notes, cross-tenant channel).
9. Stale CLI surface in tapes (`demos/demo.tape` is 75% dead commands; `--last` vs `--limit`;
   manifest advertises `--reply-to=` where the real flag is `--reply=`).
10. Duplicates and dead assets (3 tutorials share one recording; `cli-overview.gif` fronts every
    CLI command page; `RECORDING_ASSET_VERSION` frozen in April while June assets shipped).
