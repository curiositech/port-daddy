Terminal replays that are real text, not pixels.

Every frame below is an honest asciicast capture of the released pd CLI against the live daemon — no truncation, no staging, no GIF. It streams like a terminal, scrolls like a terminal, and you can select and copy every character.

pd —
select any line to copy — it’s real text
0.0s / 0.0s

Capture

asciicast v2 from a real PTY: every output byte timestamped at emission. The recorder types; the product answers. Nothing is piped through head ever again.

Replay

A ~200-line VT interpreter turns the byte stream into styled DOM spans with full scrollback — output longer than the viewport is scrollable history, not lost frames.

Explorability

Pause it. Scrub it. Slow it to quarter speed. Hover a line for the ⧉ copy glyph, or just select text like it’s your own terminal — because it effectively is.
