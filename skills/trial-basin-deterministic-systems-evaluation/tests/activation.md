# Activation tests

## Must activate

1. Use a deterministic fake to support an admission-state claim.
2. Replay a crash/duplicate/reorder trace as release evidence.
3. Minimize a concurrency counterexample.
4. Use a shadow or canary result to justify readiness.
5. Check that an oracle detects manifest-declared negative controls.
6. Compare model-checked conservation with an implementation trace.

## Must not activate

1. Run an ordinary pure helper unit test with no system claim.
2. Launch a real VM or provider.
3. Authorize a canary.
4. Grant a capability.
5. Conduct a market interview.
6. Claim screen-reader usability from a static DOM assertion.
