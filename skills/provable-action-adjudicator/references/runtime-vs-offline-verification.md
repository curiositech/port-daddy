# Runtime versus offline verification

Do not assume a microsecond budget or import another system’s benchmark. Measure the exact decision path on the frozen local build, workload, machine, policy size, and concurrency.

Runtime may evaluate a bounded precomputed predicate. Proof search, model construction, unbounded reachability, and deployment claims remain offline or unproven. A passing runtime predicate establishes only that predicate on the observed inputs; it does not establish complete mediation, liveness, or target-side settlement.

Use the claim ladder in SKILL.md and `references/evidence-classes-and-uncertain-effects.md` to state the bounded result.
