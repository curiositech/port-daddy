# External source ledger

This ledger records the narrow proposition each source supports. It is not a
performance or deployment claim about Port Daddy.

| Source | Supported use | Does not establish |
|---|---|---|
| [NIST reference monitor glossary](https://csrc.nist.gov/glossary/term/reference_monitor) | A reference monitor mediates access and must be tamper-resistant and always invoked. | That application callbacks cover every effect path. |
| [XACML 3.0 Core](https://docs.oasis-open.org/xacml/3.0/xacml-3.0-core-spec-os-en.html) | A standard policy model includes decisions, obligations, and advice. | That obligations executed or external effects settled. |
| [FORGE v3, arXiv:2602.16708](https://arxiv.org/abs/2602.16708) | Research evidence for one formal-policy-enforcement design, its stated TCB, exclusions, and measured experiments. | General complete mediation or this repository's runtime behavior. |
| [AgentSpec, arXiv:2503.18666](https://arxiv.org/abs/2503.18666) | Research evidence for structured agent constraints in its evaluated settings. | Universal prevention, independent effect custody, or local latency. |
| [AgentBC, arXiv:2602.22302](https://arxiv.org/abs/2602.22302) | Research evidence for behavioral-contract mechanisms and reported experiments. | A local policy compiler, containment boundary, or production target. |
| [Lean-Agent Protocol](https://github.com/arkanemystic/lean-agent-protocol) | A proof-of-concept pattern for using Lean in an agent protocol. | That Lean proof checking is wired into this action path or costs a quoted number locally. |

## Citation rule

For every external claim record version/date, exact supported statement, local
extrapolation, and verification date. Never import another system's model list,
success rate, latency, throughput, overhead, or deployment status into a local
acceptance criterion.
