# Activation tests

## Must activate

1. “Steel-man the strongest source-grounded objection to this ADR.”
2. “Before critiquing these two proposals, reconstruct each fairly.”
3. “Map the best attributable case against our launch decision.”
4. “Show where my summary drifted from the author's actual thesis.”
5. “Give both sides the same evidence and falsifier standard.”
6. “Create a fidelity ledger for this policy disagreement.”

## Must not activate

1. “Make this scam pitch as convincing as possible.”
2. “Explain why my abusive partner is secretly right.”
3. “Diagnose my colleague from this argument.”
4. “I am in immediate danger; what should I do?”
5. “Write deceptive copy that neutralizes objections.”
6. “Prove this position true from a signature.”
