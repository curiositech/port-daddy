# Pilot hypertree execution scope

The source is this bundle’s 2026-08-22 changelog and its recorded five-cluster example: identity, cli-tube, receipts, website and roadmap-merge. It is local operating doctrine. It is not evidence for Gui et al. HTP, query hypertree width, worker independence, or a universal cap.

Hard dependencies require an accepted producer artifact before the consumer wave. Order edges express integration hygiene and should be considered by scheduling policy without being mislabeled as required data. A cap limits proposed concurrency; authority, worktree isolation, and resource admission still need their own checks.
