# Meta-programming boundary

Consider an artifact pipeline when the task has distinct handoffs, stable enough artifact contracts, and consumers that can name prerequisites. Prefer direct work or a looser reviewed workflow when the request is still materially ambiguous, the handoffs would not add inspectable evidence, or a fixed SOP would hide useful exploration. MetaGPT proposes role prompts, SOP artifacts, and coordination; it does not prove this outperforms direct programming in every domain.

If comparing approaches, hold model, tools, time/token budget, and acceptance tests constant. Report scoped executability, incomplete requirements, repair count, and human correction separately. Paper benchmark scores remain tied to their task/model/setup, not a production claim.
