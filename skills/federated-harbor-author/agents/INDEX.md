# Agents — Federated Harbor (author side)

Subagent role cards. Dispatch the one whose job matches the slice in front of you.

- `drafter.md`: `fh-author-drafter` — drafts a new section or claim against the
  topic map and probe template.
- `voice-editor.md`: `fh-author-voice-editor` — passes a draft through the
  voice check so the prose matches the paper's registered voice.
- `cross-paper-citation.md`: `fh-author-cross-paper-citation` — resolves and
  inserts citations across the federated-harbor paper set using
  `cross-paper-dependencies.md`.
