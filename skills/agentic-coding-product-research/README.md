# Agentic Coding Product Research

Evidence-backed product research for AI coding assistant and software-agent tools.

Use this skill when a Port Daddy slice needs current audience stories, competitive mechanics, social/homegrown workflow evidence, and a ranked opportunity map.

## Quick Start

1. Read `SKILL.md`.
2. Load `references/source-map.md` for current source lanes and citations.
3. Load `references/audience-stories.md` for segmentation and Port Daddy opportunities.
4. Put sources and audiences into a manifest.
5. Run `node scripts/story_matrix.mjs --input manifest.json`.

The output should distinguish verified facts from inference and name which claims need fresh verification before publication.
