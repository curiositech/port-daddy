# Book Evidence Writing

Editorial craft and revision discipline for *The Harbor, the Person, and the Economy* (The Harbor Book).

## Overview

This skill guides authors and editors revising manuscript sections to ensure that prose, figures, tables, and marginalia explain a single coherent argument without relying on private design documents, unpublished ADR numbers, or ungrounded claims.

## Structure

- `SKILL.md`: Main execution instructions and editorial checklist.
- `references/`: Reference documentation for argument inspection and margin apparatus.
- `examples/`: Worked before-and-after text and margin transformations.
- `tests/`: Verification test suite asserting editorial invariants.
