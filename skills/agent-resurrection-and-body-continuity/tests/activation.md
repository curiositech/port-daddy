# Activation tests

## Should activate

1. “The VM never came up; how do we retain the agent's assignment without
   starting a hundred replacements?”
2. “Codex hit its usage wall. Continue the same durable worker in Claude without
   copying credentials or replaying its GitHub call.”
3. “The process was garbage-collected and later woke after a successor started;
   design generation fencing.”
4. “Audit whether our resurrection capsule safely carries tools, skills, hooks,
   permissions, plan, and exact worktree state.”
5. “Can this provider-native session be resumed, or must we create a sanitized
   cross-harness successor?”
6. “Design a cold-birth state machine where process creation or handshake fails.”
7. “Audit this request to transplant an old agent's credential and transcript
   into a replacement body.” Activate in order to return `INVALID` and explain
   the fresh-grant path; activation does not imply compliance.

## Should not activate

1. “The operator retired this AgentNode last month; bring it back.” Use the
   explicit identity-resurrection governance path.
2. “Restore our PostgreSQL database after a disk failure.” Use database disaster
   recovery expertise.
3. “Restart this ordinary stateless web process.” Use service supervision.
4. “Write a better one-shot prompt for this coding task.” Use prompt engineering.
5. “Define long-term reputation and compensation for a caste of agents.” Use
   identity/reputation and agent-economy expertise.
