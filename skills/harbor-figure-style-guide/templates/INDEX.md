# Templates Index

This directory contains standalone, canonical TikZ templates for the diagram families and scratch prototype figures:

- [before-after-pair.tex](before-after-pair.tex): Before-and-after contrast panel pair with consistent bounding geometry.
- [dag-causal-tree.tex](dag-causal-tree.tex): Directed acyclic graph / causal tree diagram with layered hierarchy.
- [pgfplots-regime.tex](pgfplots-regime.tex): PGFPlots quantitative regime partition diagram.
- [record-byte-layout.tex](record-byte-layout.tex): Binary protocol record and memory byte layout diagram.
- [scratch_actor.tex](scratch_actor.tex): Hewitt-Agha actor concurrency operational diagram.
- [scratch_bdi.tex](scratch_bdi.tex): Rao-Georgeff BDI operational deliberation architecture diagram.
- [scratch_csp.tex](scratch_csp.tex): Communicating Sequential Processes (CSP) synchronous rendezvous diagram.
- [sequence-protocol.tex](sequence-protocol.tex): Multi-participant temporal sequence protocol ladder diagram.
- [state-machine.tex](state-machine.tex): Formal state machine transition graph.
- [swimlanes-gantt.tex](swimlanes-gantt.tex): Concurrent agent execution Gantt and swimlane timeline diagram.
