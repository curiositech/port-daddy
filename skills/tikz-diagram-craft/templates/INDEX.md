# templates/

One compiling fragment per grammar, drawn to the v2 language and the 4.5 in column.
Copy the one whose grammar answers the figure's reader question.

| File | Grammar |
|---|---|
| `tpl-before-after.tex` | the same system before and after one change, identical geometry |
| `tpl-block-stack.tex` | layers that sit on each other, with a bracket for the chapter's layer |
| `tpl-grid-matrix.tex` | where each item lands in a fixed grid of slots |
| `tpl-message-ladder.tex` | numbered, forward-sloped messages keyed to a ruled legend of what each binds |
| `tpl-nested-sets.tex` | containment on real axes (a child inside its parent on both) |
| `tpl-quadrant.tex` | a 2 × 2 with one concrete instance per cell |
| `tpl-regime-plot.tex` | a region between two curves (`fillbetween`), a worked point dropped to both axes |
| `tpl-sequence.tex` | lifelines and numbered messages between named parties |
| `tpl-slope-chart.tex` | two ranked columns, one line per item, a rank-swap crossing in the chapter hue |
| `tpl-small-multiples.tex` | a `groupplot` of panels on one shared scale, one varying parameter per panel |
| `tpl-state-machine.tex` | a spine of states, guarded transitions as badges, a ruled legend |
| `tpl-step-chart.tex` | a quantity that narrows through stages, `const plot`, never interpolated |
| `tpl-swimlane-gantt.tex` | concurrent work in lanes over a single commit rail |
| `tpl-timeline-epochs.tex` | epochs on one axis, bounded by named instants |
| `tpl-tree-dag.tex` | derivation left to right, the refused edge dashed |
| `tpl-waterfall.tex` | a running total, one floating bar per correction, computed base-to-top |
