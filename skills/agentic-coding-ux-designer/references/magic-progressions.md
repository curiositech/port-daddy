# Magic Progressions For Agentic Coding UX

Use this when designing the flow that makes users return.

## The Seven-Beat Loop

1. **Natural entry**: User starts from the thing already causing friction: selected code, failing test, terminal block, issue, PR comment, screenshot, or spoken note.
2. **Context snap**: App shows what context was captured and what remains invisible.
3. **Intent preview**: Agent declares goal, scope, model, tools, budget, and stop condition.
4. **Visible work**: User sees current step, commands, file changes, test results, queued messages, and blockers.
5. **Cheap steering**: User can interrupt, queue follow-ups, narrow scope, or ask "why."
6. **Local review**: Diffs, evidence, and comments appear where the work happened.
7. **Receipt and recovery**: Checkpoint, transcript, tests, final diff, risks, and rollback are durable.

## Comeback Triggers

- The first run fixes a real local pain within 5 minutes.
- The user can undo without thinking.
- The agent asks a useful question while continuing non-blocking work.
- The next session remembers the right project rules but not stale noise.
- Background agents feel alive: heartbeat, spend, current file, cancel, and result.
- The receipt reduces reviewer labor rather than adding another explanation chore.

## Screens That Matter

- Start work: goal, repo, files, model, budget, safety mode.
- Live work: steps, commands, tools, file claims, queued input, blockers.
- Diff review: grouped hunks, tests, rationale, accept/reject, rollback.
- Swarm board: roles, owners, worktrees, status, spend, conflicts, merge owner.
- Receipt: transcript, commands, tests, artifacts, PR links, unresolved risks.

## Taste Rules

- Use compact operator surfaces, not marketing hero layouts.
- Prefer symbols and status chips for repeated controls, but label unfamiliar agent concepts.
- Keep progress and risk close together: "running tests" and "last failed test" belong in the same visual area.
- Make permission prompts specific: tool, path, reason, blast radius, and default safe action.
- Show the first useful artifact early. A plan, diff preview, or failing-test diagnosis is better than a decorative spinner.
