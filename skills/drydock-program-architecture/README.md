# Drydock Program Architecture

This is the integrated entrypoint for designing the Drydock program. It joins
containment, durable agent bodies, subscription capacity, context control,
operator experience, and proof without replacing the focused skills that own
those contracts.

Start with `SKILL.md`. Load only the reference named at the decision you are
making. The local Port Daddy halt remains authoritative: source implementation
and static validation may proceed, but this bundle cannot authorize a run.

For hypertree execution, the bundle now separates the static eligibility DAG
from bounded review/rework routing, manager staffing rounds, and one append-only
event projection shared by browser, Swift, and Rust clients. A pure TypeScript
controller reducer and cursor-bound projection consumer are now source-present;
none has been promoted beyond T0. The included T0
fixture deliberately fails a structurally complete but substantively unproven
first attempt, then requires a low-cost independent review, authority
specialist, and distinct manager before accepting the repair; it is contract
evidence, not a running engine.
The reducer binds capacity receipts and witness labels but deliberately does not
authenticate them; that requires the future signed controller ingress and
broker witness, so H1 remains protocol proof rather than spend-custody proof.
