# Drydock Program Architecture

This is the integrated entrypoint for designing the Drydock program. It joins
containment, durable agent bodies, subscription capacity, context control,
operator experience, and proof without replacing the focused skills that own
those contracts.

Start with `SKILL.md`. Load only the reference named at the decision you are
making. The local Port Daddy halt remains authoritative: this bundle can design
and statically validate Drydock, but it cannot authorize a run.
