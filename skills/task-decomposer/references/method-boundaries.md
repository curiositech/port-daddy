# Method and evidence boundary

The task-decomposition procedure is first-party planning policy. It is not validated by keyword matching, a universal node count, a one-call size limit, or an uncalibrated confidence value.

[Erol, Hendler, and Nau (1994)](https://www.cs.umd.edu/~nau/papers/erol1994semantics.pdf) formalize hierarchical task-network planning using task networks and methods with formal applicability/solution semantics. A prose workplan becomes an HTN only after it supplies the relevant primitive-task, method, precondition/effect, and solution definitions.

A typed work graph can be checked structurally: each edge endpoint exists, every producer output exists, the graph is acyclic, and a topological layer respects edges. These checks do not prove that tasks are executable concurrently, that outputs are correct, or that an effect is authorized.
