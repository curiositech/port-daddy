# Activation tests

## Must activate

1. Reserve model allowance and wall time before a new attempt.
2. Decide whether a retry may reuse capacity after lost acknowledgement.
3. Preserve teardown capacity while ordinary work exhausts its budget.
4. Reconstruct balances after a crash between reservation and lease creation.
5. Hand completed-effect evidence to an independent dispute process.
6. Admit a successor that requires a new resource vector.

## Must not activate

1. Rank roadmap work by product value.
2. Select a model from a benchmark.
3. Decide whether a shell command is permitted.
4. Grade a pull request for correctness.
5. Determine employment or tax status.
6. Convert tokens, dollars, time, and attention into one universal score.
