# Three meanings of hypertree

- HTP: Gui et al.’s rooted, rule-licensed planning outline.
- Query hypertree decomposition: [Gottlob, Leone and Scarcello](https://arxiv.org/abs/cs/9812022) variable bags `chi(p)`, hyperedge covers `lambda(p)`, and width `max |lambda(p)|` for formal query/CSP assumptions. It is not an LLM outline or agent count.
- Pilot hypertree: first-party context-cluster doctrine. Its caps and wave rules are policy.

A planning child set, a query hyperedge cover, and a work cluster answer different questions. Do not transfer a width or tractability result into a planning claim.
