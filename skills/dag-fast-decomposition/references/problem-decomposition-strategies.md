# Choose traversal, index, or another objective

First decide whether the question is reachability, exact chain partition, direct-edge path cover, or scheduling. For rare reachability checks, traversal can be simpler. For many checks on a static graph, test the index break-even with measured preprocessing, memory, and baseline latency. For durations/resources, use a scheduling method rather than a reachability index.

A meaningful comparison holds graph revision, query distribution, verifier, and hardware/environment fixed. Source: [SEA 2023](https://drops.dagstuhl.de/opus/volltexte/2023/18352/pdf/LIPIcs-SEA-2023-2.pdf).
