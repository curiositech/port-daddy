# Index applicability and validation failures

High `k_c` increases `O(k_c|V|)` index space. Frequent graph changes invalidate static precomputation. Unsorted adjacency changes the construction bound. A partial filter does not license an exact-reduction claim. Each condition is a measurement or model boundary, not a diagnosis of an agent organization.

For a rollout, record DAG revision, chain decomposition, memory, preprocessing time, query p50/p95, baseline agreement, rejected/unknown cases, and rebuild disposition. A failed baseline comparison blocks use of the index for that revision.

Source: [SEA 2023](https://doi.org/10.4230/LIPIcs.SEA.2023.2), full-paper complexity/correctness and empirical scope.
