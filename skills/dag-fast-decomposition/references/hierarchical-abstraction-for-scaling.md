# A proposed application needs a measured graph

Chain-based indexing is a graph method. Applying it to skill routing, agents, or architecture is a constructed proposal until nodes, edge meaning, static window, query mix, and independent baseline are supplied. Width does not equal active workers, and dense graphs do not automatically become easier.

Use the SEA method only for its documented static reachability task. Report the observed benefit and representation cost; do not call transitive edges “illusory complexity.”

Source: [SEA 2023](https://doi.org/10.4230/LIPIcs.SEA.2023.2).
