# Width is a poset property, not coordination cost

For reachability order, width is a maximum-antichain size and, by Dilworth, minimum disjoint-chain count. It can parameterize an index but does not predict worker count, failure propagation, or a universal density phase transition. The SEA paper's generator-specific observations are not an arbitrary-DAG estimator such as `|V|/average degree`.

Use matching on reachability comparability for an exact width certificate; then separately measure index space and query behavior. Sources: [Dilworth 1950](https://doi.org/10.2307/1969503); [SEA 2023](https://doi.org/10.4230/LIPIcs.SEA.2023.2).
