# Tug discrepancy and bounded model revision

```mermaid
flowchart TD
  A[Two generic simulator scenarios; optional tug offered] --> B[Initial GOMS assumes no tug and omits tug procedures]
  B --> C[Final model review: five selected SWOs]
  C --> D[All five choose tug and find the no-tug model inaccurate]
  D --> E[They report no-tug handling as very rare because of damage consequences]
  E --> F[Grassi revises model to include tug procedures]
  F --> G[Finding remains bounded to this sample and scenarios]
```

Source: Grassi IV.B.1 and IV.C.3 (printed pp. 44–45, 50). Each scenario used a twin-screw ship, empty pier, and 1–2 knots of wind and no current. The tug was optional. This records a specific assumption discrepancy and revision; it does not establish a universal tug rule or advise live operations.
