# Reference Index

Load one reference at a time. Do not read the whole folder by default.

## Decision References

- `framework-selection.md`: use when choosing the Rust desktop stack or challenging an existing choice.
- `visual-inspiration.md`: use when the user asks for gorgeous examples, visual references, templates, tutorials, or proof of what Rust desktop apps can look like.
- `visual-design-system.md`: use when the request asks for modern, beautiful, buttery, native-feeling desktop UI.
- `architecture-and-state.md`: use when defining code structure, state, IPC, persistence, or OS integration.
- `security-privacy-packaging.md`: use when the app touches local files, secrets, updater, signing, installers, telemetry, or privileged APIs.
- `performance-accessibility-testing.md`: use when proving the app is fast, accessible, stable, and cross-platform.
