# Source-to-claim and evidence limits

| Source | Supports | Does not support |
|---|---|---|
| [NIST AI RMF 1.0](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10), inherited research reading | Risk/context/evidence framing | Universal disclosure, cache, memory, or approval rule |
| [Anthropic prompt caching docs](https://platform.claude.com/docs/en/build-with-claude/prompt-caching), checked 2026-09-24 | Provider-specific cache configuration vocabulary and documented TTL options | Cache hit, installed model behavior, or universal cadence |
| [MCP stable 2025-11-25 specification](https://modelcontextprotocol.io/specification/2025-11-25), inherited research reading | Protocol/topology vocabulary | A fixed MCP size, safety level, framework choice, or runtime performance |

A static declaration and its audit prove only supplied-field consistency. Separate implementation, runtime, provider, account, and effect evidence must name the observation and boundary.
