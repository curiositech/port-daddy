# Evidence scope

## Opened source

A. S. Rao and M. P. Georgeff, *BDI Agents: From Theory to Practice* (ICMAS 1995), https://doi.org/10.5555/2074336.2074341

## What it supports

It supports the source-specific concepts used in `bdi-agency-model`. The skill deliberately avoids treating it as proof of a universal threshold, security property, legal conclusion, commercial comparison, or local runtime result.

## Use rule

For a current framework or provider claim, re-open the authoritative documentation on the implementation date and record the checked version or update date. For local behavior, attach a reproducible test and observed receipt.
