# Activation tests

## Must activate

1. Continue a durable actor in another backend.
2. Compact a long session while preserving active obligations.
3. Translate skills, tools, permissions, and model settings to a new body.
4. Mix current directives with historical memory and untrusted documents.
5. Join retrieved memories from a versioned embedding space.
6. Prepare a successor capsule after a crash.

## Must not activate

1. Summarize a short meeting for human reading only.
2. Grant a filesystem or network capability.
3. Decide whether a predecessor process is dead.
4. Copy a token or another actor's context file.
5. Rank public documents where no continuation or authority boundary exists.
6. Admit or start the proposed body.
