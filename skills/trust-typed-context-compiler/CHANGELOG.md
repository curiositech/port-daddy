# Changelog

## 1.0.1 — 2026-09-17

- Enforce the schema's closed retrieval, obligation, and translation status vocabularies in the executable validator.
- Add unknown-status mutations so arbitrary values cannot fall through as omission or coverage states.

## 1.0.0 — 2026-09-16

- Establish trust-typed Context IR with authority filtering before relevance.
- Separate verified facts, live directives, historical intent, proposals, inferences, third-party content, and secret handles.
- Make retrieval-space identity, redaction, obligation coverage, body translation, omissions, and unknowns explicit.
- Preserve context preparation as proposal evidence with no admission or capability authority.
- Add a closed schema, executable example, semantic validator, activation corpus, and adversarial test bundle.
