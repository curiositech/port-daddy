# Operad source scope

- [Spivak 2013](https://arxiv.org/abs/1305.0297), sections 2, 4 and 5: typed wiring diagrams, operads, algebras, plug-and-play and recursion.
- [Vagner, Spivak and Lerman](https://arxiv.org/abs/1408.1598), sections 2–4: a particular operad and compatible open dynamical-system algebra.

Units, associative substitution, and symmetric equivariance concern formal composites. A matching operation signature does not prove implementation conformance. This skill’s acyclic workflow is an engineering restriction; the source wiring grammar can discuss recursion.
