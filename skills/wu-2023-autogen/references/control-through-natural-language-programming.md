# Prompt policy plus code-enforced bounds

The paper shows natural-language control in a system message: ask the Assistant to revise on observed errors, return code and output in an agreed format, and emit `TERMINATE` when it considers the task complete (arXiv:2308.08155, §2.2 and Appendix C). Treat that as an advisory response policy. It may guide an LLM's message, but it does not itself enforce a transition or an external effect.

Pair the prompt with executable controls: an `is_termination_msg` predicate over a received message, `max_consecutive_auto_reply` for a direct agent, configured human-input mode, and an executor policy. For a group, separately configure participants, speaker-selection method, allowed transitions where used, and `max_round`. Preserve prompt text, code control, selected speaker/reply path, and terminal reason together. The paper also describes code-to-natural control through a reply function that invokes LLM inference, and natural-to-code control through LLM-proposed function calls; neither makes an LLM's choice an enforced authorization. [Paper v2](https://arxiv.org/html/2308.08155v2); [0.2 ConversableAgent API](https://microsoft.github.io/autogen/0.2/docs/reference/agentchat/conversable_agent/), accessed 2026-09-24.
