# Port Daddy Users

24 named, textured personas standing in for Port Daddy's real audience spectrum — solo/indie developers, small and big engineering teams, enterprise decision-makers, hiring managers evaluating Erich Owens/Curiositech, friends of Erich, AI power-users, curious newcomers, and one deliberately adversarial skeptic.

Used as test subjects for `ux-friction-analyzer` and `product-appeal-analyzer`: pick the 4-8 personas relevant to a given surface (landing page, install flow, CLI onboarding, pricing/licensing, README-as-portfolio), and see where their reactions diverge. Full profiles live in `references/personas.md`; see `SKILL.md` for the selection matrix and usage process.
