# Examples — Federated Harbor (red-team side)

Worked artifacts you can copy and adapt.

- `probe-trust-example.json`: a filled-in red-team trust probe (matches
  `probe-template.json`) showing the expected shape for a single attack claim.
- `dialogue-fh-v0.1-to-v0.2.example.json`: an example adversarial dialogue
  transcript moving a claim set from v0.1 to v0.2.
