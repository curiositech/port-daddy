# Sources and accounting boundary

[Graham 1966](https://ia801900.us.archive.org/27/items/bstj45-9-1563/bstj45-9-1563_text.pdf) assumes finite fixed-duration tasks, identical processors, precedence, and non-preemption. It does not establish optimality for uncertain heterogeneous runs. In the fixture, one ISO date-day is one constructed tick and the human gate is not a compute slot.
