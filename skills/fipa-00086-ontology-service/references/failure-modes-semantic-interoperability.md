# Semantic mismatch dispositions

## Diagnostic dispositions

`not-understood` means content was not understood; `failure` records an attempted action that failed; `refuse` is a refusal. For modification, XC00086C defines `READ-ONLY` and `INCONSISTENT` reasons. A missing response is transport or availability evidence until separately diagnosed; it does not prove the relationship is absent.

Weak translation permits loss without added inconsistency; approximate translation can introduce inconsistency. Neither supplies application action rules. Put confirmation, action gating, loss reporting, or criticality requirements in named local policy.

Positive: store returned expression and fixture result with direction. Negative: if a fixture relies on an unmapped fruit category, retain it as unsatisfied rather than silently deleting its constraint.
Record syntax-invalid, unknown term, ambiguous mapping, unacceptable loss, inconsistent mapping, provider refusal, and missing response separately. A valid serialized response can still be semantically unsuitable. Test a candidate mapping with fixed task fixtures and preserve the fixture/version/result.
