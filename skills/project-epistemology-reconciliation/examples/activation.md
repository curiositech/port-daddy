# Activation examples

These are expected routing examples, not observed model activation results.

## Positive triggers

1. “Does our new analytics exception supersede the old PostgreSQL-only decision?”
2. “These two changes merge cleanly, but could their combined effect violate our promise?”
3. “Reconcile these conflicting reviewer findings and preserve the rejected argument.”
4. “Prepare an impact preview showing whose commitments this policy change invalidates.”
5. “Audit this structured reconciliation packet before the outcome owner reviews it.”

## Negative triggers

1. “Summarize this article in three sentences.” → ordinary summarization.
2. “Restart the coordination daemon.” → administration; outside this skill and currently forbidden.
3. “Choose the winning argument by majority vote.” → clarify jurisdiction; voting is not this workflow.
4. “Verify this cryptographic signature.” → a signature-verification tool and explicit trust roots.
5. “Publish this decision automatically.” → an independently authorized publication workflow, not this skill.
