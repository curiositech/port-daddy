# Changelog

- Added a dependency-free, local-only Harbor Clearance projection over frozen
  repository artifacts and captured PR metadata.
- Added exact structured relation classes, proposed PR dispositions and a
  fail-closed claim-level loss audit for destructive candidates.

  plan-to-implementation seam, plus negative, adversarial and property tests.

  generated reports to `.cache/harbor-clearance/`.
