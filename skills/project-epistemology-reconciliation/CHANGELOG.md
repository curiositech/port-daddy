# Changelog

## 0.1.1 — 2026-09-08

- Declared nonblank patterns and safe integer maxima in the packet schema.
- Made the validator interpret those rules, including Unicode code-point length.
- Added independent Ajv parity tests for every string/revision schema location;
  the standalone declaration auditor remains dependency-free and non-actuating.

## 0.1.0 — 2026-09-08

- Added a single-scope, offline reconciliation workflow and declaration auditor.
- Added strict input shape, three anti-pattern finding families and CLI failure exits.
- Added synthetic passing input, negative/malformed regressions and activation examples.
- Explicitly excluded runtime authority, independent-review proof and paid execution.
