# Stratification is a representation, not an optimality shortcut

A topological layering is useful for visualization and for algorithms that specify it, but a largest layer is merely an antichain and may not be maximum. Local matching between adjacent layers can be a heuristic; it does not become a proof of a globally minimum reachability-chain partition unless the exact method and proof establish it.

If using the 2009 Chen procedure, name its paper and retain its virtual-node/alternating-graph context. If using exact Fulkerson matching, use reachability comparability across all relevant vertices.

Sources: [Chen 2009 PDF](https://www.scitepress.org/PublishedPapers/2009/18583/18583.pdf); [Fulkerson 1956](https://resources.mpi-inf.mpg.de/departments/d1/teaching/ss11/graph_theory/DilworthFulkerson.pdf).
