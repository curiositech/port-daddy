# Chen method source boundary

The searchable body of Yangjun Chen’s [ICEIS 2009 paper](https://www.scitepress.org/PublishedPapers/2009/18583/18583.pdf) was available only to the B06 primary-source research through indexed body text; a direct PDF request can return 403. That source describes three phases—DAG stratification, chain generation, and virtual-node resolution—distinguishes virtual nodes generated for actual nodes from virtual nodes generated for virtual nodes, and names a combined alternating graph used to maximize virtual-node resolution at each level.

The fully operational construction/proof for the alternating graph was not verified in the research record. The paper critiques a different 2008 Chen-and-Chen algorithm as sometimes non-minimum; it must not be conflated with the DEXA 2007 record, whose access is abstract/metadata level here. Therefore this bundle does not implement or certify a generic Chen-style level matching algorithm.

For exact finite-poset chain partitions, use the separate Dilworth/Fulkerson comparability-and-maximum-matching proof procedure in the entry skill. These source roles are not interchangeable.
