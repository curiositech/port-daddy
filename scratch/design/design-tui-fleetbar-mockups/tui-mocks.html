How a developer implements this

Hero cost-burn strip

  • Top horizontal slice: Layout::vertical([Length(4), Fill(1), Length(4)]).
  • $23.40 number: tui_big_text · BigText::builder().pixel_size(PixelSize::Full).style(Style::new().fg(canary).bg(ebony)).lines(vec!["$23.40".into()]).build().
  • Daily cap progress: ratatui::widgets::LineGauge with line_set(symbols::line::THICK), ratio 0.585, filled cinnabar / unfilled ebony.
  • Outer chrome: Block::bordered().border_type(BorderType::Thick).border_style(canary.bold()).

Scrollback body

  • Container: tui_scrollview::ScrollView sized to the conversation bounds; pages on PgUp / PgDn.
  • Each chat bubble: Block with BorderType::Rounded, Padding::uniform(1); inner Paragraph with Wrap{ trim:false }.
  • User bubble: bg cinnabar Rgb(204,61,46), fg paper, right-aligned via Layout::horizontal([Min(0), Length(34)]).
  • Agent bubble: bg ebony, border canary, left-aligned; title is "──[K] cartographer · INFORM · 14:33" rendered as the Block title (top-left).

Inline syntax-highlighted code block

  • Syntax highlighter: syntect with TextMate themes, output converted to ratatui::text::Line spans (one Span per scope).
  • Line-number gutter: a 4-wide Layout::horizontal([Length(4), Fill(1)]) column, fog-deep on ebony, tabular-nums.
  • Inside the agent Block, this nests as a child Paragraph.

"Agent thinking" throbber

  • Spinner widget: throbber_widgets_tui · Throbber::default().throbber_set(BRAILLE_DOUBLE).throbber_style(sky.bold()).
  • Stateful — store ThrobberState on the app model, advance on every Event::Tick (10 Hz is enough).
  • Companion label: "drafting test plan · 3 routes · 19s" rendered as a Paragraph in fog.

Mike flag at 8×8 cells

  • ratatui::widgets::canvas::Canvas · marker(Marker::HalfBlock) · x_bounds([0.0,16.0]) · y_bounds([0.0,16.0]).
  • Paint: blue navy background via a Rectangle, then two white diagonals as Line with color: Color::Rgb(245,245,240). Each cell renders as a 2-row HalfBlock — two square pixels per cell.
  • For Yankee / Bravo (diagonal stripes harder than ±45°), bump to Marker::Octant at 12×12 cells (8 sub-pixels per cell, v0.30+).

Input bar

  • Editor: tui_textarea · TextArea::default().set_cursor_line_style(Style::new()).
  • Frame: a Block with a custom symbols::border::Set using ▓ for top/bottom and side strokes — neobrutalist filled-edge.
  • Below: a thin Paragraph with hints; key bindings handled by your event loop, not tui-textarea (which is editor-local).

Effects (tachyonfx)

  • New bubble appearance: tachyonfx · fx::fade_in((400, Interpolation::SineOut)) scoped to the new bubble's Rect via CellFilter::Area.
  • "Agent thinking" arrival: fx::slide_in(Direction::Up, 18, 0, (250, Interpolation::CubicOut)).
  • Cost-burn dollar number ticks: fx::evolve((180, Interpolation::Linear)) on the digit cells only.

States not shown

  • Empty conversation: the scrollback shows only the cost-burn strip and a centered "start with a question · /flag M to escalate" hint in fog-deep.
  • Stream error: a transient Foxtrot pill replaces the throbber; the agent Block border switches from canary to cinnabar; retry-with-backoff line beneath.
  • Daily cap exceeded: the cost-burn strip's 58% gauge lifts to 100% cinnabar; the input bar shrinks to a single read-only line "cap reached · raise with `pd costs --cap`".
  • Tool-call in flight: agent bubble carries a sub-bubble with a Bravo flag and the syntect-highlighted tool args.

Flags used on this mock

  • K · Kilo — I wish to communicate (INFORM bubbles)
  • M · Mike — vessel stopped (review-needed escalation)

Contrast note: user-bubble pair (paper #F5F5F0 on cinnabar #CC3D2E) sits at 4.5:1 — the AA Normal floor with no headroom. If cinnabar drifts darker or the renderer applies any dim modifier, this pair tips into failure. Option to lift to paper-soft #FFFFFF on cinnabar (~5.2:1) is documented in the audit grid. This is the tightest pair in the file; flagged for design review.

How a developer implements this

The DAG canvas

  • Outer frame: a single Canvas sized to the fleet column, marker(Marker::Braille), x_bounds([0.0, 100.0]), y_bounds([0.0, 40.0]).
  • Edges: ctx.draw(&Line { x1, y1, x2, y2, color: mustard }) per parent→child pair. Call ctx.layer() between edges and nodes so nodes paint on top.
  • Nodes: a custom Widget impl (see "Agent node widget" card) painted into the canvas's sub-area — NOT via canvas shapes, since Block borders sit better as real cells.

Agent node widget (custom)

  • impl Widget for AgentNode · in render(self, area, buf) draw a small Block with rounded borders, then a 3-line Paragraph of "name / state-tag / target".
  • State tag is one of [A] [I] [D] [M] styled to kelp / sky / cinnabar / mustard.
  • Position resolved via Layout::horizontal([Length(20), Length(38), Length(20)]) nested inside vertical splits — the DAG layout is a static HashMap<NodeId, Rect> the renderer reads.

Active-edge pulse

  • tachyonfx · fx::repeating(fx::sequence(vec![ fx::hsl_shift([0.0, 0.0, 8.0], (300, Interpolation::SineIn)), fx::hsl_shift([0.0, 0.0, -8.0], (300, Interpolation::SineOut)) ])).
  • Targeted at the active edge's cells via CellFilter::Area(active_edge_rect).
  • Idle edges get no effect — performance budget is for the live ones only.

Severity ledger column

  • Outer: a Block titled "SEVERITY LEDGER" with custom border_set using ┏ ┓ ┗ ┛ ━ ┃ (a literal Thick set).
  • Inside: a List of entries — each row is a styled Line: ICS code in cinnabar/mustard/sky/kelp bold, then timestamp + actor in paper, then a fog-tagged subtitle.
  • Codes map to flags: V=Victor (escalation), F=Foxtrot (failure), D=Delta (blocked), I=India (query), C=Charlie (agree).

Throughput & CPU sparklines

  • Throughput: Sparkline with direction(Direction::Right), max=auto, bar_set(symbols::bar::NINE_LEVELS), style canary.
  • CPU: same widget, max(100), style sky. Updated on each Event::Tick from a ring buffer.

Footer gauge

  • LineGauge with filled_symbol("━"), unfilled_symbol("━") (same glyph, different colors) and ratio(0.62).
  • ETA text + CPU mini-spark rendered as Paragraph children in a 3-column Layout::horizontal.

Agent-node avatar (Octant)

  • Each node carries a 2-cell ICS-flag avatar to its left: ▀▄ (Charlie — affirmative), ●● (India — query), ▀▀ (Delta — blocked), ▞▚ (Mike — idle).
  • Real rendering: ratatui::widgets::canvas::Canvas · marker(Marker::Octant) · x_bounds([0.0, 4.0]) · y_bounds([0.0, 4.0]). Octant gives 8 sub-pixels per cell (v0.30+) — enough density for Charlie's 5-stripe field or November's 4×4 checker, where HalfBlock would alias.
  • Paint the field as a Rectangle, then the inner shape as Line or Points. Each cell renders 2×4 colored sub-pixels.

Severity-ledger flag micro-glyphs

  • Each row in the SEVERITY LEDGER leads with a 2-cell HalfBlock pixel flag, NOT a bracketed letter code. The flag IS the indicator.
  • Canvas · marker(Marker::HalfBlock) · x_bounds([0.0, 4.0]) · y_bounds([0.0, 2.0]) per row. Field rectangle + diagonal/horizontal/center-dot shape painted in the flag's signal colors.
  • Color hand-off (HTML mock ↔ ratatui): Victor = paper-on-cinnabar X via Marker::Octant diagonals; Foxtrot = cinnabar diamond on paper; Delta = horizontal canary/ebony band via two stacked half-blocks; India = canary field, single ebony center pixel; Charlie = 5-stripe blue/white/red field via per-row HalfBlock fill.

Keybind footer

  • Outer: a single-row Block across the bottom edge with border_set using ▓ for top + bottom — the same HEAVY_UNREAD set documented in mock 04.
  • Inside: one Paragraph of styled Spans — key chord canary bold, label fog. Keys: ⏎ focus node · p pause · j/k navigate severity · f filter by flag · / search · q quit.
  • This is mostly observational; ⏎ on a Severity Ledger row drills into the FIPA envelope (deep-link to pd inbox --conversation).

States not shown

  • Empty fleet: "no agents · run pd spawn" centered Paragraph with a faint canary border.
  • Loading / connecting: a throbber_widgets_tui spinner replaces the DAG until the first Event::Render after the SSE handshake.
  • Daemon-disconnected: Severity Ledger collapses to a single Victor row "daemon offline · last seen 14:32" on a blood-bg.
  • Mouse-focus: hover on an agent node lifts the border to canary bold; out of scope for this static frame.

Flags & codes used on this mock

  • P · Papa — about to proceed (CFP — fleet starting up)
  • V · Victor — I require assistance (severity high)
  • F · Foxtrot — I am disabled (failure)
  • D · Delta — keep clear (blocked)
  • I · India — altering course to query (in-progress / scanning)
  • C · Charlie — affirmative (agree / completed)
