  {\textbf{Property.} Reputation is \emph{monotone in honest outcomes}
   ($o_1,o_2,o_4$ never silently erased) but \emph{individually revocable}: the
   fraudulent $o_3$ is nullified by an appended \textbf{tombstone}, which
   \emph{propagates} across harbors bounded by the revocation-convergence window
   (Paper~4). The poisoned point was spendable only during that window.\\[3pt]
   \textbf{Bounded memory} (Liu--Skrzypacz) is a \emph{tunable parameter}, not a
   virtue: $\infty$-memory is rarely optimal --- it freezes types and removes the
   incentive to keep performing.};

\caption{\textbf{Tombstone revocation on an append-only ledger.} A fraudulent
outcome is not deleted (that would break append-only and auditability); it is
nullified by an appended \emph{tombstone} --- a saga-style compensating entry ---
which propagates across harbors. ``Reputation never ends'' is corrected to:
monotone in \emph{honest} outcomes, individually revocable via tombstone, with
bounded memory as a design parameter.}
\label{fig:tombstone}
