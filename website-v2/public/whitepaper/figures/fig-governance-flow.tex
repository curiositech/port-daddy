\caption{\linespread{1.08}\selectfont\textbf{Dispute resolution is a guarded
state machine, not a free-form process.} Four terminal states, tried in
increasing cost: direct release, TTL time-out, bonded preemption, and human
escalation. Escalation to the next state fires only when the current guard
fails to resolve the dispute --- the claimant does not yield, no heartbeat
arrives, the wait cost exceeds the preemption bond, or the case is ambiguous
or high-stakes. Every terminal state writes the same evidence record --- actor,
reason, artifact, outcome, and Merkle-forest binding --- into one appeal
window, so escalation changes the decision cost and decision-maker without
discarding the record an appeal needs [internal].}
\label{fig:governance-flow}
