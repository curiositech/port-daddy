% Reader question: Which single key holder, if compromised, breaks which
%   custody guarantee?
% Claim: three of the four guarantees have one sufficient secret; only user
%   impersonation needs a conjunction of two secrets.
% Evidence: the custody theorem four minimum compromise sets (daemon signing
%   key, harbor session key, email AND passphrase, KMS witness signature)
%   from this chapter section on key custody [internal].
% Must distinguish: a single-point cut (one secret suffices) from the one
%   conjunctive cut (both secrets are required together).
% Grammar chosen: custody-by-guarantee threat matrix, four columns each with
%   its own minimum cut set and mitigation. Rejected: a node-link graph of
%   custodians, because it would hide which cuts are conjunctive.
% Five-second test: a reader names the one guarantee that needs two secrets
%   at once, and the mitigation under each column.

forest rollback each have one sufficient secret; user impersonation is the
sole conjunctive failure and requires both email and passphrase. Each
baseline names the consequence-limiting control for that cut. Same-user code
execution stays outside the theorem because that adversary can read every
secret the user process can read. [internal]}
