% Reader question (a): if nobody can see which engine is actually running,
% why does the market spiral toward the cheap one? Reader question (b): does
% attesting the engine force everyone onto the expensive model, or does it
% align incentive with efficiency? Claim: unattested, the one-period swap
% gain Delta c is constant in price, so no price deters it, and pooling
% survives only above the committed-share threshold mu*; attested with full
% price pass-through, the same gain becomes Delta c - Delta theta, which
% flips negative exactly when the cheap engine is the efficient one. Evidence:
% theta_H=1, theta_L=0.4, c_H=0.5, c_L=0.2 => Delta c=0.3, mu*=1/6 approx
% 0.167; attested keep=0.50 vs swap=0.20 => flip=-0.3 (thm:engine-swap,
% b5_engine_substitution.py, seed 20260816, 4000 draws, 0 violations). Must
% distinguish: the gain is price-independent (a flat line, not a slope) in
% both regimes; only its sign and the collapse threshold change. Grammar: a
% paired regime plot, one panel per regime on identical axes, rejected: one
% panel with two lines superimposed (hides that mu* and the flip are
% different mechanisms) and a bare pair of numbers (states the flip but not
% that it holds at every price). Five-second test: a reader says "the same
% gain that survives every price without attestation flips negative once
% the engine is attested."

\caption{The engine-swap gain (Theorem~\ref{thm:engine-swap}), at

one-period swap gain is the flat line $\Delta c=0.3$ at every committed share

strong engine is now the efficient choice, at zero audit stake. Both lines
