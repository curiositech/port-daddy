  {{\bfseries Trust boundary.}\quad Daemons A--E are trusted endpoints. Every link
   between them --- the dotted mesh edges and the cobalt gossip arrows alike ---
   runs over the untrusted network of \S\ref{sec:threat-model}. On that network the
   Dolev--Yao adversary may \emph{observe} every delta, learning which cards have
   been revoked (see ``Privacy,'' \S\ref{sec:revocation}), and may \emph{delay,
   drop, duplicate, or reorder} deltas --- which is why no finite worst-case
   freshness bound is claimed here. It cannot \emph{forge} a revocation, which is
   signed, nor \emph{un-revoke} one, which the append-only log forbids.};

% ─── Legend / mechanics panel beneath all five frames ────────────────────
\node[draw=hhebony,thick,fill=hhsand!30,rounded corners=3pt,

      text width=190mm]
  {{\bfseries Mechanism.}\quad
   Each daemon maintains a cuckoo filter (8-bit fingerprints, 4 entries/bucket,
   FP rate $\leq 2^{-5}$, load ceiling $0.95$) and a \emph{version vector} over its
   peers. Every 30\,s each daemon picks a random peer, exchanges vectors, and
   ships deltas (cards revoked since the peer's last-seen version).\\[2pt]
   {\bfseries Expected propagation.}\quad
   In a connected reliable-round random-peer model, a new revocation reaches all
   $m$ peers in expected $\Theta(\log m)$ rounds. The pictured 30\,s steps are an
   illustrative trace, not a deadline; partitions admit no finite global bound.\\[2pt]
   {\bfseries Legend.}\quad
   sand-filled node $=$ filter clean \quad$\cdot$\quad
   cobalt-ringed node $=$ filter contains revoked card \quad$\cdot$\quad

\caption{Gossip-synchronized revocation across a five-daemon mesh. At $t=0$ daemon~A
locally revokes a Harbor Card (its filter and revocation table). Anti-entropy gossip
ships deltas to random peers every 30\,s. Expected $\Theta(\log m)$ propagation
requires the stated connected reliable-round model; the panels show one possible
execution, not a worst-case time guarantee. Version vectors make duplicate and
reordered deltas idempotent once delivered, but do not heal an unbounded partition.
The dashed strip beneath the panels states the trust boundary the panels themselves
cannot draw: the daemons are trusted, every wire between them is not.}
\label{fig:anchor-revocation-gossip}
