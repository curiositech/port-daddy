%   the axis. Amber is never text (S3) and cream on white is a sticker (S6);
%   both labels are now ink, in clear space, with the amber restricted to
%   rules and the one fill region.
% Reader question: how quickly does a revocation reach all participants under
%   stated assumptions, and what is the residual exposure while it has not?
% Claim: every verifier has its own exposure interval, closed only when
%   gossip reaches it; the protocol's own guarantee is an expectation, not a
%   wall-clock deadline, and an unbounded partition removes even that.
% Evidence: five daemons A-E, wake times spread across the window (\S
%   "Gossip-based synchronization"); Theta(log m) expected rounds; the
%   pdexample computing 4-6 seconds for m=5 [internal].
% Must distinguish: the stale interval (exposure, before a lane's own wake)
%   from the informed interval (after); the partition caveat is a separate
%   claim from the timing trace, so it gets a second, explicit marker.
% Grammar chosen: swimlane Gantt (tpl-swimlane-gantt). Rejected: a single
%   average-latency number -- it would hide that C, D and E stay exposed far
%   longer than B, which is exactly the fact a reader needs to distrust an
%   average.
% Five-second test: "daemon A already knows; C, D, E are still stale when B
%   learns; the dashed line on the right says a partition has no deadline at
%   all."
