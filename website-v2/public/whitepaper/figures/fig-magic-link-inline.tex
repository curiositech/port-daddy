\caption{\linespread{1.08}\selectfont\textbf{Single-use redemption is a
concurrency property, one atomic step decides it.} Consumers A and B present
the same token in an overlapping window; both reach the shared step
\texttt{UPDATE ... WHERE consumed\_at IS NULL RETURNING}. SQLite's writer
serialization drains the token under the first transaction: it returns
\textsc{success} to A and zero rows, hence \textsc{reject}, to B. The audit
row records exactly one entry, the winning consumer, never a second success
path [verified, \texttt{magic-link.pv}].}
