\caption{\textbf{The transfer ceremony narrows a capability and moves
verification to the destination.} Four messages over Harbor A, Harbor B, and
the verifier at B: a self-presented request, A's offer binding its epoch root
$R_A^{(e)}$, B's acknowledgement minting $C_B'=\mathrm{att}_B(\mathrm{att}_A(C_A))$
under its own root $R_B^{(e)}$, and delivery. The capability set only shrinks
--- from ``read/write \texttt{src/payments/}, run tests'' to ``read/write
\texttt{payments/checkout}, run tests, no network, 6h TTL'' --- and after
message 3 every later check verifies under $B$'s key alone, with no synchronous
call back to Harbor A (Protocol~\ref{prot:xfer}) [internal].}
\label{fig:fh-xfer}
