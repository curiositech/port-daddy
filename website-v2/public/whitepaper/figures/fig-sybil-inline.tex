\caption{Sybil attack flow. The attacker spawns $K$ Sybil identities, each posting deposit $B_{\mathrm{dep}}$, then undercuts honest bids by $\varepsilon$ and defaults on loss. Empirically demonstrated in Figure~\ref{fig:sybil-mc-inline}.}
