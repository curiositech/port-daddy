% oracle layer's detection probability, that the folk-theorem threshold is

% starting point" -- but never puts the default beside the threshold, so a
% reader cannot see how much headroom 10% actually buys or where a cheaper
% sample would stop working. Curve: the chapter's own closed form
% p_d* = (pi_C - (1-delta) pi_D) / (L + delta pi_D) at the supplied payoffs
% pi_C = 5/3, pi_D = 4.95, L = 25, which reproduces the chapter's anchor
% p_d*(0.95) = 0.0478 exactly [verified].

\caption{\textbf{The default human-audit sample is roughly twice the detection
rate the cartel model demands, and a halved sample is not.} The amber curve is
the chapter's own fragility threshold, the per-round detection probability at
which a colluding oracle pair stops preferring the cartel, drawn from
$(\pi_C-(1-\delta)\pi_D)/(L+\delta\pi_D)$ at the supplied payoffs
$\pi_C=5/3$, $\pi_D=4.95$, $L=25$; below it collusion still pays. Because the
human-audit sampling rate is the oracle layer's detection probability, the
protocol's default $\sigma=10\%$ is the flat teal rule, and it clears the
threshold at every patience the model admits -- $0.0478$ at $\delta=0.95$, and
never more than $0.0557$ even as $\delta\to1$. A $5\%$ sample clears it only
until $\delta=0.964$; past that the cheaper sample silently licenses exactly the
2-of-3 oracle collusion the audit exists to price. The threshold is
model-conditional: a different payoff spread, event timing, or monitoring model
moves the whole curve, and the deployed detector is not claimed to attain it.

\texttt{figures/data/make-figure-data.py}, deterministic]}
