%   [verified, v1_refined.pv].

%   the wire) from the pinned verifier's (3, reads issuer policy) and its
%   extra signature check (4) that the naive path never reaches.

\caption{Two verifier ladders for the same wire bytes: \textbf{token} sends
\texttt{alg=none} with a tampered payload to \textbf{verifier} in both
panels (step 1, inside the dashed network band the Dolev-Yao adversary
controls). Panel A lets the token's own header choose the algorithm (step 2)
and accepts the forgery; panel B pins the algorithm to Ed25519 from issuer
policy (step 3), so the signature check (step 4) fails and the token is
rejected. This is the design invariant behind the ProVerif v1 (HS256) query
the attacker cannot derive \texttt{master\_key}: the accepting
path in panel A is exactly the path Algorithmic Pinning removes
[verified, v1\_refined.pv].}
