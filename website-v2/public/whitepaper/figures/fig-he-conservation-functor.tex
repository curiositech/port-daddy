% Figure IV.5 --- accounting quantities, not architecture boxes.
%
% Reader question: what is conserved inside one accounting unit, and exactly
% where does cross-currency exposure enter the books?
% Claim: a native-unit waterfall returns to zero by construction; a
% conversion waterfall cannot, because it must add a valuation function, a
% fee, slippage, and an open risk leg that is conserved only per unit, not
% in aggregate.
% Evidence: the wallet/escrow/commons deltas of prop:conservation (panel A)
% against the priced-conversion terms this section derives (panel B).
% Must distinguish: panel A's net bar actually closing at zero from panel
% B's dashed risk leg, which is the one term that does not close.
% Grammar chosen: paired accounting waterfalls, stacked (not side by side) so
% panel B's five terms get the full column and no longer crowd each other --
% the v1 defect. Bars are edged boxes on a drawn zero baseline, each signed by
% a +/- mark, not bare strokes. Grammar rejected: an abstract commutative
% diagram (atlas reject) -- it would show that a diagram commutes, not that
% specific signed quantities sum to zero.
% Five-second test: a reader can see panel A's last bar return to the zero
% line and panel B's last bar hang open, dashed, off that line.

and commons deltas return exactly to zero (the gold bar, each leg signed $+$ or
$-$ against the zero baseline). Panel B cannot close by adding unlike units: it
must record the valuation function and instant, plus fee and slippage, and it

unit-free portfolio total. [internal]}
