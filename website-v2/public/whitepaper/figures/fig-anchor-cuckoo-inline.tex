\caption{Two six-bucket cuckoo filters compared before and after the design
change. Top: peer $A$ inserts \texttt{c1} into bucket 2 and peer $B$ inserts
the same \texttt{c1} into bucket 5, an artifact of each peer's own insertion
and eviction history; bitwise \texttt{OR} keeps both placements, which is a
state no single filter build could have produced. Bottom: gossiping the
append-only ID log instead---peer $A$'s \texttt{c1 c7 c4} and peer $B$'s
\texttt{c2 c1 c9}---and taking the ordinary set union gives \texttt{c1 c2 c4
c7 c9}; each daemon rebuilds one local filter with \texttt{c1} in a single
bucket. [internal]}
