% Brief (grammar: before/after on identical six-bucket geometry; atlas
%   V/fig:anchor-cuckoo-inline). Fixes the audit defect: v1 filled every
%   bucket with a heavy solid navy cell, so the one fact (where c1 lands)
%   could not out-shout the five empty buckets around it. Here every empty
%   bucket is a plain white pd artifact cell; only a bucket that actually
%   holds c1 is filled, in the hue that names why it is there.
% Reader question: why can two daemons not merge cuckoo filters by OR-ing
%   their bit arrays, and what do they gossip instead?
% Claim: OR-ing keeps every placement either peer ever made, which is a state
%   no single filter build could produce; gossiping the ID log and rebuilding
%   locally keeps c1 in exactly one bucket.
% Evidence: peer A's c1 at bucket 2, peer B's c1 at bucket 5 (\S "Withdrawing
%   a card before it expires"); log union c1 c2 c4 c7 c9 [internal].
% Must distinguish: an empty bucket (plain, uninformative) from a bucket that
%   holds c1 (breach hue when the state is invalid, focus hue when rebuilt).
% Grammar chosen: before/after (tpl-before-after), same six-bucket geometry in
%   both panels. Rejected: heavy fills on every bucket (the v1 defect) --
%   equal weight for five empty cells and the one occupied one erases the
%   fact the figure exists to show.
% Five-second test: "OR keeps c1 in two buckets at once; the rebuilt log
%   keeps it in exactly one."

\caption{Two six-bucket cuckoo filters compared before and after the design
change. Top: peer $A$ inserts \texttt{c1} into bucket 2 and peer $B$ inserts
the same \texttt{c1} into bucket 5, an artifact of each peer's own insertion
and eviction history; every other bucket is empty, and bitwise \texttt{OR}
keeps both \texttt{c1} placements, a state no single filter build could have
produced. Bottom: gossiping the append-only ID log instead---peer $A$'s
\texttt{c1 c7 c4} and peer $B$'s \texttt{c2 c1 c9}---and taking the ordinary
set union gives \texttt{c1 c2 c4 c7 c9}; each daemon rebuilds one local
filter with \texttt{c1} in a single bucket, the rest in gold as ordinary
occupants. [internal]}
