§ 02 · Contrast study

WCAG 2.2, every pair, both themes

76 foreground/background pairs computed with the WCAG relative-luminance formula: the three text tiers on all three surfaces, every hue as small-text foreground on base and raised, and ink/cream text on every zone fill. Thresholds: AA text ≥ 4.5, AA large/UI ≥ 3.0, AAA ≥ 7.0.

Finding 1 — amber was never a text color

Light-theme --status-warning #a66f00 scores 3.71 on cream: it fails AA for small text and always did. It passes as a stripe/dot (UI ≥ 3.0) and at large sizes. Rule shipped with v2: amber text uses --status-warning-on-tint (8.5:1); raw amber is reserved for stripes, dots, and ≥24px display. Economy zones no longer inherit this trap: gold clears 5.0 as text and 5.4 under cream fills.

Finding 2 — the dark "black on gray" failure

The v1 doc put near-black code wells (#0b0d11) on the near-black page (#101216) — a 1.06:1 surface edge, invisible, with small colored text on top. v2 rule: code panels use the site's own theme-independent tokens (#edf1f9 on #12161f, 12.9:1), dark raised surfaces always carry a hairline or bracket edge, and colored text on dark surfaces uses the lighter *-on-tint cut.

Finding 3 — the audit itself was too narrow (self-caught late)

The first pass graded only text-on-surface pairs — so it certified pages whose surface-on-surface edges were invisible. Light-theme cards sat raised-on-base at 1.046:1: the "white on near beige." The matrix below now grades every surface adjacency in both themes. Fixes shipped: cards use the strong well in light (1.113:1, the same tint depth the FleetBar research report's own cards use), and every unbordered card carries a hairline edge in both themes. Nothing relies on background delta alone.

§ 03 · Type

Four systems, same page — you pick

IBM Plex is your chosen default and stays Option A. The question is only what, if anything, earns a place beside it. All four options use faces already on the site's rostered switcher, all self-hostable. Loading matches the design system’s own mechanism: IBM Plex arrives via the identical Google Fonts stylesheet the site ships in index.html (same families, same weights), and alternates load on demand exactly as TypeThemeSwitcher does. Each renders the same hero line and body so the voices compare directly. Per the typography audit: Bricolage Grotesque is excluded (high-contrast humanist terminals read "bubbly" against a Swiss-technical brief — the canonical mismatch), Hanken sits too close to the Inter voice you called boring, Recursive is back in the mix as the play voice: its CASL axis marks display em-phrases in the ports (Plex and Recursive are both superfamily-shortcut faces in the updated typography reference). Radnika remains the archive reference.

A · Plex, disciplined default
display — Plex Sans 700, −3% track
body — Plex Sans 400/16
mono — Plex Mono, tnum + zero

Your call, kept. What changes is usage, not face: per-scale tracking, tabular figures on every metric, and the mono voice doing all eyebrows/timestamps. The five ports below are set in exactly this.

§ 04 · The assignment

Five straight ports of the live pages

Faithful to the real routes: actual headlines, actual copy, actual data (18 blog posts, 13 examples, 7 papers, 13 product features), actual generated art from public/img — re-drawn in linework + palette v2, set in Plex (Option A). Level 3 — blocks as page architecture, calibrated against the v0-agentsd reference: edge-bleeding cobalt/chartreuse slabs, exposed column grid, poster-caps display, the one-filled-cell rule, legend-semantic diagram fills, black bands (all five ports run at this level; slab/fill chartreuse is --chart-yellow #cad900 with ink text; never small text). Blocking is a dial. The FleetBar rule ("one zone per view") was written for a 380pt popover; full pages earn more. Level 1 — hairline + stripe only (library, examples, blog, cli-backend). Level 2 — Vignelli blocking: filled ink label-blocks, filled stat tiles, a solid definition block, one zone per section (retired — home has moved up). Everywhere: stripes carry state or layer, brackets frame live panels, hard borders stay on primary surfaces. Toggle dark mode on each.
