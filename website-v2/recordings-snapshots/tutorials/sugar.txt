  Get started:
    pd setup                  [notify] Install daemon, MCP, FleetBar, init project
    pd begin "purpose" --lifecycle durable  [notify] I'll set up your agent + session
    pd done "summary"        [notify] Finish up — I'll clean everything
    pd whoami                [silent] See your current context
    pd attention             [notify] What other agents queued for you (run first thing!)

  Ports:
    pd claim <id>            [notify] I'll assign a port  (c)
    pd release <id>          [notify] Free it up  (r)  (--expired is destructive)
    pd find [pattern]        [silent] What's running  (f, l, ps)

  Sessions & notes:
    pd session start "why"   [notify] Manual session start
    pd session abandon        [destructive] End session as abandoned, release claims
    pd note "message"        [notify] Leave a note
    pd notes                 [silent] Review recent notes
    pd feedback "message"    [notify] Drop structured feedback (auto-slug, agent from context)
